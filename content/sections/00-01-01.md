Python è un linguaggio che si **legge quasi come l'inglese** e che gli ingegneri usano per calcolare, fare grafici e automatizzare il lavoro noioso. Si può usare in due modi: scrivendo una riga alla volta in una **console** (la REPL) oppure salvando più righe in uno **script**, un file `.py`.

Il modo più semplice per iniziare è usarlo come una calcolatrice. Premi **Esegui**:

```python
# area di una sezione rettangolare 30 × 50 mm, in mm²
print(30 * 50)
print("Momento d'inerzia:", 30 * 50**3 / 12, "mm^4")
```

`print` mostra il risultato. Tutto quello che sta dopo `#` è un **commento**: Python lo ignora, serve a te.

## Che cosa è successo, riga per riga

Un programma è un elenco di **istruzioni** che Python esegue **dall'alto in basso**, una alla volta. Rileggiamo l'esempio della scheda:

1. `# area di una sezione…` è un commento: Python salta la riga.
2. `print(30 * 50)` fa due cose. Prima calcola quello che sta tra le parentesi, `30 * 50 = 1500`, poi lo **stampa** sullo schermo.
3. `print("Momento d'inerzia:", 30 * 50**3 / 12, "mm^4")` stampa **tre cose** separate da virgole: un testo, un numero calcolato e un altro testo. Python le scrive una dopo l'altra, separate da uno spazio.

Il testo va **tra virgolette** (`"…"` oppure `'…'`): così Python sa che non deve calcolarlo ma solo ripeterlo. Senza virgolette, `mm` sarebbe un nome sconosciuto e otterresti un errore.

```python
print("Ciao, ingegnere")     # → Ciao, ingegnere
print(2 + 3)                 # → 5
print("2 + 3")               # → 2 + 3   (è testo: non viene calcolato)
print("Somma:", 2 + 3)       # → Somma: 5
```

In questo libro, accanto agli esempi, il commento `# →` indica che cosa compare quando premi **Esegui**.

## Le quattro operazioni (e la potenza)

| Scrivi | Significa | Esempio | Risultato |
|---|---|---|---|
| `+` | somma | `12 + 3` | `15` |
| `-` | differenza | `12 - 3` | `9` |
| `*` | prodotto | `12 * 3` | `36` |
| `/` | divisione | `12 / 3` | `4.0` |
| `**` | potenza | `12 ** 2` | `144` |

```python
print(12 + 3, 12 - 3, 12 * 3, 12 / 3, 12 ** 2)   # → 15 9 36 4.0 144
```

Nota `4.0`: la divisione `/` restituisce sempre un numero con la virgola, anche quando il risultato è intero. Nella prossima sezione vedrai perché esistono due tipi di numeri.

Si possono usare le **parentesi tonde** come in algebra, anche annidate:

```python
# media di tre misure di diametro, in mm
print((20.02 + 19.98 + 20.01) / 3)       # → 20.003333333333334
# senza parentesi divideresti solo l'ultima misura!
print(20.02 + 19.98 + 20.01 / 3)         # → 46.67
```

## Un piccolo calcolo da ingegnere

Le righe vuote non contano: servono solo a respirare. I commenti invece servono a ricordare **le unità di misura**, che Python non conosce.

```python
# tensione in un tirante: σ = F / A
print("Area:", 3.1416 * 12**2 / 4, "mm²")          # diametro 12 mm
print("Tensione:", 10000 / (3.1416 * 12**2 / 4), "MPa")  # forza 10 000 N
```

Funziona, ma ripetere `3.1416 * 12**2 / 4` è scomodo e rischioso. Nella prossima sezione darai un **nome** ai valori, e il calcolo diventerà leggibile come una formula sul quaderno.

## Console e script

Nella console scrivi un'istruzione e vedi subito il risultato: è perfetta per provare. Uno script invece si salva e si riesegue domani, magari con dati diversi. In questa app ogni blocco di codice è un piccolo script: lo puoi eseguire e, nelle task **Scrivi**, modificare.

Sul tuo computer installa Python da [python.org](https://www.python.org/downloads/) e prova `python` nel terminale; per gli esercizi lunghi userai un editor come VS Code (appendice A).

## Le regole di base

- Un'istruzione per riga, senza punto e virgola.
- **L'indentazione conta**: gli spazi a inizio riga dicono a Python quali righe stanno insieme (lo vedrai con `if` e `for`). Per ora: niente spazi all'inizio delle righe.
- Maiuscole e minuscole sono diverse: `Print` non esiste, `print` sì.
- Il separatore dei decimali è il **punto**: `2.5`, non `2,5`.

```python
forza = 1200        # N
area = 30 * 50      # mm²
tensione = forza / area
print(tensione, "N/mm² (cioè MPa)")   # → 0.8 N/mm² (cioè MPa)
```

## Gli errori del primo giorno

Sbagliare è normale: Python si ferma e scrive un messaggio. L'ultima riga dice che cosa non va.

| Hai scritto | Errore | Perché |
|---|---|---|
| `30 x 50` | `SyntaxError` | la moltiplicazione è `*` |
| `print(Ciao)` | `NameError` | mancano le virgolette: `Ciao` sembra un nome |
| `Print(5)` | `NameError` | maiuscola sbagliata |
| `print(3^2)` | nessun errore, ma vale `1`! | `^` non è la potenza: usa `**` |

> [!ing] I calcoli della relazione di un esercizio di Scienza delle costruzioni stanno benissimo in uno script: se cambia un dato, lo riesegui e tutto si aggiorna, senza ricopiare numeri a mano.

> [!trappola] `30 x 50` dà errore: in Python la moltiplicazione è `*`, la potenza è `**` (non `^`).

## Riepilogo

- Python esegue le istruzioni dall'alto in basso.
- `print(...)` mostra valori; più valori si separano con la virgola.
- Testo tra virgolette, numeri senza; commenti dopo `#`.
- Operazioni: `+ - * / **`, con le parentesi come in algebra.
