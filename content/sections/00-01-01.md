Python è un linguaggio che si **legge quasi come l'inglese** e che gli ingegneri usano per calcolare, fare grafici e automatizzare il lavoro noioso. Si può usare in due modi: scrivendo una riga alla volta in una **console** (la REPL) oppure salvando più righe in uno **script**, un file `.py`.

Il modo più semplice per iniziare è usarlo come una calcolatrice. Premi **Esegui**:

```python
# area di una sezione rettangolare 30 × 50 mm, in mm²
print(30 * 50)
print("Momento d'inerzia:", 30 * 50**3 / 12, "mm^4")
```

`print` mostra il risultato. Tutto quello che sta dopo `#` è un **commento**: Python lo ignora, serve a te.

## Console e script

Nella console scrivi un'istruzione e vedi subito il risultato: è perfetta per provare. Uno script invece si salva e si riesegue domani, magari con dati diversi. In questa app ogni blocco di codice è un piccolo script: lo puoi eseguire e, nelle task **Scrivi**, modificare.

Sul tuo computer installa Python da [python.org](https://www.python.org/downloads/) e prova `python` nel terminale; per gli esercizi lunghi userai un editor come VS Code.

## Le regole di base

- Un'istruzione per riga, senza punto e virgola.
- **L'indentazione conta**: gli spazi a inizio riga dicono a Python quali righe stanno insieme (lo vedrai con `if` e `for`).
- Maiuscole e minuscole sono diverse: `Print` non esiste, `print` sì.

```python
forza = 1200        # N
area = 30 * 50      # mm²
tensione = forza / area
print(tensione, "N/mm² (cioè MPa)")
```

> [!ing] I calcoli della relazione di un esercizio di Scienza delle costruzioni stanno benissimo in uno script: se cambia un dato, lo riesegui e tutto si aggiorna, senza ricopiare numeri a mano.

> [!trappola] `30 x 50` dà errore: in Python la moltiplicazione è `*`, la potenza è `**` (non `^`).
