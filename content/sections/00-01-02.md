Una **variabile** è un nome che si riferisce a un valore. Si crea con `=`, senza dichiarare il tipo: Python lo capisce da solo.

```python
lunghezza = 2.5      # m   -> float (numero con la virgola)
n_bulloni = 8        # pz  -> int (intero)
materiale = "S235"   # testo -> str
print(type(lunghezza), type(n_bulloni), type(materiale))
```

I numeri interi sono `int`, quelli con la virgola sono `float`. **Il separatore decimale è il punto**, non la virgola.

## Nomi chiari

Un buon nome vale più di un commento: `tensione_ammissibile` si capisce, `ta` no. Le regole: lettere, cifre e `_`, senza spazi e senza iniziare con una cifra. Per convenzione si usa il minuscolo con i trattini bassi (lo stile si chiama *snake_case*, il nome è tutto un programma).

## Interi e float

Gli `int` in Python non hanno limite di grandezza. I `float` invece hanno una precisione finita, come in una calcolatrice:

```python
print(2**100)          # nessun overflow
print(0.1 + 0.2)       # non è esattamente 0.3!
print(round(0.1 + 0.2, 3))
```

Per confrontare risultati con la virgola non usare mai `==` alla cieca: arrotonda o usa una tolleranza (lo vedremo con `math.isclose`).

## Riassegnare

Una variabile può cambiare valore, anche di tipo:

```python
carico = 10      # kN
carico = carico * 1.5   # coefficiente di sicurezza
print(carico)
```

> [!c] Se vieni dal C: non dichiari `int x;`. Il tipo appartiene al valore, non al nome. Il nome è un'etichetta che puoi spostare su un altro oggetto.

> [!trappola] `2,5` non è due e mezzo: per Python è una **coppia** di numeri `(2, 5)`. Scrivi `2.5`.
