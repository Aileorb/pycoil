Una **variabile** è un nome che si riferisce a un valore. Si crea con `=`, senza dichiarare il tipo: Python lo capisce da solo.

```python
lunghezza = 2.5      # m   -> float (numero con la virgola)
n_bulloni = 8        # pz  -> int (intero)
materiale = "S235"   # testo -> str
print(type(lunghezza), type(n_bulloni), type(materiale))
```

I numeri interi sono `int`, quelli con la virgola sono `float`. **Il separatore decimale è il punto**, non la virgola.

## Che cosa fa davvero `=`

In matematica `=` dice che due cose sono uguali. In Python vuol dire **assegna**: «calcola quello che sta a destra e chiamalo con il nome a sinistra». Si legge da destra verso sinistra.

```python
F = 12_000          # N   (il _ serve solo a leggere meglio: è 12000)
A = 30 * 50         # mm² (prima si calcola 1500, poi gli si dà il nome A)
sigma = F / A       # MPa
print(sigma)        # → 8.0
```

Passo per passo: Python crea `F` con il valore `12000`; poi calcola `30 * 50`, ottiene `1500` e lo chiama `A`; infine calcola `F / A`, cioè `12000 / 1500 = 8.0`, e lo chiama `sigma`. Da quel momento, scrivere `sigma` equivale a scrivere `8.0`.

Il nome deve esistere **prima** di essere usato: se scrivi `print(tau)` senza aver mai assegnato `tau`, Python si ferma con `NameError: name 'tau' is not defined`.

## Nomi chiari

Un buon nome vale più di un commento: `tensione_ammissibile` si capisce, `ta` no. Le regole:

- lettere, cifre e `_`, **senza spazi**;
- non può iniziare con una cifra (`2piani` no, `piani_2` sì);
- maiuscole e minuscole contano: `Area` e `area` sono due nomi diversi;
- non si possono usare le parole riservate del linguaggio, come `if`, `for`, `class`, `lambda`.

Per convenzione si usa il minuscolo con i trattini bassi: lo stile si chiama *snake_case*, e il nome è tutto un programma. Nelle formule tecniche vanno benissimo anche i simboli brevi che usi sul quaderno (`F`, `A`, `E`, `I`), purché il commento dica l'unità.

## I tipi: int, float, str (e bool)

Ogni valore ha un **tipo**, che `type()` ti mostra:

| Tipo | Che cos'è | Esempi |
|---|---|---|
| `int` | numero intero | `8`, `-3`, `12_000` |
| `float` | numero con la virgola | `2.5`, `-0.75`, `2.1e5` (cioè 2,1·10⁵) |
| `str` | testo (stringa) | `"S235"`, `'IPE 200'` |
| `bool` | vero o falso | `True`, `False` |

```python
E = 2.1e5          # MPa, modulo elastico dell'acciaio
print(E)           # → 210000.0
print(type(E))     # → <class 'float'>
print(type(7 / 2), type(7 * 2))   # → <class 'float'> <class 'int'>
```

Quando un'operazione mescola `int` e `float`, il risultato è `float`: `3 * 1.5` dà `4.5`. La divisione `/` dà **sempre** `float`. Per passare da un tipo all'altro ci sono `int()`, `float()` e `str()`:

```python
print(int(7.9))       # → 7      (tronca, non arrotonda)
print(round(7.9))     # → 8
print(float(3))       # → 3.0
print(float("2.5") * 2)   # → 5.0  (dal testo al numero)
```

## Interi e float: precisione

Gli `int` in Python non hanno limite di grandezza. I `float` invece hanno una precisione finita, come in una calcolatrice: circa 15–16 cifre significative.

```python
print(2**100)          # nessun overflow
print(0.1 + 0.2)       # non è esattamente 0.3!
print(round(0.1 + 0.2, 3))
```

`0.1` in binario è un numero periodico, come 1/3 in decimale: il computer ne salva un'approssimazione e i piccoli errori si vedono. Per i calcoli tecnici non è un problema (nessuno misura una trave al sedicesimo decimale), ma **per confrontare due float non usare mai `==` alla cieca**: arrotonda o usa una tolleranza (lo vedrai con `math.isclose` nella prossima sezione).

## Riassegnare

Una variabile può cambiare valore, anche di tipo. Il valore vecchio viene semplicemente dimenticato.

```python
carico = 10              # kN
carico = carico * 1.5    # coefficiente di sicurezza: prima si calcola 10 * 1.5
print(carico)            # → 15.0
```

La seconda riga confonde chi viene dalla matematica (`carico = carico * 1.5` sarebbe un'equazione impossibile). In Python è normale: «prendi il valore attuale di `carico`, moltiplicalo per 1,5 e rimetti il risultato nello stesso nome». Esiste anche la forma breve `carico *= 1.5`, e così `+=`, `-=`, `/=`.

```python
totale = 0
totale += 12.5     # come totale = totale + 12.5
totale += 8.0
print(totale)      # → 20.5
```

## Esempio completo: peso di una barra

```python
# barra tonda in acciaio
d = 20          # mm, diametro
L = 1.5         # m, lunghezza
rho = 7850      # kg/m³, densità dell'acciaio

A = 3.1416 * (d / 1000)**2 / 4    # m² (prima i mm diventano m)
V = A * L                          # m³
m = rho * V                        # kg
print("Massa:", round(m, 2), "kg")         # → Massa: 3.7 kg
print("Peso:", round(m * 9.81, 1), "N")    # → Peso: 36.3 N
```

Se domani la barra è lunga 2 m, cambi **una** riga e riesegui: ecco il vantaggio dei nomi rispetto ai numeri scritti dentro le formule.

> [!c] Se vieni dal C: non dichiari `int x;`. Il tipo appartiene al valore, non al nome. Il nome è un'etichetta che puoi spostare su un altro oggetto.

> [!trappola] `2,5` non è due e mezzo: per Python è una **coppia** di numeri `(2, 5)`. Scrivi `2.5`.

## Riepilogo

- `nome = valore` crea o aggiorna una variabile; prima si calcola il lato destro.
- Tipi principali: `int`, `float`, `str`, `bool`; `type()` li mostra.
- `/` dà sempre un `float`; `int()`, `float()`, `str()` convertono.
- I float sono approssimati: mai `==` tra risultati di calcoli.
- `+=`, `-=`, `*=` aggiornano una variabile in una sola mossa.
