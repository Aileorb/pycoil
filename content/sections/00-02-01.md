Gli operatori aritmetici sono quelli che ti aspetti, più qualche sorpresa utile:

| Operatore | Significato | Esempio | Risultato |
| --- | --- | --- | --- |
| `+ - *` | somma, differenza, prodotto | `3 * 4` | `12` |
| `/` | divisione (sempre float) | `7 / 2` | `3.5` |
| `//` | divisione intera | `7 // 2` | `3` |
| `%` | resto | `7 % 2` | `1` |
| `**` | potenza | `2 ** 3` | `8` |

Per seno, radici e π serve il **modulo** `math`, che si importa una volta in cima:

```python
import math
d = 20  # mm, diametro di un perno
area = math.pi * d**2 / 4
print(round(area, 1), "mm²")
```

## Le funzioni più usate

```python
import math
print(math.sqrt(2))            # radice quadrata
print(math.sin(math.radians(30)))  # gli angoli vanno in radianti!
print(math.degrees(math.atan2(3, 4)))
print(math.isclose(0.1 + 0.2, 0.3))  # confronto con tolleranza
```

Le funzioni trigonometriche lavorano in **radianti**: usa `math.radians` per convertire i gradi.

## Precedenza

Valgono le regole dell'algebra: prima `**`, poi `* / // %`, poi `+ -`. Nel dubbio, metti le parentesi.

```python
# modulo di resistenza di una sezione rettangolare b×h
b, h = 30, 50
W = b * h**2 / 6
print(W, "mm³")
```

> [!ing] Nei corsi di Disegno e di Costruzione di macchine userai di continuo `math.pi`, `math.sqrt` e la conversione gradi/radianti: tienili a portata di mano.

> [!trappola] `-2**2` vale `-4`, non `4`: la potenza viene prima del segno meno. Scrivi `(-2)**2`.
