Gli operatori aritmetici sono quelli che ti aspetti, più qualche sorpresa utile:

| Operatore | Significato | Esempio | Risultato |
| --- | --- | --- | --- |
| `+ - *` | somma, differenza, prodotto | `3 * 4` | `12` |
| `/` | divisione (sempre float) | `7 / 2` | `3.5` |
| `//` | divisione intera | `7 // 2` | `3` |
| `%` | resto | `7 % 2` | `1` |
| `**` | potenza | `2 ** 3` | `8` |

Per seno, radici e π serve il **modulo** `math`, che si importa una volta in cima:

```python
import math
d = 20  # mm, diametro di un perno
area = math.pi * d**2 / 4
print(round(area, 1), "mm²")
```

## Divisione intera e resto: a cosa servono

`//` e `%` sembrano strani, ma risolvono problemi concreti. `//` dice **quante volte** un numero sta in un altro, `%` dice **che cosa avanza**.

```python
# da una barra di 6000 mm si tagliano spezzoni da 850 mm
barra = 6000
pezzo = 850
print(barra // pezzo)    # → 7     (pezzi interi)
print(barra % pezzo)     # → 50    (sfrido, in mm)

# 200 minuti di prova: quante ore e quanti minuti?
print(200 // 60, "h", 200 % 60, "min")   # → 3 h 20 min
```

Un uso classico di `%`: un numero è pari se `n % 2` vale `0`.

## Che cos'è un modulo

Python di base sa fare le quattro operazioni. Tutto il resto (funzioni matematiche, date, file…) sta in **moduli**, cioè raccolte di strumenti già pronti. `import math` li rende disponibili; poi si usano scrivendo il nome del modulo, un punto e il nome dello strumento: `math.sqrt`, `math.pi`.

```python
import math
print(math.pi)          # → 3.141592653589793
print(math.sqrt(144))   # → 12.0
print(math.e)           # → 2.718281828459045
```

L'`import` si scrive **una volta**, di solito in cima allo script, e vale per tutte le righe sotto.

## Le funzioni più usate

| Funzione | Che cosa fa | Esempio | Risultato |
|---|---|---|---|
| `math.sqrt(x)` | radice quadrata | `math.sqrt(2)` | `1.4142…` |
| `math.sin(x)`, `cos`, `tan` | trigonometria (**radianti**) | `math.cos(0)` | `1.0` |
| `math.radians(g)` | gradi → radianti | `math.radians(180)` | `3.1415…` |
| `math.degrees(r)` | radianti → gradi | `math.degrees(math.pi)` | `180.0` |
| `math.atan2(y, x)` | angolo di un vettore | `math.atan2(1, 1)` | `0.785…` (45°) |
| `math.hypot(x, y)` | lunghezza di un vettore | `math.hypot(3, 4)` | `5.0` |
| `math.log(x)`, `log10` | logaritmo naturale / decimale | `math.log10(1000)` | `3.0` |
| `math.exp(x)` | esponenziale | `math.exp(0)` | `1.0` |
| `math.isclose(a, b)` | confronto con tolleranza | `math.isclose(0.1 + 0.2, 0.3)` | `True` |

```python
import math
print(math.sqrt(2))            # radice quadrata
print(math.sin(math.radians(30)))  # gli angoli vanno in radianti!
print(math.degrees(math.atan2(3, 4)))
print(math.isclose(0.1 + 0.2, 0.3))  # confronto con tolleranza
```

Le funzioni trigonometriche lavorano in **radianti**: usa `math.radians` per convertire i gradi. Il seno di 30° non è `math.sin(30)` (quello è il seno di 30 radianti!).

## Esempio: le componenti di una forza

Una forza di 5 kN inclinata di 30° sull'orizzontale. Componenti e, al contrario, modulo e angolo a partire dalle componenti:

```python
import math
F = 5.0                       # kN
alfa = math.radians(30)       # 30° in radianti
Fx = F * math.cos(alfa)
Fy = F * math.sin(alfa)
print(round(Fx, 3), round(Fy, 3))            # → 4.33 2.5

# e all'indietro: dalle componenti al modulo e all'angolo
print(round(math.hypot(Fx, Fy), 3))          # → 5.0
print(round(math.degrees(math.atan2(Fy, Fx)), 1))   # → 30.0
```

`round(x, n)` arrotonda a `n` decimali: utile per stampare, ma conviene arrotondare **solo alla fine**, mai nei passaggi intermedi.

## Precedenza

Valgono le regole dell'algebra: prima `**`, poi `* / // %`, poi `+ -`. A parità di livello si procede da sinistra a destra. Nel dubbio, metti le parentesi: non costano niente e rendono chiara l'intenzione.

```python
# modulo di resistenza di una sezione rettangolare b×h
b = 30   # mm
h = 50   # mm
W = b * h**2 / 6
print(W, "mm³")

print(2 + 3 * 4)       # → 14   (prima il prodotto)
print((2 + 3) * 4)     # → 20
print(2 * 3 ** 2)      # → 18   (prima la potenza: 3² = 9)
```

## Esempio: carico critico di Eulero

La formula `P = π² E I / L²` diventa una riga quasi identica:

```python
import math
E = 210_000          # MPa
d = 20               # mm, asta tonda
I = math.pi * d**4 / 64     # mm^4
L = 1500             # mm
P = math.pi**2 * E * I / L**2
print(round(P), "N")         # → 7235 N
```

> [!ing] Nei corsi di Disegno e di Costruzione di macchine userai di continuo `math.pi`, `math.sqrt` e la conversione gradi/radianti: tienili a portata di mano.

> [!trappola] `-2**2` vale `-4`, non `4`: la potenza viene prima del segno meno. Scrivi `(-2)**2`.

## Riepilogo

- `//` quante volte sta, `%` quanto avanza.
- `import math` una volta in cima; poi `math.nome`.
- Trigonometria in radianti: `math.radians` e `math.degrees` convertono.
- Precedenza come in algebra; nel dubbio, parentesi.
- Arrotonda con `round` solo il risultato finale.
