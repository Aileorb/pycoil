Il testo in Python è una **stringa** (`str`), tra apici singoli o doppi. Per inserire numeri nel testo si usano le **f-string**: una `f` davanti e le variabili tra graffe.

```python
F = 12500    # N
A = 314.16   # mm²
sigma = F / A
print(f"Tensione: {sigma:.1f} MPa")
```

Dopo i due punti si mette il **formato**: `.1f` significa "una cifra decimale".

## Formati utili per un ingegnere

```python
x = 1234567.891
print(f"{x:.2f}")     # 2 decimali
print(f"{x:,.0f}")    # separatore delle migliaia
print(f"{x:.3e}")     # notazione scientifica
print(f"{0.0457:.1%}")  # percentuale
print(f"{'S355':>8}|")  # allineato a destra in 8 caratteri
```

## Operazioni sulle stringhe

```python
codice = "  IPE 200  "
print(codice.strip())         # toglie gli spazi ai lati
print(codice.strip().lower())
print("200" in codice)        # contiene?
print(codice.strip().split(" "))  # divide in pezzi
```

Le stringhe sono **immutabili**: i metodi non modificano l'originale ma restituiscono una stringa nuova.

## Da testo a numero

I dati letti da un file o digitati sono testo: vanno convertiti.

```python
valore = "235"
fy = float(valore)
print(fy * 1.2)
```

> [!trappola] `"2" + "3"` dà `"23"`, non `5`: sono stringhe. Converti prima con `int()` o `float()`.

> [!ing] Nelle relazioni tecniche metti sempre l'unità di misura accanto al numero: con le f-string è una riga, e niente più "2.3456789" con nove decimali inutili.
