Il testo in Python è una **stringa** (`str`), tra apici singoli o doppi. Per inserire numeri nel testo si usano le **f-string**: una `f` davanti e le variabili tra graffe.

```python
F = 12500    # N
A = 314.16   # mm²
sigma = F / A
print(f"Tensione: {sigma:.1f} MPa")
```

Dopo i due punti si mette il **formato**: `.1f` significa "una cifra decimale".

## Scrivere una stringa

Apici singoli o doppi sono equivalenti; si sceglie quello che non compare nel testo. Per andare a capo si usa `\n`; per un testo su più righe, tre virgolette.

```python
print('Profilo "IPE 200"')        # → Profilo "IPE 200"
print("L'acciaio S355")           # → L'acciaio S355
print("riga 1\nriga 2")           # va a capo dopo «riga 1»
nota = """Verifica a flessione
secondo la norma"""
print(nota)
```

## Unire e ripetere

Con `+` le stringhe si **concatenano**, con `*` si ripetono. Un numero però va trasformato in testo con `str()` prima di unirlo, altrimenti Python non sa se vuoi sommare o incollare:

```python
nome = "IPE" + " " + "200"
print(nome)                  # → IPE 200
print("-" * 20)              # → --------------------
h = 200
print("altezza " + str(h) + " mm")   # → altezza 200 mm
```

È proprio per evitare questi `str()` e `+` che esistono le f-string.

## f-string passo per passo

Una f-string è una stringa con una `f` davanti. Tutto quello che sta tra `{}` viene **calcolato** e inserito nel testo; il resto resta com'è.

```python
b = 30                                # mm
h = 50                                # mm
print(f"Sezione {b}×{h} mm")          # → Sezione 30×50 mm
print(f"Area: {b * h} mm²")           # → Area: 1500 mm²  (dentro le graffe si può calcolare)
print(f"I = {b * h**3 / 12:.0f} mm^4")   # → I = 312500 mm^4
```

Dopo il nome (o il calcolo) si può aggiungere `:` e un **formato**. I più utili:

| Formato | Significato | Esempio | Risultato |
|---|---|---|---|
| `.2f` | 2 decimali | `f"{3.14159:.2f}"` | `3.14` |
| `.0f` | nessun decimale (arrotonda) | `f"{2.6:.0f}"` | `3` |
| `,.0f` | separatore delle migliaia | `f"{1234567:,.0f}"` | `1,234,567` |
| `.3e` | notazione scientifica | `f"{0.000123:.3e}"` | `1.230e-04` |
| `.1%` | percentuale | `f"{0.0457:.1%}"` | `4.6%` |
| `>8` | a destra in 8 caratteri | `f"{'S355':>8}"` | `    S355` |
| `<8` | a sinistra in 8 caratteri | `f"{'S355':<8}"` | `S355    ` |

## Formati utili per un ingegnere

```python
x = 1234567.891
print(f"{x:.2f}")     # 2 decimali
print(f"{x:,.0f}")    # separatore delle migliaia
print(f"{x:.3e}")     # notazione scientifica
print(f"{0.0457:.1%}")  # percentuale
print(f"{'S355':>8}|")  # allineato a destra in 8 caratteri
```

Combinando larghezza e decimali si costruiscono tabelle allineate:

```python
print(f"{'Profilo':<10}{'A [mm²]':>10}")
print(f"{'IPE 200':<10}{2848:>10.0f}")
print(f"{'HEA 160':<10}{3877:>10.0f}")
```

## Operazioni sulle stringhe

Le stringhe hanno dei **metodi**: funzioni che si chiamano con il punto, `testo.metodo()`.

| Metodo | Che cosa fa | Esempio | Risultato |
|---|---|---|---|
| `.strip()` | toglie spazi ai lati | `"  ab  ".strip()` | `"ab"` |
| `.lower()`, `.upper()` | minuscolo, maiuscolo | `"Ipe".upper()` | `"IPE"` |
| `.replace(a, b)` | sostituisce | `"2,5".replace(",", ".")` | `"2.5"` |
| `.startswith(t)` | inizia con? | `"IPE 200".startswith("IPE")` | `True` |
| `.split(sep)` | divide in pezzi | `"a;b".split(";")` | `['a', 'b']` |
| `len(s)` | lunghezza | `len("S355")` | `4` |

```python
codice = "  IPE 200  "
print(codice.strip())         # toglie gli spazi ai lati
print(codice.strip().lower())
print("200" in codice)        # contiene?
print(codice.strip().split(" "))  # divide in pezzi
```

`split` restituisce una **lista** di pezzi (le liste le vedi tra due sezioni). I metodi si possono concatenare: `codice.strip().lower()` prima toglie gli spazi, poi trasforma in minuscolo.

Le stringhe sono **immutabili**: i metodi non modificano l'originale ma restituiscono una stringa nuova. Se vuoi tenere il risultato, assegnalo:

```python
s = "acciaio"
s.upper()          # calcola "ACCIAIO" ma nessuno lo conserva
print(s)           # → acciaio
s = s.upper()
print(s)           # → ACCIAIO
```

Un singolo carattere si legge con l'indice tra quadre, partendo da **zero**: `"S355"[0]` è `"S"`, `"S355"[-1]` è l'ultimo, `"5"`.

## Da testo a numero

I dati letti da un file o digitati sono testo: vanno convertiti.

```python
valore = "235"
fy = float(valore)
print(fy * 1.2)
```

Un caso tipico italiano: un numero scritto con la virgola. `float("2,5")` dà errore; prima si sostituisce la virgola:

```python
letto = "2,5"
x = float(letto.replace(",", "."))
print(x * 2)        # → 5.0
```

> [!trappola] `"2" + "3"` dà `"23"`, non `5`: sono stringhe. Converti prima con `int()` o `float()`.

> [!ing] Nelle relazioni tecniche metti sempre l'unità di misura accanto al numero: con le f-string è una riga, e niente più "2.3456789" con nove decimali inutili.

## Riepilogo

- Stringhe tra `'…'` o `"…"`; `\n` va a capo; `+` unisce, `*` ripete.
- f-string: `f"testo {espressione:formato}"`; formati `.2f`, `,.0f`, `.3e`, `.1%`, `>8`.
- Metodi: `strip`, `lower`, `upper`, `replace`, `split`, `startswith`; `len()` per la lunghezza.
- Le stringhe non cambiano: assegna il risultato dei metodi.
- Testo → numero con `float()` o `int()`, dopo aver sistemato la virgola.
