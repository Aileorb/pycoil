Con `if` il programma sceglie cosa fare. La condizione finisce con i **due punti** e il blocco da eseguire è **indentato** di 4 spazi.

```python
sigma = 180      # MPa
amm = 160        # MPa, tensione ammissibile
if sigma <= amm:
    print("Verifica soddisfatta")
else:
    print(f"NON verificato: {sigma} > {amm} MPa")
```

## Più casi: elif

```python
eta = 0.83   # coefficiente di utilizzo
if eta < 0.5:
    giudizio = "sovradimensionato"
elif eta <= 1.0:
    giudizio = "ok"
else:
    giudizio = "da rinforzare"
print(giudizio)
```

Python controlla le condizioni dall'alto in basso e si ferma alla **prima vera**.

## Confronti e operatori logici

`==` uguale, `!=` diverso, `< <= > >=`. Le condizioni si combinano con `and`, `or`, `not`. E si possono concatenare come in matematica:

```python
temperatura = 85
print(20 <= temperatura <= 90)          # dentro l'intervallo
ok_carico = True
print(ok_carico and temperatura < 100)
```

## Valori "veri" e "falsi"

Zero, la stringa vuota, la lista vuota e `None` contano come falso:

```python
misure = []
if not misure:
    print("Nessuna misura registrata")
```

> [!c] Se vieni dal C: niente parentesi tonde obbligatorie né graffe; si usano `and`/`or`/`not` al posto di `&&`/`||`/`!`. E non esiste lo `switch` classico (c'è il più potente `match`, che vedremo nella Parte II).

> [!trappola] `if x = 5:` è un errore: per confrontare serve `==`. Un solo `=` assegna.
