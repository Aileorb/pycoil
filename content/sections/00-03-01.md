Con `if` il programma sceglie cosa fare. La condizione finisce con i **due punti** e il blocco da eseguire è **indentato** di 4 spazi.

```python
sigma = 180      # MPa
amm = 160        # MPa, tensione ammissibile
if sigma <= amm:
    print("Verifica soddisfatta")
else:
    print(f"NON verificato: {sigma} > {amm} MPa")
```

## Condizioni: vero o falso

Una **condizione** è un'espressione che vale `True` (vero) o `False` (falso): il tipo `bool`. Si costruisce con gli operatori di confronto.

| Operatore | Significato | Esempio | Vale |
|---|---|---|---|
| `==` | uguale | `3 == 3` | `True` |
| `!=` | diverso | `3 != 4` | `True` |
| `<`, `<=` | minore, minore o uguale | `5 <= 5` | `True` |
| `>`, `>=` | maggiore, maggiore o uguale | `2 > 7` | `False` |

```python
sigma = 180
print(sigma <= 160)        # → False
print(sigma > 100)         # → True
print("S355" == "S355")    # → True   (si confrontano anche le stringhe)
```

## Come si legge un if

```python
sigma = 120
amm = 160
if sigma <= amm:                      # 1. la condizione, poi i due punti
    print("Verifica soddisfatta")     # 2. il blocco: eseguito solo se è vera
    print("margine:", amm - sigma, "MPa")
print("fine verifica")                # 3. di nuovo a sinistra: eseguita sempre
```

Python valuta la condizione: se è vera esegue **tutte** le righe indentate sotto; se è falsa le salta. La riga non indentata dopo il blocco viene eseguita in entrambi i casi. Prova a cambiare `sigma = 120` in `sigma = 200` e premi di nuovo **Esegui**.

Con `else` si dice cosa fare **altrimenti**:

```python
def esito(sigma, amm):
    if sigma <= amm:
        return "verificato"
    else:
        return "non verificato"

print(esito(120, 160))    # → verificato
print(esito(200, 160))    # → non verificato
```

## Più casi: elif

Quando le possibilità sono più di due, si aggiungono rami `elif` («altrimenti, se…»):

```python
eta = 0.83   # coefficiente di utilizzo
if eta < 0.5:
    giudizio = "sovradimensionato"
elif eta <= 1.0:
    giudizio = "ok"
else:
    giudizio = "da rinforzare"
print(giudizio)
```

Python controlla le condizioni dall'alto in basso e si ferma alla **prima vera**: gli altri rami non vengono nemmeno guardati. Per questo l'ordine conta. Con `eta = 0.3` la prima condizione è vera e `"sovradimensionato"` vince, anche se `0.3 <= 1.0` sarebbe vero a sua volta.

## Esempio: classe di resistenza

```python
def classe_snellezza(lam):
    """Classifica un'asta compressa in base alla snellezza λ."""
    if lam < 20:
        return "tozza: nessuna instabilità"
    elif lam < 100:
        return "intermedia: formula di Johnson"
    else:
        return "snella: formula di Eulero"

print(classe_snellezza(15))     # → tozza: nessuna instabilità
print(classe_snellezza(60))     # → intermedia: formula di Johnson
print(classe_snellezza(140))    # → snella: formula di Eulero
```

## Confronti e operatori logici

Le condizioni si combinano con `and` (devono essere vere **entrambe**), `or` (ne basta **una**), `not` (rovescia). E si possono concatenare come in matematica:

```python
temperatura = 85
print(20 <= temperatura <= 90)          # dentro l'intervallo
ok_carico = True
print(ok_carico and temperatura < 100)
```

| `a` | `b` | `a and b` | `a or b` |
|---|---|---|---|
| `True` | `True` | `True` | `True` |
| `True` | `False` | `False` | `True` |
| `False` | `False` | `False` | `False` |

```python
sigma, tau = 150, 95     # MPa
if sigma <= 160 and tau <= 92:
    print("entrambe verificate")
elif sigma > 160 or tau > 92:
    print("almeno una non verificata")   # → almeno una non verificata
```

## Valori "veri" e "falsi"

Non solo i `bool` vanno bene in un `if`: zero, la stringa vuota, la lista vuota e `None` contano come falso, tutto il resto come vero.

```python
misure = []
if not misure:
    print("Nessuna misura registrata")
```

## if dentro una funzione

Spesso un `if` decide che cosa restituire. Appena un `return` viene eseguito la funzione finisce, quindi a volte l'`else` non serve:

```python
def tensione(N, A):
    """MPa; None se l'area non ha senso."""
    if A <= 0:
        return None          # esce subito
    return N / A

print(tensione(10_000, 200))   # → 50.0
print(tensione(10_000, 0))     # → None
```

> [!c] Se vieni dal C: niente parentesi tonde obbligatorie né graffe; si usano `and`/`or`/`not` al posto di `&&`/`||`/`!`. E non esiste lo `switch` classico (c'è il più potente `match`, che vedremo nella Parte II).

> [!trappola] `if x = 5:` è un errore: per confrontare serve `==`. Un solo `=` assegna. E attenzione ai due punti e all'indentazione: dimenticarli è l'errore più frequente.

## Riepilogo

- Una condizione vale `True` o `False`; si scrive con `== != < <= > >=`.
- `if condizione:` + blocco indentato; `elif` per altri casi; `else` per il resto.
- Si esegue solo il primo ramo vero, dall'alto in basso.
- `and`, `or`, `not` combinano le condizioni; `a <= x <= b` controlla un intervallo.
- Zero, vuoto e `None` contano come falso.
