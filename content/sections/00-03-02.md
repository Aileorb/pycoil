Il ciclo `for` ripete un blocco **per ogni elemento** di una sequenza. Con `range` ottieni una sequenza di interi.

```python
# tabella dei carichi da 0 a 10 kN, passo 2.5
for i in range(5):
    carico = i * 2.5
    print(f"{carico:5.1f} kN")
```

`range(5)` produce 0, 1, 2, 3, 4: **parte da zero e si ferma prima di 5**.

## Come funziona un ciclo, giro per giro

```python
diametri = [8, 10, 12]           # mm
for d in diametri:               # «per ogni d nella lista diametri»
    print("diametro", d)         # il blocco indentato si ripete
print("fatto")                   # dopo il ciclo, una volta sola
```

Python fa tre **giri** (iterazioni), uno per elemento:

1. primo giro: `d = 8`, esegue il blocco e stampa `diametro 8`;
2. secondo giro: `d = 10`, stampa `diametro 10`;
3. terzo giro: `d = 12`, stampa `diametro 12`;
4. la lista è finita: esce dal ciclo e stampa `fatto`.

Il nome dopo `for` (qui `d`) lo scegli tu: a ogni giro riceve il valore successivo. Il blocco ripetuto è tutto quello che è indentato sotto.

## Iterare direttamente sugli elementi

In Python si scorre la lista, non gli indici:

```python
diametri = [8, 10, 12, 16]   # mm
for d in diametri:
    area = 3.1416 * d**2 / 4
    print(f"Ø{d}: {area:.1f} mm²")
```

Si può scorrere anche una stringa, carattere per carattere: `for c in "S355":` dà `S`, `3`, `5`, `5`.

## Le forme di range

Quando servono dei numeri interi in fila si usa `range`, che ha tre forme:

| Scrivi | Produce | Uso tipico |
|---|---|---|
| `range(5)` | 0, 1, 2, 3, 4 | ripetere 5 volte |
| `range(2, 6)` | 2, 3, 4, 5 | da 2 a 5 |
| `range(0, 20, 5)` | 0, 5, 10, 15 | con un passo |

```python
print(list(range(5)))         # 0..4
print(list(range(2, 6)))      # 2..5
print(list(range(0, 20, 5)))  # 0, 5, 10, 15
```

`list(...)` serve solo per vedere i numeri tutti insieme. In un `for` si scrive direttamente `for i in range(5):`.

## Accumulare: somme, massimi, conteggi

Lo schema più usato in assoluto: **prima del ciclo** si crea una variabile di partenza, **dentro** la si aggiorna a ogni giro, **dopo** si usa il risultato.

```python
forze = [120.0, -45.5, 300.0, 12.5]    # N

totale = 0                  # 1. si parte da zero
for f in forze:
    totale += f             # 2. a ogni giro si aggiunge
print("risultante:", totale, "N")    # → risultante: 387.0 N
```

Con un `if` dentro il ciclo si contano o si filtrano gli elementi:

```python
tensioni = [180, 250, 210, 300, 120]   # MPa
fy = 235
oltre = 0
massimo = tensioni[0]
for s in tensioni:
    if s > fy:
        oltre += 1          # conta quelle oltre lo snervamento
    if s > massimo:
        massimo = s         # tiene la più alta vista finora
print(oltre, "oltre fy; massimo", massimo, "MPa")   # → 2 oltre fy; massimo 300 MPa
```

## Costruire una lista nuova

Si parte da una lista vuota e si aggiunge un valore a ogni giro con `append`:

```python
diametri = [8, 10, 12, 16]
aree = []
for d in diametri:
    aree.append(round(3.1416 * d**2 / 4, 1))
print(aree)          # → [50.3, 78.5, 113.1, 201.1]
```

## Posizione e coppie: enumerate e zip

Se ti serve anche la posizione usa `enumerate`, se devi scorrere due liste insieme `zip`:

```python
forze = [1.2, 3.4, 2.2]    # kN
bracci = [0.5, 0.8, 1.1]   # m
M = 0
for i, (F, b) in enumerate(zip(forze, bracci), start=1):
    M += F * b
    print(f"forza {i}: contributo {F*b:.2f} kNm")
print(f"Momento totale: {M:.2f} kNm")
```

`enumerate` dà a ogni giro la coppia (posizione, elemento) e `zip` la coppia (forza, braccio): scrivendo `i, (F, b)` dai un nome a ciascun valore, con lo stesso *unpacking* visto per le funzioni che restituiscono più risultati. Separatamente sono più semplici:

```python
for i, d in enumerate([8, 10, 12]):
    print(i, d)              # 0 8, poi 1 10, poi 2 12

for F, b in zip([1.2, 3.4], [0.5, 0.8]):
    print(F * b)             # 0.6, poi 2.72
```

## Esempio: tabella di una funzione

Un ciclo con `range` e una funzione producono in un attimo una tabella di verifica:

```python
def freccia_mensola(F, L, E, I):
    """mm: mensola con forza in punta (N, mm, MPa, mm^4)."""
    return F * L**3 / (3 * E * I)

E, I = 210_000, 8.36e6          # acciaio, IPE 200 (mm^4)
for L in range(1000, 3001, 500):
    print(f"L = {L} mm  →  f = {freccia_mensola(5000, L, E, I):.2f} mm")
```

> [!c] Se vieni dal C: niente `for (i=0; i<n; i++)`. Scorri direttamente gli elementi; gli indici servono molto meno di quanto pensi.

> [!trappola] `range(1, 10)` non include il 10. Per includerlo scrivi `range(1, 11)`. E non modificare una lista mentre la scorri con `for`: costruiscine una nuova.

## Riepilogo

- `for x in sequenza:` ripete il blocco una volta per elemento.
- `range(n)`, `range(a, b)`, `range(a, b, passo)`: la fine è esclusa.
- Accumulare: variabile prima del ciclo, aggiornata dentro, usata dopo.
- `append` dentro il ciclo costruisce una lista nuova.
- `enumerate` dà posizione ed elemento, `zip` scorre più liste insieme.
