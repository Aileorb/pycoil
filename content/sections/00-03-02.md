Il ciclo `for` ripete un blocco **per ogni elemento** di una sequenza. Con `range` ottieni una sequenza di interi.

```python
# tabella dei carichi da 0 a 10 kN, passo 2.5
for i in range(5):
    carico = i * 2.5
    print(f"{carico:5.1f} kN")
```

`range(5)` produce 0, 1, 2, 3, 4: **parte da zero e si ferma prima di 5**.

## Le forme di range

```python
print(list(range(5)))         # 0..4
print(list(range(2, 6)))      # 2..5
print(list(range(0, 20, 5)))  # 0, 5, 10, 15
```

## Iterare direttamente sugli elementi

In Python si scorre la lista, non gli indici:

```python
diametri = [8, 10, 12, 16]   # mm
for d in diametri:
    area = 3.1416 * d**2 / 4
    print(f"Ø{d}: {area:.1f} mm²")
```

Se ti serve anche la posizione usa `enumerate`, se devi scorrere due liste insieme `zip`:

```python
forze = [1.2, 3.4, 2.2]    # kN
bracci = [0.5, 0.8, 1.1]   # m
M = 0
for i, (F, b) in enumerate(zip(forze, bracci), start=1):
    M += F * b
    print(f"forza {i}: contributo {F*b:.2f} kNm")
print(f"Momento totale: {M:.2f} kNm")
```

## Accumulare

Lo schema "parti da zero e aggiungi" è il pane quotidiano: somme, massimi, conteggi.

> [!c] Se vieni dal C: niente `for (i=0; i<n; i++)`. Scorri direttamente gli elementi; gli indici servono molto meno di quanto pensi.

> [!trappola] `range(1, 10)` non include il 10. Per includerlo scrivi `range(1, 11)`.
