`while` ripete un blocco **finché la condizione è vera**. È adatto quando non sai in anticipo quante volte servirà.

```python
# quante spire servono perché la molla sopporti 900 N?
spire = 1
portata = 0
while portata < 900:
    spire += 1
    portata = 120 * spire
print(spire, "spire →", portata, "N")
```

## break e continue

`break` esce subito dal ciclo, `continue` salta al giro successivo:

```python
letture = [21.3, 21.8, -999, 22.4, 95.0, 22.9]  # °C, -999 = sensore guasto
for t in letture:
    if t == -999:
        continue          # ignora la lettura non valida
    if t > 90:
        print("Allarme surriscaldamento!", t)
        break             # interrompi il monitoraggio
    print("ok", t)
```

## Metodi iterativi

Molti metodi numerici sono `while` che si fermano quando l'errore è abbastanza piccolo. Ecco la radice quadrata col metodo di Newton:

```python
a = 2.0
x = a
iterazioni = 0
while abs(x * x - a) > 1e-12:
    x = (x + a / x) / 2
    iterazioni += 1
print(x, "in", iterazioni, "iterazioni")
```

> [!trappola] Se la condizione non diventa mai falsa il ciclo non finisce. Qui l'app lo interrompe dopo 20 secondi; sul tuo computer premi **Ctrl+C**.
