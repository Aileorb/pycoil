`while` ripete un blocco **finché la condizione è vera**. È adatto quando non sai in anticipo quante volte servirà.

```python
# quante spire servono perché la molla sopporti 900 N?
spire = 1
portata = 0
while portata < 900:
    spire += 1
    portata = 120 * spire
print(spire, "spire →", portata, "N")
```

## for o while?

- `for` quando sai **su che cosa** ripetere: gli elementi di una lista, i numeri di un `range`.
- `while` quando sai **fino a quando** ripetere, ma non quante volte: finché l'errore è grande, finché la portata non basta, finché l'utente non scrive «fine».

## Come funziona, giro per giro

```python
n = 1
while n < 20:
    print(n)
    n = n * 2
print("uscito con n =", n)     # → uscito con n = 32
```

1. controlla `n < 20`: con `n = 1` è vera, entra, stampa `1`, `n` diventa 2;
2. torna su, controlla: `2 < 20`, stampa `2`, `n` diventa 4;
3. … e così via con 4, 8, 16;
4. con `n = 32` la condizione è falsa: salta il blocco e prosegue dopo il ciclo.

La condizione si controlla **all'inizio di ogni giro**. Perché il ciclo finisca, qualcosa nel blocco deve cambiare le variabili della condizione: qui `n = n * 2`.

## Lo schema completo

Ogni `while` ben scritto ha tre parti:

```python
# dopo quanti anni un capitale di 1000 € al 3% supera 1500 €?
capitale = 1000.0        # 1. preparazione: valori di partenza
anni = 0
while capitale < 1500:   # 2. condizione
    capitale *= 1.03     # 3. aggiornamento: avvicina la fine
    anni += 1
print(anni, "anni:", round(capitale, 2), "€")    # → 14 anni: 1512.59 €
```

## break e continue

`break` esce subito dal ciclo, `continue` salta al giro successivo. Funzionano sia nei `while` sia nei `for`:

```python
letture = [21.3, 21.8, -999, 22.4, 95.0, 22.9]  # °C, -999 = sensore guasto
for t in letture:
    if t == -999:
        continue          # ignora la lettura non valida
    if t > 90:
        print("Allarme surriscaldamento!", t)
        break             # interrompi il monitoraggio
    print("ok", t)
```

L'ultima lettura, `22.9`, non viene mai guardata: il `break` ha già chiuso il ciclo.

Un uso tipico di `break` è il ciclo «infinito» `while True:`, che si ferma da dentro quando succede qualcosa:

```python
x = 100.0
passi = 0
while True:
    x = x / 2
    passi += 1
    if x < 1:
        break
print(passi, "dimezzamenti, x =", x)     # → 7 dimezzamenti, x = 0.78125
```

## Metodi iterativi

Molti metodi numerici sono `while` che si fermano quando l'errore è abbastanza piccolo. Ecco la radice quadrata col metodo di Newton:

```python
a = 2.0
x = a
iterazioni = 0
while abs(x * x - a) > 1e-12:
    x = (x + a / x) / 2
    iterazioni += 1
print(x, "in", iterazioni, "iterazioni")
```

`abs()` dà il valore assoluto: l'errore `x² − a` può essere positivo o negativo, a noi interessa quanto è grande. `1e-12` è la **tolleranza**, 10⁻¹².

## Esempio: dimensionare per tentativi

Il diametro minimo di un tirante, aumentando di 1 mm finché la tensione non scende sotto l'ammissibile:

```python
import math
F = 50_000        # N
amm = 160         # MPa
d = 1             # mm, si parte piccoli
while F / (math.pi * d**2 / 4) > amm:
    d += 1
print("diametro minimo:", d, "mm")    # → diametro minimo: 20 mm
```

È lo stesso ragionamento che faresti a mano con le tabelle dei diametri commerciali, solo automatico.

> [!trappola] Se la condizione non diventa mai falsa il ciclo non finisce. Qui l'app lo interrompe dopo 20 secondi; sul tuo computer premi **Ctrl+C**. Controlla sempre che nel blocco ci sia l'aggiornamento della variabile che compare nella condizione.

## Riepilogo

- `while condizione:` ripete finché la condizione è vera; si controlla all'inizio di ogni giro.
- Preparazione, condizione, aggiornamento: senza aggiornamento il ciclo non finisce.
- `break` esce dal ciclo; `continue` passa al giro dopo; `while True` + `break` per uscire da dentro.
- I metodi numerici iterano finché l'errore supera una tolleranza.
