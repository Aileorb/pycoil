Una **funzione** dà un nome a un calcolo che userai più volte. Si definisce con `def`, riceve dei **parametri** e restituisce un risultato con `return`.

```python
def momento_inerzia_rett(b, h):
    """Momento d'inerzia di una sezione rettangolare b×h."""
    return b * h**3 / 12

print(momento_inerzia_rett(30, 50))
print(momento_inerzia_rett(50, 30))  # stessa sezione, ruotata
```

La stringa tra triple virgolette è la **docstring**: spiega cosa fa la funzione.

## Più risultati

Una funzione può restituire più valori, separati da virgole, e chi la chiama li riceve assegnandoli a più nomi in un colpo solo (si chiama *unpacking*, lo riprendi con le tuple nella Parte I):

```python
def sezione_circolare(d):
    import math
    A = math.pi * d**2 / 4
    I = math.pi * d**4 / 64
    return A, I

area, inerzia = sezione_circolare(20)
print(f"A = {area:.1f} mm², I = {inerzia:.0f} mm^4")
```

## Variabili locali

Le variabili create dentro una funzione **esistono solo lì dentro**. Questo evita che un calcolo ne sporchi un altro.

```python
def tensione(F, A):
    sigma = F / A
    return sigma

print(tensione(10_000, 200))
# print(sigma)  -> errore: sigma esiste solo dentro la funzione
```

Nota `10_000`: il trattino basso nei numeri è solo per leggerli meglio.

## return vs print

`print` mostra un valore sullo schermo; `return` lo **restituisce** a chi ha chiamato la funzione, che può usarlo in altri calcoli. Una funzione senza `return` restituisce `None`.

> [!trappola] Dimenticare `return` è l'errore più comune: la funzione calcola, ma tu ricevi `None`.

> [!ing] Una piccola libreria di funzioni ben scritte (sezioni, verifiche, conversioni) diventa il tuo formulario personale: è esattamente il Progetto 1.
