Una **funzione** dà un nome a un calcolo che userai più volte. Si definisce con `def`, riceve dei **parametri** e restituisce un risultato con `return`.

```python
def momento_inerzia_rett(b, h):
    """Momento d'inerzia di una sezione rettangolare b×h."""
    return b * h**3 / 12

print(momento_inerzia_rett(30, 50))
print(momento_inerzia_rett(50, 30))  # stessa sezione, ruotata
```

La stringa tra triple virgolette è la **docstring**: spiega cosa fa la funzione.

<!-- /card -->

## Perché servono

Finora ogni calcolo era scritto una volta sola. Ma la formula del momento d'inerzia la userai per decine di sezioni: riscriverla ogni volta è lento e prima o poi sbagli una potenza. Una funzione la scrivi **una volta**, la controlli **una volta**, e poi la usi quante volte vuoi chiamandola per nome. Sono le tue formule del formulario, ma che fanno i conti da sole.

## Anatomia di una funzione

```python
def area_rettangolo(b, h):        # 1. intestazione: nome e parametri, poi i due punti
    """Area di un rettangolo b×h."""   # 2. docstring (facoltativa ma utile)
    A = b * h                         # 3. corpo: indentato di 4 spazi
    return A                          # 4. il risultato che esce dalla funzione

print(area_rettangolo(30, 50))    # → 1500
```

1. `def` dice «sto definendo una funzione»; segue il **nome** (stesse regole delle variabili), le **parentesi** con i **parametri** e i **due punti**.
2. Tutto quello che appartiene alla funzione è **indentato** (4 spazi). Quando l'indentazione torna a sinistra, la funzione è finita.
3. `return` restituisce il risultato a chi ha chiamato e **termina** la funzione.

Definire una funzione **non** la esegue: Python la memorizza e basta. Il calcolo avviene solo quando la **chiami**, scrivendo il nome con i valori tra parentesi: `area_rettangolo(30, 50)`.

## Che cosa succede in una chiamata

Quando scrivi `area_rettangolo(30, 50)`:

1. Python entra nella funzione e assegna i valori ai parametri **nell'ordine**: `b = 30`, `h = 50`;
2. esegue il corpo: `A = 30 * 50 = 1500`;
3. incontra `return A`: esce e la chiamata **vale** `1500`.

Una chiamata è quindi un valore come un altro: si può stampare, assegnare, usare in un'altra formula.

```python
def area_rettangolo(b, h):
    return b * h

A1 = area_rettangolo(30, 50)
A2 = area_rettangolo(20, 10)
print(A1 + A2)                          # → 1700
print(area_rettangolo(2, 3) * 10)       # → 60
```

L'ordine degli argomenti conta: con i parametri `(b, h)` il primo valore va in `b`. Per non sbagliare si può anche scrivere il nome: `area_rettangolo(h=50, b=30)` (lo approfondisci nella Parte I).

## Funzioni che usano altre funzioni

Le funzioni si combinano come mattoncini. Qui la tensione di flessione usa il modulo di resistenza, che usa il momento d'inerzia:

```python
def inerzia_rett(b, h):
    """mm^4"""
    return b * h**3 / 12

def modulo_resistenza(b, h):
    """mm³: I divisa per la distanza dal baricentro al bordo"""
    return inerzia_rett(b, h) / (h / 2)

def sigma_flessione(M, b, h):
    """MPa, con M in N·mm"""
    return M / modulo_resistenza(b, h)

print(sigma_flessione(2_000_000, 30, 50))   # → 160.0
```

Ogni funzione si controlla da sola con un caso semplice (un quadrato di lato 1, una forza nulla) e poi ci si fida di lei.

## Più risultati

Una funzione può restituire più valori, separati da virgole, e chi la chiama li riceve assegnandoli a più nomi in un colpo solo (si chiama *unpacking*, lo riprendi con le tuple nella Parte I):

```python
def sezione_circolare(d):
    import math
    A = math.pi * d**2 / 4
    I = math.pi * d**4 / 64
    return A, I

area, inerzia = sezione_circolare(20)
print(f"A = {area:.1f} mm², I = {inerzia:.0f} mm^4")
```

## Variabili locali

Le variabili create dentro una funzione **esistono solo lì dentro**. Questo evita che un calcolo ne sporchi un altro.

```python
def tensione(F, A):
    sigma = F / A
    return sigma

print(tensione(10_000, 200))
# print(sigma)  -> errore: sigma esiste solo dentro la funzione
```

Nota `10_000`: il trattino basso nei numeri è solo per leggerli meglio. Una funzione invece **può leggere** i nomi definiti fuori, come le costanti:

```python
G = 9.81   # m/s²

def peso(m):
    return m * G      # G viene da fuori

print(peso(80))       # → 784.8000000000001   (i float sono approssimati)
```

È comodo per le costanti fisiche; per tutto il resto è meglio passare i dati come parametri, così la funzione dipende solo da quello che riceve.

## return vs print

`print` mostra un valore sullo schermo; `return` lo **restituisce** a chi ha chiamato la funzione, che può usarlo in altri calcoli. Una funzione senza `return` restituisce `None` («niente»).

```python
def area_con_print(b, h):
    print(b * h)          # la mostra, ma non la restituisce

def area_con_return(b, h):
    return b * h

x = area_con_print(2, 3)      # stampa 6…
print(x)                      # → None  (…ma x non vale niente)
y = area_con_return(2, 3)
print(y * 2)                  # → 12
```

Regola pratica: le funzioni di **calcolo** usano `return`; si stampa solo fuori, alla fine.

## Docstring

La stringa tra triple virgolette subito sotto `def` descrive la funzione: che cosa calcola, in che unità sono parametri e risultato. Non è obbligatoria, ma fra tre mesi ringrazierai te stesso. Gli editor la mostrano quando passi il mouse sul nome, e `help(nome)` la stampa.

> [!trappola] Dimenticare `return` è l'errore più comune: la funzione calcola, ma tu ricevi `None`. Altri due classici: dimenticare i **due punti** dopo `def ...(...)` (`SyntaxError`) e sbagliare l'**indentazione** del corpo (`IndentationError`).

> [!ing] Una piccola libreria di funzioni ben scritte (sezioni, verifiche, conversioni) diventa il tuo formulario personale: è esattamente il Progetto 1.

## Riepilogo

- `def nome(parametri):` + corpo indentato; `return` restituisce e chiude.
- Definire non esegue: si esegue chiamando `nome(valori)`.
- Gli argomenti vanno nei parametri nell'ordine; la chiamata vale il risultato.
- Le variabili interne sono locali; le costanti esterne si possono leggere.
- Calcoli con `return`, `print` solo alla fine.
