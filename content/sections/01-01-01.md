In Python **tutto è un oggetto** e le variabili sono **etichette** attaccate agli oggetti, non scatole che li contengono. `==` confronta il **valore**, `is` controlla se due nomi indicano **lo stesso oggetto**.

```python
a = [1, 2, 3]
b = a          # stessa lista, due etichette
c = [1, 2, 3]  # lista uguale ma diversa
print(a == c, a is c)   # True False
b.append(4)
print(a)                # anche a è cambiata!
```

## Etichette, non scatole: passo per passo

Immagina gli oggetti come cose appoggiate su un tavolo e i nomi come **etichette** con un filo. `a = [1, 2, 3]` crea una lista sul tavolo e le lega l'etichetta `a`. `b = a` **non** crea una seconda lista: lega una seconda etichetta alla **stessa** lista.

```python
a = [1, 2, 3]
b = a                  # due etichette, una lista
b.append(4)            # modifico «attraverso» b…
print(a)               # → [1, 2, 3, 4]   (…e lo vede anche a)
print(a is b)          # → True
c = [1, 2, 3, 4]       # una lista nuova con gli stessi valori
print(a == c, a is c)  # → True False
```

`==` chiede «hanno lo stesso valore?», `is` chiede «sono lo stesso oggetto?». Due liste possono essere uguali senza essere la stessa, come due bulloni M10 identici: uguali, ma due pezzi distinti.

## Perché con i numeri non succede

`x += 1` su un intero non modifica il numero 10 (i numeri non si possono modificare): crea il numero 11 e sposta l'etichetta `x` su di lui. L'altra etichetta resta dov'era. Con le liste invece `append` cambia **la lista stessa**, e tutte le etichette la vedono cambiata.

| Tipo | Mutabile? | Una «modifica»… |
|---|---|---|
| `int`, `float`, `str`, `tuple` | no | crea un oggetto nuovo |
| `list`, `dict`, `set` | sì | cambia l'oggetto per tutti i nomi |

## Mutabili e immutabili

Numeri, stringhe e tuple sono **immutabili**: ogni "modifica" crea un oggetto nuovo. Liste, dizionari e insiemi sono **mutabili**: si modificano sul posto e tutte le etichette vedono il cambiamento.

```python
x = 10
y = x
x += 1        # crea un nuovo int, y non cambia
print(x, y)

carichi = [5, 7]
backup = carichi.copy()   # copia esplicita
carichi.append(9)
print(carichi, backup)
```

## Quando usare is

Usa `is` solo per `None` (e per i singoli `True`/`False`):

```python
risultato = None
if risultato is None:
    print("calcolo non ancora eseguito")
```

## id e copia profonda

`id(x)` restituisce l'identità dell'oggetto. Per strutture annidate (liste di liste) `.copy()` copia solo il primo livello: serve `copy.deepcopy`.

```python
import copy
tabella = [[1, 2], [3, 4]]
superficiale = tabella.copy()
profonda = copy.deepcopy(tabella)
tabella[0][0] = 99
print(superficiale[0][0], profonda[0][0])   # 99 1
```

## Liste passate alle funzioni

Lo stesso vale quando passi una lista a una funzione: il parametro è un'altra etichetta sulla stessa lista. Se la funzione la modifica, la modifica resta.

```python
def aggiungi_peso_proprio(carichi):
    carichi.append(2.5)          # modifica la lista di chi chiama

def con_peso_proprio(carichi):
    return carichi + [2.5]       # crea una lista nuova

c = [10, 20]
nuova = con_peso_proprio(c)
print(c, nuova)                  # → [10, 20] [10, 20, 2.5]
aggiungi_peso_proprio(c)
print(c)                         # → [10, 20, 2.5]
```

Se non vuoi sorprese, nelle funzioni di calcolo **non modificare** le liste ricevute: costruiscine una nuova e restituiscila.

## Tre modi di copiare una lista

```python
originale = [5.0, 7.5, 9.0]
c1 = originale.copy()
c2 = list(originale)
c3 = originale[:]          # fetta dall'inizio alla fine
originale[0] = 0.0
print(c1, c2, c3)          # → [5.0, 7.5, 9.0] [5.0, 7.5, 9.0] [5.0, 7.5, 9.0]
```

Tutti e tre copiano il primo livello. Per liste che contengono altre liste serve `copy.deepcopy`, come visto sopra.

> [!c] Se vieni dal C: pensa ai nomi Python come a puntatori che non devi dereferenziare. Assegnare non copia mai i dati.

> [!trappola] `if x == None` funziona ma è considerato sbagliato: scrivi `if x is None`.

## Riepilogo

- I nomi sono etichette: assegnare non copia mai, lega un altro nome allo stesso oggetto.
- `==` confronta i valori, `is` l'identità; `is` si usa per `None`.
- Liste, dizionari e insiemi sono mutabili: le modifiche si vedono da tutti i nomi, anche dentro le funzioni.
- Copie: `.copy()`, `list(x)`, `x[:]`; per strutture annidate `copy.deepcopy`.
