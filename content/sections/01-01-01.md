In Python **tutto è un oggetto** e le variabili sono **etichette** attaccate agli oggetti, non scatole che li contengono. `==` confronta il **valore**, `is` controlla se due nomi indicano **lo stesso oggetto**.

```python
a = [1, 2, 3]
b = a          # stessa lista, due etichette
c = [1, 2, 3]  # lista uguale ma diversa
print(a == c, a is c)   # True False
b.append(4)
print(a)                # anche a è cambiata!
```

## Mutabili e immutabili

Numeri, stringhe e tuple sono **immutabili**: ogni "modifica" crea un oggetto nuovo. Liste, dizionari e insiemi sono **mutabili**: si modificano sul posto e tutte le etichette vedono il cambiamento.

```python
x = 10
y = x
x += 1        # crea un nuovo int, y non cambia
print(x, y)

carichi = [5, 7]
backup = carichi.copy()   # copia esplicita
carichi.append(9)
print(carichi, backup)
```

## Quando usare is

Usa `is` solo per `None` (e per i singoli `True`/`False`):

```python
risultato = None
if risultato is None:
    print("calcolo non ancora eseguito")
```

## id e copia profonda

`id(x)` restituisce l'identità dell'oggetto. Per strutture annidate (liste di liste) `.copy()` copia solo il primo livello: serve `copy.deepcopy`.

```python
import copy
tabella = [[1, 2], [3, 4]]
superficiale = tabella.copy()
profonda = copy.deepcopy(tabella)
tabella[0][0] = 99
print(superficiale[0][0], profonda[0][0])   # 99 1
```

> [!c] Se vieni dal C: pensa ai nomi Python come a puntatori che non devi dereferenziare. Assegnare non copia mai i dati.

> [!trappola] `if x == None` funziona ma è considerato sbagliato: scrivi `if x is None`.
