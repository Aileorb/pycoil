Una **tupla** è una sequenza **immutabile**, tra parentesi tonde. È perfetta per dati che vanno insieme e non devono cambiare, come le coordinate di un nodo.

```python
nodo = (1.5, 0.0, 2.0)     # x, y, z in metri
x, y, z = nodo             # unpacking
print(f"x={x} m, z={z} m")
```

L'**unpacking** assegna in un colpo solo gli elementi a più nomi.

## Scambiare e restituire più valori

```python
a, b = 3, 7
a, b = b, a          # scambio senza variabile temporanea
print(a, b)

def reazioni_appoggio(F, L, a):
    """Trave appoggiata con forza F a distanza a dall'appoggio A."""
    RB = F * a / L
    RA = F - RB
    return RA, RB     # in realtà restituisce una tupla

RA, RB = reazioni_appoggio(10, 4, 1)
print(f"RA = {RA} kN, RB = {RB} kN")
```

## Unpacking esteso con *

```python
misure = [20.1, 20.4, 20.9, 21.3, 21.0]
prima, *centrali, ultima = misure
print(prima, centrali, ultima)
```

## Tuple come chiavi

Essendo immutabili, le tuple possono fare da chiavi di un dizionario (le liste no):

```python
spostamenti = {(0, 0): 0.0, (1, 0): 1.2, (1, 1): 2.7}   # (riga, colonna) -> mm
print(spostamenti[(1, 0)])
```

> [!trappola] Una tupla con un solo elemento vuole la virgola: `(5,)`. Scritto `(5)` è solo il numero 5 tra parentesi.

> [!ing] Coordinate, coppie (forza, braccio), terne (σx, σy, τxy): quando i dati hanno un numero fisso di componenti, una tupla rende il codice più chiaro e più sicuro.
