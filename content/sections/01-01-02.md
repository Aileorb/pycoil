Una **tupla** è una sequenza **immutabile**, tra parentesi tonde. È perfetta per dati che vanno insieme e non devono cambiare, come le coordinate di un nodo.

```python
nodo = (1.5, 0.0, 2.0)     # x, y, z in metri
x, y, z = nodo             # unpacking
print(f"x={x} m, z={z} m")
```

L'**unpacking** assegna in un colpo solo gli elementi a più nomi.

## Tuple e liste: quando usare quale

Una tupla si legge come una lista (indici, fette, `len`, `in`, `for`), ma **non si può modificare**:

```python
nodo = (1.5, 0.0, 2.0)
print(nodo[0], len(nodo))      # → 1.5 3
print(2.0 in nodo)             # → True
```

```python norun
nodo[0] = 3.0     # TypeError: 'tuple' object does not support item assignment
```

| | Lista `[...]` | Tupla `(...)` |
|---|---|---|
| si modifica | sì | no |
| uso tipico | tante misure dello stesso tipo, che crescono | pochi dati di natura diversa che vanno insieme |
| esempi | letture di un sensore | (x, y, z) di un nodo, (forza, braccio) |

Le parentesi tonde sono spesso facoltative: `p = 3, 4` crea già la tupla `(3, 4)`. È quello che succede in `return RA, RB`.

## Unpacking passo per passo

A sinistra di `=` metti tanti nomi quanti sono gli elementi; Python li assegna in ordine:

```python
F, braccio = (1200, 0.35)        # N, m
print(F * braccio)               # → 420.0
larghezza, altezza, spessore = 200, 100, 8
print(altezza)                   # → 100
```

Se i numeri non tornano Python si ferma: `a, b = (1, 2, 3)` dà `ValueError: too many values to unpack`. Con l'asterisco un nome raccoglie «tutto il resto» in una lista (lo vedi più sotto, in «Unpacking esteso»).

## Scambiare e restituire più valori

```python
a, b = 3, 7
a, b = b, a          # scambio senza variabile temporanea
print(a, b)

def reazioni_appoggio(F, L, a):
    """Trave appoggiata con forza F a distanza a dall'appoggio A."""
    RB = F * a / L
    RA = F - RB
    return RA, RB     # in realtà restituisce una tupla

RA, RB = reazioni_appoggio(10, 4, 1)
print(f"RA = {RA} kN, RB = {RB} kN")
```

## Unpacking esteso con *

```python
misure = [20.1, 20.4, 20.9, 21.3, 21.0]
prima, *centrali, ultima = misure
print(prima, centrali, ultima)
```

## Unpacking nei cicli

Il caso più comune: una lista di tuple, scorsa con un `for` che dà un nome a ogni componente.

```python
forze = [(10, 1.0), (5, 2.5), (8, 4.0)]     # (kN, m dall'appoggio)
M = 0
for F, x in forze:
    M += F * x
print("momento rispetto all'appoggio:", M, "kNm")   # → momento rispetto all'appoggio: 54.5 kNm
```

È esattamente quello che fanno `enumerate` e `zip`: producono tuple, e il `for` le spacchetta.

## Una funzione che restituisce una tupla

```python
def tensioni_principali(sx, sy, txy):
    """MPa: σ1 e σ2 di uno stato piano di tensione."""
    c = (sx + sy) / 2
    r = ((sx - sy)**2 / 4 + txy**2) ** 0.5
    return c + r, c - r

s1, s2 = tensioni_principali(80, 20, 40)
print(round(s1, 1), round(s2, 1))      # → 100.0 0.0
risultato = tensioni_principali(80, 20, 40)
print(type(risultato))                 # → <class 'tuple'>
```

> [!trappola] Una tupla con un solo elemento vuole la virgola: `(5,)`. Scritto `(5)` è solo il numero 5 tra parentesi.

> [!ing] Coordinate, coppie (forza, braccio), terne (σx, σy, τxy): quando i dati hanno un numero fisso di componenti, una tupla rende il codice più chiaro e più sicuro.

## Riepilogo

- Una tupla è una sequenza immutabile: si legge come una lista, non si modifica.
- Tuple per pochi dati che vanno insieme, liste per tante misure dello stesso tipo.
- Unpacking: `a, b = coppia`; con `*resto` si raccolgono gli elementi in più.
- `for a, b in lista_di_coppie:` spacchetta a ogni giro; `return x, y` restituisce una tupla.
