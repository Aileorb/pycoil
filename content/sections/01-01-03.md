Un **dizionario** associa **chiavi** a **valori**. È il modo naturale di tenere una tabella di materiali, di proprietà o di risultati.

```python
fy = {"S235": 235, "S275": 275, "S355": 355}   # MPa
print(fy["S355"])
fy["S460"] = 460            # aggiunge una voce
for acciaio, valore in fy.items():
    print(f"{acciaio}: {valore} MPa")
```

## Come funziona un dizionario, passo per passo

Una lista si consulta per **posizione** (`l[0]`), un dizionario per **nome** (`d["S355"]`): come una rubrica, o la tabella dei materiali in fondo al libro.

```python
fy = {}                     # 1. dizionario vuoto
fy["S235"] = 235            # 2. aggiungo la chiave "S235" con valore 235
fy["S355"] = 355
print(fy)                   # → {'S235': 235, 'S355': 355}
fy["S235"] = 240            # 3. stessa chiave: il valore viene sostituito
print(fy["S235"], len(fy))  # → 240 2
```

Le chiavi sono uniche e di solito sono stringhe o numeri; i valori possono essere qualsiasi cosa, anche liste o altri dizionari.

## I metodi principali

| Scrivi | Che cosa fa |
|---|---|
| `d[k]` | valore della chiave `k` (errore se manca) |
| `d.get(k, riserva)` | valore di `k`, oppure `riserva` se manca |
| `k in d` | la chiave c'è? |
| `d.keys()`, `d.values()`, `d.items()` | chiavi, valori, coppie (chiave, valore) |
| `d.pop(k)` | toglie `k` e ne restituisce il valore |
| `d.update(altro)` | aggiunge o sostituisce le voci di un altro dizionario |

```python
E = {"acciaio": 210_000, "alluminio": 70_000, "titanio": 110_000}   # MPa
for nome in E:                       # scorrere un dizionario dà le chiavi
    print(nome)
print(sum(E.values()) / len(E))      # → 130000.0   (media dei moduli)
for nome, valore in E.items():       # chiave e valore insieme
    print(f"{nome:<10}{valore:>8} MPa")
```

## Leggere in sicurezza

Una chiave inesistente dà `KeyError`; con `.get` scegli un valore di riserva:

```python
E = {"acciaio": 210_000, "alluminio": 70_000}   # MPa
print(E.get("titanio", "non in tabella"))
print("acciaio" in E)
```

## Dizionari annidati

```python
materiali = {
    "S355": {"fy": 355, "fu": 510, "E": 210_000},
    "EN AW-6082": {"fy": 260, "fu": 310, "E": 70_000},
}
m = materiali["EN AW-6082"]
print(f"Rapporto fy/E = {m['fy'] / m['E']:.4f}")
```

## Insiemi

Un **set** è una collezione senza duplicati e senza ordine. Utilissimo per confrontare elenchi:

```python
in_magazzino = {"M8", "M10", "M12", "M16"}
richiesti = {"M10", "M12", "M20"}
print(richiesti - in_magazzino)    # cosa manca
print(richiesti & in_magazzino)    # cosa c'è
print(len({20.1, 20.1, 20.4}))     # i duplicati spariscono
```

## Tuple come chiavi

Essendo immutabili, le tuple possono fare da chiavi di un dizionario (le liste no, perché si possono modificare):

```python
spostamenti = {(0, 0): 0.0, (1, 0): 1.2, (1, 1): 2.7}   # (riga, colonna) -> mm
print(spostamenti[(1, 0)])
```

## Contare con un dizionario

Lo schema «se c'è aggiungi uno, altrimenti parti da zero» si scrive in una riga con `get`:

```python
distinta = ["M8", "M10", "M8", "M12", "M8", "M10"]
conteggio = {}
for vite in distinta:
    conteggio[vite] = conteggio.get(vite, 0) + 1
print(conteggio)          # → {'M8': 3, 'M10': 2, 'M12': 1}
```

## Un dizionario di liste

Utile per raggruppare misure per categoria:

```python
prove = {"S235": [362, 371, 358], "S355": [520, 515, 530]}   # Rm in MPa
prove["S235"].append(366)
for acciaio, valori in prove.items():
    print(acciaio, round(sum(valori) / len(valori), 1))
```

## Operazioni sugli insiemi

| Scrivi | Significa |
|---|---|
| `a \| b` | unione: in almeno uno |
| `a & b` | intersezione: in entrambi |
| `a - b` | differenza: in `a` ma non in `b` |
| `s.add(x)`, `s.discard(x)` | aggiunge, toglie |
| `set(lista)` | elimina i doppioni di una lista |

```python
codici = ["A12", "B07", "A12", "C33", "B07"]
unici = set(codici)
print(len(codici), len(unici))     # → 5 3
```

> [!c] Se vieni dal C: un dizionario è una tabella hash pronta all'uso, con chiavi di qualsiasi tipo immutabile. Dalla versione 3.7 mantiene l'ordine di inserimento.

> [!trappola] Modificare un dizionario mentre lo scorri con `for` dà errore. Scorri una copia: `for k in list(d):`.

## Riepilogo

- `{chiave: valore}`: si consulta per nome con `d[k]`; `d[k] = v` aggiunge o sostituisce.
- `get(k, riserva)` evita il `KeyError`; `in` controlla le chiavi.
- `items()` dà le coppie da spacchettare nel `for`; `values()` i soli valori.
- Contare: `d[k] = d.get(k, 0) + 1`.
- Insiemi: niente doppioni, operazioni `| & -`; `set(lista)` toglie i duplicati.
