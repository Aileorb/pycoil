Un **dizionario** associa **chiavi** a **valori**. È il modo naturale di tenere una tabella di materiali, di proprietà o di risultati.

```python
fy = {"S235": 235, "S275": 275, "S355": 355}   # MPa
print(fy["S355"])
fy["S460"] = 460            # aggiunge una voce
for acciaio, valore in fy.items():
    print(f"{acciaio}: {valore} MPa")
```

## Leggere in sicurezza

Una chiave inesistente dà `KeyError`; con `.get` scegli un valore di riserva:

```python
E = {"acciaio": 210_000, "alluminio": 70_000}   # MPa
print(E.get("titanio", "non in tabella"))
print("acciaio" in E)
```

## Dizionari annidati

```python
materiali = {
    "S355": {"fy": 355, "fu": 510, "E": 210_000},
    "EN AW-6082": {"fy": 260, "fu": 310, "E": 70_000},
}
m = materiali["EN AW-6082"]
print(f"Rapporto fy/E = {m['fy'] / m['E']:.4f}")
```

## Insiemi

Un **set** è una collezione senza duplicati e senza ordine. Utilissimo per confrontare elenchi:

```python
in_magazzino = {"M8", "M10", "M12", "M16"}
richiesti = {"M10", "M12", "M20"}
print(richiesti - in_magazzino)    # cosa manca
print(richiesti & in_magazzino)    # cosa c'è
print(len({20.1, 20.1, 20.4}))     # i duplicati spariscono
```

## Tuple come chiavi

Essendo immutabili, le tuple possono fare da chiavi di un dizionario (le liste no, perché si possono modificare):

```python
spostamenti = {(0, 0): 0.0, (1, 0): 1.2, (1, 1): 2.7}   # (riga, colonna) -> mm
print(spostamenti[(1, 0)])
```

> [!c] Se vieni dal C: un dizionario è una tabella hash pronta all'uso, con chiavi di qualsiasi tipo immutabile. Dalla versione 3.7 mantiene l'ordine di inserimento.

> [!trappola] Modificare un dizionario mentre lo scorri con `for` dà errore. Scorri una copia: `for k in list(d):`.
