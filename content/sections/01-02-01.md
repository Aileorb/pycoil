Una **comprehension** costruisce una lista in una riga: "per ogni elemento, calcola qualcosa, se vale una condizione".

```python
carichi = [5, 12, 8, 20, 3]      # kN
A = 400                          # mm²
tensioni = [F * 1000 / A for F in carichi]          # MPa
critiche = [s for s in tensioni if s > 25]
print(tensioni)
print(critiche)
```

È equivalente a un `for` con `append`, ma più corta e più leggibile.

## Dal ciclo alla comprehension, passo per passo

Una comprehension è un ciclo `for` con `append`, riscritto in una riga. Si parte da quello che già conosci:

```python
diametri = [8, 10, 12, 16]           # mm
aree = []
for d in diametri:
    aree.append(3.1416 * d**2 / 4)
print([round(a, 1) for a in aree])   # → [50.3, 78.5, 113.1, 201.1]
```

Le tre parti del ciclo diventano le tre parti della comprehension, **nell'ordine** «che cosa metto · da dove lo prendo · a quale condizione»:

```python
diametri = [8, 10, 12, 16]
aree = [3.1416 * d**2 / 4 for d in diametri]
#       ───────────────   ─────────────────
#       che cosa metto    per ogni d nella lista
print(len(aree))                       # → 4
grandi = [d for d in diametri if d >= 12]
print(grandi)                          # → [12, 16]
```

Si legge quasi in italiano: «la lista di `3.1416·d²/4` **per ogni** `d` in `diametri`». Il filtro `if` alla fine tiene solo gli elementi per cui la condizione è vera.

## Trasformare e filtrare insieme

```python
letture = ["20,1", "20,4", "", "19,9", "  20,2 "]     # testo letto da un file
valori = [float(x.strip().replace(",", ".")) for x in letture if x.strip()]
print(valori)                     # → [20.1, 20.4, 19.9, 20.2]
```

La condizione `if x.strip()` scarta le stringhe vuote (che contano come falso); per le altre si tolgono gli spazi, si sistema la virgola e si converte.

## Un if-else dentro l'espressione

Se invece di **scartare** vuoi **scegliere** il valore, l'`if … else` va **prima** del `for`:

```python
utilizzi = [0.42, 0.91, 1.08, 0.77]
esiti = ["ok" if u <= 1 else "NO" for u in utilizzi]
print(esiti)                      # → ['ok', 'ok', 'NO', 'ok']
```

Ricapitolando: `[x for x in l if c]` filtra (la lista può accorciarsi), `[a if c else b for x in l]` sceglie (stessa lunghezza).

## La forma generale

`[espressione for elemento in sequenza if condizione]`. La condizione è facoltativa.

```python
# diametri dei bulloni metrici fino a M24
diametri = [d for d in range(6, 25, 2) if d not in (14, 18, 22)]
print(diametri)
```

## Dizionari e insiemi

La stessa idea funziona con graffe:

```python
import math
aree = {d: round(math.pi * d**2 / 4, 1) for d in [8, 10, 12, 16]}
print(aree)
materiali = {"S235", "s355", "S355 "}
print({m.strip().upper() for m in materiali})
```

## Espressioni generatrici

Con le tonde non si costruisce nessuna lista: i valori vengono prodotti uno alla volta, perfetti dentro `sum`, `max`, `any`:

```python
lunghezze = [1.2, 3.5, 2.8, 4.1]   # m
peso_lineare = 26.2                # kg/m (IPE 200)
print(sum(L * peso_lineare for L in lunghezze), "kg")
print(any(L > 4 for L in lunghezze))
```

## Quando non usarla

Se la riga diventa lunga o servono più istruzioni per elemento (stampe, più calcoli intermedi), torna al ciclo normale: la leggibilità viene prima della brevità. Una comprehension annidata su tre livelli è un indovinello, non codice.

> [!trappola] Una comprehension annidata su tre livelli non è più leggibile: in quel caso torna al `for` classico.

> [!ing] "Prendi le misure valide e convertile" è una riga sola: `[float(x) for x in righe if x.strip()]`.

## Riepilogo

- `[espressione for x in sequenza]` costruisce una lista; `if condizione` in fondo filtra.
- `[a if c else b for x in sequenza]` sceglie un valore per ogni elemento.
- Con le graffe si costruiscono dizionari (`{k: v for …}`) e insiemi.
- Con le tonde dentro `sum`, `max`, `any`, `all` i valori si producono uno alla volta.
- Se diventa complicata, meglio un ciclo `for`.
