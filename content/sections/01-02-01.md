Una **comprehension** costruisce una lista in una riga: "per ogni elemento, calcola qualcosa, se vale una condizione".

```python
carichi = [5, 12, 8, 20, 3]      # kN
A = 400                          # mm²
tensioni = [F * 1000 / A for F in carichi]          # MPa
critiche = [s for s in tensioni if s > 25]
print(tensioni)
print(critiche)
```

È equivalente a un `for` con `append`, ma più corta e più leggibile.

<!-- /card -->

## La forma generale

`[espressione for elemento in sequenza if condizione]`. La condizione è facoltativa.

```python
# diametri dei bulloni metrici fino a M24
diametri = [d for d in range(6, 25, 2) if d not in (14, 18, 22)]
print(diametri)
```

## Dizionari e insiemi

La stessa idea funziona con graffe:

```python
import math
aree = {d: round(math.pi * d**2 / 4, 1) for d in [8, 10, 12, 16]}
print(aree)
materiali = {"S235", "s355", "S355 "}
print({m.strip().upper() for m in materiali})
```

## Espressioni generatrici

Con le tonde non si costruisce nessuna lista: i valori vengono prodotti uno alla volta, perfetti dentro `sum`, `max`, `any`:

```python
lunghezze = [1.2, 3.5, 2.8, 4.1]   # m
peso_lineare = 26.2                # kg/m (IPE 200)
print(sum(L * peso_lineare for L in lunghezze), "kg")
print(any(L > 4 for L in lunghezze))
```

> [!trappola] Una comprehension annidata su tre livelli non è più leggibile: in quel caso torna al `for` classico.

> [!ing] "Prendi le misure valide e convertile" è una riga sola: `[float(x) for x in righe if x.strip()]`.
