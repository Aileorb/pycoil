I parametri possono avere un **valore di default** e si possono passare **per nome**: le chiamate diventano autoesplicative.

```python
def tensione_ammissibile(fy, gamma_M=1.05):
    return fy / gamma_M

print(tensione_ammissibile(355))                 # usa il default
print(tensione_ammissibile(355, gamma_M=1.25))   # per nome
print(tensione_ammissibile(fy=235, gamma_M=1.1))
```

## Solo per nome

Un `*` nella firma obbliga a passare per nome i parametri successivi: niente più dubbi su quale numero sia quale.

```python
def molla(d, D, n, *, G=81_500):
    """Rigidezza di una molla elicoidale: d filo, D diametro medio, n spire attive."""
    return G * d**4 / (8 * D**3 * n)

print(round(molla(2, 20, 10), 2), "N/mm")
print(round(molla(2, 20, 10, G=79_000), 2), "N/mm")
```

## *args e **kwargs

`*args` raccoglie un numero variabile di argomenti posizionali, `**kwargs` quelli per nome:

```python
def risultante(*forze):
    return sum(forze)

def descrivi(nome, **proprieta):
    for k, v in proprieta.items():
        print(f"{nome}.{k} = {v}")

print(risultante(3, 4.5, -1.2))
descrivi("albero", d=30, L=450, materiale="C45")
```

> [!trappola] Mai usare una lista come default: `def f(x, storico=[])` crea **una sola** lista condivisa tra tutte le chiamate. Usa `storico=None` e dentro `if storico is None: storico = []`.

> [!ing] Coefficienti parziali, moduli elastici, densità: metterli come default con un nome esplicito rende i calcoli verificabili da chiunque legga il codice.
