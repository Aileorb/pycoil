I parametri possono avere un **valore di default** e si possono passare **per nome**: le chiamate diventano autoesplicative.

```python
def tensione_ammissibile(fy, gamma_M=1.05):
    return fy / gamma_M

print(tensione_ammissibile(355))                 # usa il default
print(tensione_ammissibile(355, gamma_M=1.25))   # per nome
print(tensione_ammissibile(fy=235, gamma_M=1.1))
```

## Argomenti per posizione e per nome

Quando chiami una funzione, gli argomenti si possono passare in due modi:

```python
def tensione_flessione(M, b, h):
    """MPa: M in N·mm, sezione b×h in mm."""
    return 6 * M / (b * h**2)

print(tensione_flessione(2_000_000, 30, 50))         # → 160.0   (per posizione: l'ordine conta)
print(tensione_flessione(b=30, h=50, M=2_000_000))   # → 160.0   (per nome: l'ordine no)
print(tensione_flessione(2_000_000, h=50, b=30))     # → 160.0   (misto: prima i posizionali)
```

Per nome è più lungo ma **non si sbaglia**: scambiare `b` e `h` in una chiamata posizionale dà un risultato diverso senza nessun errore. Regola: gli argomenti posizionali vanno **prima** di quelli per nome.

## Valori di default, passo per passo

`gamma_M=1.05` nella definizione vuol dire: «se chi chiama non lo passa, vale 1,05». I parametri con default vanno **dopo** quelli obbligatori.

```python
def verifica(sigma, fy, gamma_M=1.05):
    return sigma <= fy / gamma_M

print(verifica(320, 355))                # → True    (gamma_M vale 1.05)
print(verifica(320, 355, 1.15))          # → False   (gamma_M vale 1.15)
print(verifica(320, 355, gamma_M=1.15))  # → False   (stessa cosa, più chiaro)
```

Il default va bene per i valori «di solito questo»: coefficienti di sicurezza, unità, numero di suddivisioni di un metodo numerico.

## Solo per nome

Un `*` nella firma obbliga a passare per nome i parametri successivi: niente più dubbi su quale numero sia quale.

```python
def molla(d, D, n, *, G=81_500):
    """Rigidezza di una molla elicoidale: d filo, D diametro medio, n spire attive."""
    return G * d**4 / (8 * D**3 * n)

print(round(molla(2, 20, 10), 2), "N/mm")
print(round(molla(2, 20, 10, G=79_000), 2), "N/mm")
```

## *args e **kwargs

`*args` raccoglie un numero variabile di argomenti posizionali, `**kwargs` quelli per nome:

```python
def risultante(*forze):
    return sum(forze)

def descrivi(nome, **proprieta):
    for k, v in proprieta.items():
        print(f"{nome}.{k} = {v}")

print(risultante(3, 4.5, -1.2))
descrivi("albero", d=30, L=450, materiale="C45")
```

## La trappola del default mutabile

Il default viene calcolato **una sola volta**, quando Python legge `def`. Se è una lista, tutte le chiamate condividono **la stessa** lista:

```python
def registra(valore, storico=[]):        # da NON fare
    storico.append(valore)
    return storico

print(registra(1))          # → [1]
print(registra(2))          # → [1, 2]   (la lista è sempre la stessa!)

def registra_bene(valore, storico=None):
    if storico is None:
        storico = []        # una lista nuova a ogni chiamata
    storico.append(valore)
    return storico

print(registra_bene(1), registra_bene(2))   # → [1] [2]
```

> [!trappola] Mai usare una lista come default: `def f(x, storico=[])` crea **una sola** lista condivisa tra tutte le chiamate. Usa `storico=None` e dentro `if storico is None: storico = []`.

> [!ing] Coefficienti parziali, moduli elastici, densità: metterli come default con un nome esplicito rende i calcoli verificabili da chiunque legga il codice.

## Riepilogo

- Gli argomenti si passano per posizione (l'ordine conta) o per nome (l'ordine no); prima i posizionali.
- `parametro=valore` nella definizione dà un default; i default vanno dopo gli obbligatori.
- Dopo `*` nella firma i parametri si passano solo per nome.
- `*args` raccoglie gli argomenti in più in una tupla, `**kwargs` quelli per nome in un dizionario.
- Mai una lista o un dizionario come default: usa `None` e creali dentro.
