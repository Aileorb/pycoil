In Python le funzioni sono **valori**: si mettono in variabili, in liste, si passano ad altre funzioni. La **lambda** è una piccola funzione senza nome, scritta in una riga.

```python
profili = [("IPE 200", 194), ("HEA 160", 220), ("IPE 160", 109)]  # nome, Wx in cm³
for nome, Wx in sorted(profili, key=lambda p: p[1]):
    print(nome, Wx)
```

`key=` dice a `sorted` **in base a cosa** ordinare.

## Una funzione è un valore

Il nome di una funzione, **senza parentesi**, è la funzione stessa: un oggetto che si può assegnare a un'altra variabile, mettere in una lista, passare come argomento. Con le parentesi invece la si **chiama**.

```python
def raddoppia(x):
    return 2 * x

f = raddoppia            # nessuna chiamata: f è la stessa funzione
print(f(21))             # → 42
operazioni = [abs, round, raddoppia]
for op in operazioni:
    print(op(-2.6))      # -> 2.6, poi -3, poi -5.2
```

## lambda: una funzione in una riga

`lambda x: 2 * x` è una funzione senza nome che riceve `x` e restituisce `2 * x`. È equivalente a:

```python
def senza_nome(x):
    return 2 * x
```

ma si scrive direttamente dove serve. Può avere più parametri (`lambda b, h: b * h`) e contiene **una sola espressione**, senza `return`: il suo valore è il risultato.

```python
area = lambda b, h: b * h
print(area(30, 50))                        # → 1500
print((lambda x: x**2 + 1)(3))             # → 10
```

Usale per funzioni brevi da passare ad altre funzioni; se ti serve un nome o più righe, scrivi un `def`.

## key: ordinare in base a qualcosa

`sorted`, `min` e `max` accettano `key=`, una funzione applicata a ogni elemento per decidere **su cosa** confrontare:

```python
nomi = ["IPE 200", "HEA 160", "IPE 80"]
print(sorted(nomi))                         # → ['HEA 160', 'IPE 200', 'IPE 80']   (in ordine alfabetico)
print(sorted(nomi, key=len))                # → ['IPE 80', 'IPE 200', 'HEA 160']   (per lunghezza)
profili = [("IPE 200", 22.4), ("HEA 160", 30.4), ("IPE 160", 15.8)]   # kg/m
print(min(profili, key=lambda p: p[1]))     # → ('IPE 160', 15.8)
print(sorted(profili, key=lambda p: p[1], reverse=True)[0][0])   # → HEA 160
```

## Passare funzioni

Un integratore numerico non sa quale funzione integrare: gliela passi tu.

```python
def trapezi(f, a, b, n=1000):
    h = (b - a) / n
    return h * (f(a) / 2 + sum(f(a + i * h) for i in range(1, n)) + f(b) / 2)

# lavoro di una molla F = k x tra 0 e 30 mm (k = 2 N/mm)
print(trapezi(lambda x: 2 * x, 0, 30), "N·mm")
```

## max, min con key

```python
componenti = {"albero": 0.62, "linguetta": 0.91, "cuscinetto": 0.48}  # utilizzo
peggiore = max(componenti, key=componenti.get)
print("Componente più sollecitato:", peggiore)
```

## Tabella di formule

import math
aree = {

## Esempio: confrontare due metodi su più funzioni

Una funzione che riceve altre funzioni permette di provare lo stesso calcolo su casi diversi:

```python
import math

def errore_trapezi(f, a, b, esatto, n=10):
    h = (b - a) / n
    approx = h * (f(a) / 2 + sum(f(a + i * h) for i in range(1, n)) + f(b) / 2)
    return abs(approx - esatto)

casi = [("x²", lambda x: x**2, 1 / 3), ("sin", math.sin, 1 - math.cos(1)), ("eˣ", math.exp, math.e - 1)]
for nome, f, esatto in casi:
    print(f"{nome:4} errore con 10 trapezi: {errore_trapezi(f, 0, 1, esatto):.1e}")
```

> [!trappola] Se una lambda diventa lunga o complicata, scrivi una `def` con un nome: la leggibilità vince sempre.

> [!ing] Nella Parte IV passerai funzioni a `scipy.integrate.quad` e `scipy.optimize.minimize` esattamente così.

## Riepilogo

- Il nome di una funzione senza parentesi è un valore: si assegna, si mette in liste, si passa.
- `lambda parametri: espressione` crea una funzione breve senza nome.
- `key=` in `sorted`, `min`, `max` dice su cosa confrontare; `reverse=True` inverte l'ordine.
- Funzioni che ricevono funzioni (integratori, solutori) separano il metodo dal problema.
