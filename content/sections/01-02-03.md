In Python le funzioni sono **valori**: si mettono in variabili, in liste, si passano ad altre funzioni. La **lambda** è una piccola funzione senza nome, scritta in una riga.

```python
profili = [("IPE 200", 194), ("HEA 160", 220), ("IPE 160", 109)]  # nome, Wx in cm³
for nome, Wx in sorted(profili, key=lambda p: p[1]):
    print(nome, Wx)
```

`key=` dice a `sorted` **in base a cosa** ordinare.

## Passare funzioni

Un integratore numerico non sa quale funzione integrare: gliela passi tu.

```python
def trapezi(f, a, b, n=1000):
    h = (b - a) / n
    return h * (f(a) / 2 + sum(f(a + i * h) for i in range(1, n)) + f(b) / 2)

# lavoro di una molla F = k x tra 0 e 30 mm (k = 2 N/mm)
print(trapezi(lambda x: 2 * x, 0, 30), "N·mm")
```

## max, min con key

```python
componenti = {"albero": 0.62, "linguetta": 0.91, "cuscinetto": 0.48}  # utilizzo
peggiore = max(componenti, key=componenti.get)
print("Componente più sollecitato:", peggiore)
```

## Tabella di formule

```python
import math
aree = {
    "rettangolo": lambda b, h: b * h,
    "cerchio": lambda d: math.pi * d**2 / 4,
}
print(aree["cerchio"](20))
```

> [!trappola] Se una lambda diventa lunga o complicata, scrivi una `def` con un nome: la leggibilità vince sempre.
