I dati di laboratorio arrivano spesso in file **CSV** (valori separati da virgole o punti e virgola). Il modulo `csv` li legge riga per riga; `pathlib` gestisce i percorsi dei file in modo pulito.

```python
from pathlib import Path
import csv

Path("prova.csv").write_text("tempo_s;forza_N\n0;0\n1;120\n2;245\n3;362\n")

with open("prova.csv", newline="") as f:
    lettore = csv.DictReader(f, delimiter=";")
    for riga in lettore:
        print(float(riga["tempo_s"]), float(riga["forza_N"]))
```

## Che cos'è un CSV

Un CSV è un file di **testo** che rappresenta una tabella: una riga di testo per ogni riga della tabella, le colonne separate da un carattere (virgola, oppure punto e virgola nei programmi italiani, dove la virgola è il decimale). La prima riga di solito contiene i nomi delle colonne.

```text
tempo_s;forza_N
0;0
1;120
2;245
```

Excel lo apre come una tabella, ma per Python è testo: per fare calcoli i valori vanno **convertiti** con `float()`.

## Aprire un file, passo per passo

```python
from pathlib import Path
Path("note.txt").write_text("prima riga\nseconda riga\n")    # prepariamo un file

with open("note.txt") as f:      # 1. apre il file e lo chiama f
    testo = f.read()             # 2. legge tutto il contenuto come una stringa
print(testo.splitlines())        # → ['prima riga', 'seconda riga']

with open("note.txt") as f:
    for riga in f:               # oppure: una riga alla volta
        print(riga.strip())      # strip toglie l'a capo finale
```

`open(nome)` apre in lettura; `open(nome, "w")` in **scrittura** (e cancella il contenuto precedente!); `open(nome, "a")` in aggiunta in fondo. Il blocco `with` chiude il file da solo quando il blocco finisce.

## DictReader: ogni riga diventa un dizionario

`csv.DictReader` usa la prima riga come nomi delle colonne: ogni riga successiva diventa un dizionario `{nome_colonna: testo}`.

```python
from pathlib import Path
import csv
Path("prova.csv").write_text("tempo_s;forza_N\n0;0\n1;120\n2;245\n3;362\n")

forze = []
with open("prova.csv", newline="") as f:
    for riga in csv.DictReader(f, delimiter=";"):
        forze.append(float(riga["forza_N"]))      # da testo a numero
print(forze)                     # → [0.0, 120.0, 245.0, 362.0]
print("forza massima:", max(forze), "N")          # → forza massima: 362.0 N
```

`newline=""` è il modo raccomandato di aprire i file per il modulo `csv`; `delimiter=";"` dice qual è il separatore.

## with chiude il file per te

Il blocco `with open(...) as f:` chiude il file anche in caso di errore. È lo schema da usare **sempre**.

## Scrivere un CSV

```python
import csv
risultati = [("S235", 235, 0.68), ("S355", 355, 0.45)]
with open("verifiche.csv", "w", newline="") as f:
    w = csv.writer(f, delimiter=";")
    w.writerow(["acciaio", "fy_MPa", "utilizzo"])
    w.writerows(risultati)
print(open("verifiche.csv").read())
```

## Percorsi con pathlib

```python
from pathlib import Path
cartella = Path("dati")
cartella.mkdir(exist_ok=True)
file = cartella / "molla_01.csv"     # unisce i percorsi con /
file.write_text("x;F\n0;0\n")
print(file.name, file.suffix, file.exists())
print([p.name for p in cartella.glob("*.csv")])
```

## Esempio completo: leggere, calcolare, scrivere

Dalle misure di forza alle tensioni, salvate in un nuovo CSV:

```python
from pathlib import Path
import csv
Path("trazione.csv").write_text("forza_N;allungamento_mm\n0;0\n5000;0.05\n10000;0.10\n15000;0.16\n")
A = 78.5            # mm², provino Ø10
L0 = 50             # mm, base di misura

righe = []
with open("trazione.csv", newline="") as f:
    for r in csv.DictReader(f, delimiter=";"):
        sigma = float(r["forza_N"]) / A
        eps = float(r["allungamento_mm"]) / L0
        righe.append((round(eps, 4), round(sigma, 1)))

with open("curva.csv", "w", newline="") as f:
    w = csv.writer(f, delimiter=";")
    w.writerow(["epsilon", "sigma_MPa"])
    w.writerows(righe)
print(Path("curva.csv").read_text())
```

> [!nota] Qui nell'app i file vivono in un filesystem virtuale che sparisce quando chiudi la pagina: è normale. Sul computer i file restano.

> [!trappola] Excel in italiano esporta i CSV con il **punto e virgola** e la **virgola decimale**: `"12,5"` va convertito con `float(x.replace(",", "."))`.

> [!ing] Con pandas (Parte V) leggerai lo stesso file in una riga, ma capire `csv` ti salva quando il file è "sporco".

## Riepilogo

- Un CSV è testo: una riga per riga di tabella, colonne separate da `;` o `,`; i valori vanno convertiti.
- `with open(nome) as f:` apre e chiude da solo; `"w"` scrive (cancellando), `"a"` aggiunge.
- `csv.DictReader(f, delimiter=";")` dà un dizionario per riga; `csv.writer` scrive righe.
- `pathlib.Path` costruisce percorsi con `/`, crea cartelle, legge e scrive testo.
