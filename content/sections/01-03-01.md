I dati di laboratorio arrivano spesso in file **CSV** (valori separati da virgole o punti e virgola). Il modulo `csv` li legge riga per riga; `pathlib` gestisce i percorsi dei file in modo pulito.

```python
from pathlib import Path
import csv

Path("prova.csv").write_text("tempo_s;forza_N\n0;0\n1;120\n2;245\n3;362\n")

with open("prova.csv", newline="") as f:
    lettore = csv.DictReader(f, delimiter=";")
    for riga in lettore:
        print(float(riga["tempo_s"]), float(riga["forza_N"]))
```

## with chiude il file per te

Il blocco `with open(...) as f:` chiude il file anche in caso di errore. È lo schema da usare **sempre**.

## Scrivere un CSV

```python
import csv
risultati = [("S235", 235, 0.68), ("S355", 355, 0.45)]
with open("verifiche.csv", "w", newline="") as f:
    w = csv.writer(f, delimiter=";")
    w.writerow(["acciaio", "fy_MPa", "utilizzo"])
    w.writerows(risultati)
print(open("verifiche.csv").read())
```

## Percorsi con pathlib

```python
from pathlib import Path
cartella = Path("dati")
cartella.mkdir(exist_ok=True)
file = cartella / "molla_01.csv"     # unisce i percorsi con /
file.write_text("x;F\n0;0\n")
print(file.name, file.suffix, file.exists())
print([p.name for p in cartella.glob("*.csv")])
```

> [!nota] Qui nell'app i file vivono in un filesystem virtuale che sparisce quando chiudi la pagina: è normale. Sul computer i file restano.

> [!trappola] Excel in italiano esporta i CSV con il **punto e virgola** e la **virgola decimale**: `"12,5"` va convertito con `float(x.replace(",", "."))`.

> [!ing] Con pandas (Parte V) leggerai lo stesso file in una riga, ma capire `csv` ti salva quando il file è "sporco".
