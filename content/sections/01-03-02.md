Quando qualcosa va storto Python solleva un'**eccezione**. Con `try`/`except` la intercetti e decidi cosa fare, invece di far fermare tutto il programma.

```python
letture = ["21.5", "21,8", "n.d.", "22.1"]
valide = []
for x in letture:
    try:
        valide.append(float(x.replace(",", ".")))
    except ValueError:
        print("Lettura scartata:", x)
print(valide)
```

## Le eccezioni più comuni

| Eccezione | Quando succede |
| --- | --- |
| `ValueError` | valore del tipo giusto ma sbagliato, es. `float("abc")` |
| `TypeError` | tipo sbagliato, es. `"3" + 4` |
| `ZeroDivisionError` | divisione per zero |
| `KeyError` / `IndexError` | chiave o indice inesistente |
| `FileNotFoundError` | file che non c'è |

## Sollevare le tue eccezioni

Quando un input non ha senso fisico, **fermati subito** con un messaggio chiaro:

```python
def tensione(F, A):
    if A <= 0:
        raise ValueError(f"Area non valida: {A} mm²")
    return F / A

try:
    tensione(1000, 0)
except ValueError as e:
    print("Errore:", e)
```

## else e finally

```python
try:
    risultato = 10 / 2
except ZeroDivisionError:
    print("divisione per zero")
else:
    print("tutto ok:", risultato)    # solo se non ci sono stati errori
finally:
    print("eseguito sempre")
```

> [!trappola] `except:` da solo cattura tutto, anche gli errori di battitura nel codice: nasconde i bug. Specifica sempre il tipo di eccezione.

> [!ing] "Fallisci presto e chiaramente": una funzione di verifica che accetta un diametro negativo e restituisce un numero è più pericolosa di una che si ferma con un errore.
