Un **modulo** è un file Python con funzioni e variabili riutilizzabili. Con `import` usi i moduli della libreria standard, quelli installati con pip e quelli scritti da te.

```python
import math                       # tutto il modulo
from statistics import mean, stdev   # solo alcune funzioni
import datetime as dt             # con un nome più corto

misure = [20.1, 20.4, 20.9, 21.3]
print(mean(misure), round(stdev(misure), 3))
print(math.floor(20.9), dt.date.today().year)
```

## I tuoi moduli

Sul computer, se salvi delle funzioni in `sezioni.py`, da un altro file nella stessa cartella scrivi `import sezioni` e usi `sezioni.area_rett(30, 50)`. Qui simuliamo creando il file al volo:

```python
from pathlib import Path
Path("sezioni.py").write_text(
    "def area_rett(b, h):\n    return b * h\n"
    "def inerzia_rett(b, h):\n    return b * h**3 / 12\n"
)
import sys
sys.path.insert(0, ".")   # nell'app serve per trovare il file appena creato
import sezioni
print(sezioni.area_rett(30, 50), sezioni.inerzia_rett(30, 50))
```

## if __name__ == "__main__"

Il codice sotto questa riga parte solo quando esegui il file direttamente, non quando lo importi: ideale per le prove veloci.

```python
def verifica(sigma, amm):
    return sigma <= amm

if __name__ == "__main__":
    print(verifica(150, 160))
```

## Moduli della libreria standard da conoscere

`math`, `statistics`, `pathlib`, `csv`, `json`, `datetime`, `random`, `itertools`, `functools`, `collections`: tutti già installati con Python.

> [!trappola] Non chiamare un tuo file `math.py` o `random.py`: Python importerebbe il tuo al posto di quello standard.

> [!nota] `from modulo import *` importa tutto senza dirti cosa: evitalo, non si capisce più da dove arrivano i nomi.
