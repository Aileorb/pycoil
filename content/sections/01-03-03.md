Un **modulo** è un file Python con funzioni e variabili riutilizzabili. Con `import` usi i moduli della libreria standard, quelli installati con pip e quelli scritti da te.

```python
import math                       # tutto il modulo
from statistics import mean, stdev   # solo alcune funzioni
import datetime as dt             # con un nome più corto

misure = [20.1, 20.4, 20.9, 21.3]
print(mean(misure), round(stdev(misure), 3))
print(math.floor(20.9), dt.date.today().year)
```

## Tre modi di importare

```python
import math                    # 1. tutto il modulo: si scrive math.sqrt
print(math.sqrt(16))           # → 4.0

from math import sqrt, pi      # 2. solo alcuni nomi: si scrivono direttamente
print(sqrt(16), round(pi, 2))  # → 4.0 3.14

import statistics as st        # 3. con un soprannome
print(st.mean([1, 2, 3, 4]))   # → 2.5
```

Il primo è il più chiaro (si vede subito da dove viene ogni funzione); il secondo è comodo per due o tre nomi usati spesso; il terzo si usa per i nomi lunghi o per convenzione (`import numpy as np`, `import pandas as pd`).

Evita `from math import *`: importa decine di nomi e non sai più da dove arriva cosa.

## Libreria standard e librerie esterne

- **Libreria standard**: moduli che arrivano con Python (`math`, `csv`, `pathlib`, `statistics`, `datetime`…). Si importano e basta.
- **Librerie esterne**: NumPy, SciPy, pandas, Matplotlib… Sul tuo computer vanno installate una volta con `pip install nome` (appendice A). In questa app quelle del percorso sono già disponibili.

Se importi un modulo che non c'è ottieni `ModuleNotFoundError: No module named '…'`: o è scritto male, o va installato.

## I tuoi moduli

Sul computer, se salvi delle funzioni in `sezioni.py`, da un altro file nella stessa cartella scrivi `import sezioni` e usi `sezioni.area_rett(30, 50)`. Qui simuliamo creando il file al volo:

```python
from pathlib import Path
Path("sezioni.py").write_text(
    "def area_rett(b, h):\n    return b * h\n"
    "def inerzia_rett(b, h):\n    return b * h**3 / 12\n"
)
import sys
sys.path.insert(0, ".")   # nell'app serve per trovare il file appena creato
import sezioni
print(sezioni.area_rett(30, 50), sezioni.inerzia_rett(30, 50))
```

## if __name__ == "__main__"

Il codice sotto questa riga parte solo quando esegui il file direttamente, non quando lo importi: ideale per le prove veloci.

```python
def verifica(sigma, amm):
    return sigma <= amm

if __name__ == "__main__":
    print(verifica(150, 160))
```

## Moduli della libreria standard da conoscere

`math`, `statistics`, `pathlib`, `csv`, `json`, `datetime`, `random`, `itertools`, `functools`, `collections`: tutti già installati con Python.

## Esempio: statistica delle misure con la libreria standard

```python
from statistics import mean, median, stdev
diametri = [20.02, 19.98, 20.01, 20.05, 19.97, 20.00]   # mm
print(f"media {mean(diametri):.3f}  mediana {median(diametri):.3f}  s {stdev(diametri):.4f} mm")
```

Prima di scrivere una funzione, chiediti se esiste già nella libreria standard: spesso sì, ed è già testata.

> [!trappola] Non chiamare un tuo file `math.py` o `random.py`: Python importerebbe il tuo al posto di quello standard.

> [!nota] `from modulo import *` importa tutto senza dirti cosa: evitalo, non si capisce più da dove arrivano i nomi.

## Riepilogo

- `import modulo`, `from modulo import nome`, `import modulo as alias`; evita `import *`.
- Libreria standard sempre disponibile; le librerie esterne si installano con `pip`.
- Un tuo file `nome.py` nella stessa cartella si importa con `import nome`.
- Il codice sotto `if __name__ == "__main__":` parte solo se esegui il file direttamente.
