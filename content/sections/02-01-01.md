In Python gli operatori e le funzioni predefinite chiamano **metodi speciali** dell'oggetto: `len(x)` chiama `x.__len__()`, `a + b` chiama `a.__add__(b)`, `print(x)` usa `x.__repr__()`. Si chiamano *dunder* (double underscore). Scrivendoli, le tue classi si comportano come i tipi predefiniti.

```python
class Forza:
    def __init__(self, fx, fy):
        self.fx, self.fy = fx, fy

    def __repr__(self):
        return f"Forza({self.fx}, {self.fy})"

    def __add__(self, altra):
        return Forza(self.fx + altra.fx, self.fy + altra.fy)

print(Forza(3, 4) + Forza(1, -2))
```

## I più utili

| Metodo | Si attiva con | Esempio |
|---|---|---|
| `__repr__` | `repr(x)`, console, `print` | `Forza(3, 4)` |
| `__eq__` | `a == b` | confronto tra vettori |
| `__add__`, `__sub__`, `__mul__` | `+`, `-`, `*` | algebra dei vettori |
| `__abs__` | `abs(x)` | modulo |
| `__len__`, `__getitem__` | `len(x)`, `x[i]` | una sequenza di misure |
| `__iter__` | `for v in x` | iterare sui nodi |
| `__call__` | `x(...)` | oggetti usati come funzioni |

## Un vettore forza completo

```python
import math

class Forza:
    def __init__(self, fx, fy):
        self.fx, self.fy = float(fx), float(fy)

    def __repr__(self):
        return f"Forza({self.fx:g}, {self.fy:g})"

    def __eq__(self, altra):
        return math.isclose(self.fx, altra.fx) and math.isclose(self.fy, altra.fy)

    def __add__(self, altra):
        return Forza(self.fx + altra.fx, self.fy + altra.fy)

    def __mul__(self, k):          # Forza * numero
        return Forza(self.fx * k, self.fy * k)

    __rmul__ = __mul__             # numero * Forza

    def __abs__(self):
        return math.hypot(self.fx, self.fy)

f = 2 * Forza(3, 4) + Forza(0, -8)
print(f, abs(f), f == Forza(6, 0))
```

## Una sequenza di misure

Con `__len__` e `__getitem__` la tua classe funziona con `len`, gli indici, lo slicing e perfino il `for`:

```python
class Prova:
    def __init__(self, letture):
        self._letture = list(letture)

    def __len__(self):
        return len(self._letture)

    def __getitem__(self, i):
        return self._letture[i]

p = Prova([0.0, 1.2, 2.5, 3.1])
print(len(p), p[-1], p[1:3], max(p))
for v in p:
    print(v, end=" ")
```

> [!java] È l'equivalente di `toString()`, `equals()` e dell'overloading degli operatori che in Java non esiste: in Python basta definire il metodo giusto.

> [!trappola] Se definisci `__eq__`, Python rende l'oggetto non *hashable* (non usabile come chiave di dizionario) finché non definisci anche `__hash__`. Le dataclass con `frozen=True` lo fanno per te.
