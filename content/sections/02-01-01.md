In Python gli operatori e le funzioni predefinite chiamano **metodi speciali** dell'oggetto: `len(x)` chiama `x.__len__()`, `a + b` chiama `a.__add__(b)`, `print(x)` usa `x.__repr__()`. Si chiamano *dunder* (double underscore). Scrivendoli, le tue classi si comportano come i tipi predefiniti.

```python
class Forza:
    def __init__(self, fx, fy):
        self.fx, self.fy = fx, fy

    def __repr__(self):
        return f"Forza({self.fx}, {self.fy})"

    def __add__(self, altra):
        return Forza(self.fx + altra.fx, self.fy + altra.fy)

print(Forza(3, 4) + Forza(1, -2))
```

## Che cosa sono, in pratica

Quando scrivi `a + b`, Python non sa da solo che cosa voglia dire «sommare» due oggetti tuoi: va a cercare nella classe di `a` un metodo chiamato `__add__` e lo chiama, `a.__add__(b)`. Lo stesso per `len(x)` (`x.__len__()`), `print(x)` (`x.__repr__()`), `a == b` (`a.__eq__(b)`). Scrivendo questi metodi, i tuoi oggetti funzionano con gli operatori come i numeri e le liste.

Si chiamano *dunder* (*double underscore*) per i due trattini bassi prima e dopo il nome. `__init__` è il primo che hai incontrato.

## __repr__: come appare un oggetto

Senza `__repr__`, stampare un oggetto dà qualcosa come `<__main__.Forza object at 0x7f…>`, inutile. Con `__repr__` decidi tu:

```python
class Forza:
    def __init__(self, fx, fy):
        self.fx, self.fy = fx, fy

f = Forza(3, 4)
print(type(f).__name__)            # → Forza

class ForzaLeggibile:
    def __init__(self, fx, fy):
        self.fx, self.fy = fx, fy
    def __repr__(self):
        return f"Forza({self.fx}, {self.fy}) kN"

print(ForzaLeggibile(3, 4))        # → Forza(3, 4) kN
```

Regola: `__repr__` dovrebbe mostrare abbastanza da capire che oggetto è, idealmente come lo ricreeresti.

## __add__ passo per passo

```python
class Forza:
    def __init__(self, fx, fy):
        self.fx, self.fy = fx, fy
    def __repr__(self):
        return f"Forza({self.fx}, {self.fy})"
    def __add__(self, altra):
        return Forza(self.fx + altra.fx, self.fy + altra.fy)   # una forza NUOVA

a = Forza(3, 4)
b = Forza(1, -2)
c = a + b              # Python esegue a.__add__(b)
print(c)               # → Forza(4, 2)
print(a)               # → Forza(3, 4)   (a non è cambiata)
```

`__add__` deve **restituire** il risultato, di solito un oggetto nuovo: così `a + b` si comporta come con i numeri, senza modificare gli operandi.

## I più utili

| Metodo | Si attiva con | Esempio |
|---|---|---|
| `__repr__` | `repr(x)`, console, `print` | `Forza(3, 4)` |
| `__eq__` | `a == b` | confronto tra vettori |
| `__add__`, `__sub__`, `__mul__` | `+`, `-`, `*` | algebra dei vettori |
| `__abs__` | `abs(x)` | modulo |
| `__len__`, `__getitem__` | `len(x)`, `x[i]` | una sequenza di misure |
| `__iter__` | `for v in x` | iterare sui nodi |
| `__call__` | `x(...)` | oggetti usati come funzioni |

## Un vettore forza completo

```python
import math

class Forza:
    def __init__(self, fx, fy):
        self.fx, self.fy = float(fx), float(fy)

    def __repr__(self):
        return f"Forza({self.fx:g}, {self.fy:g})"

    def __eq__(self, altra):
        return math.isclose(self.fx, altra.fx) and math.isclose(self.fy, altra.fy)

    def __add__(self, altra):
        return Forza(self.fx + altra.fx, self.fy + altra.fy)

    def __mul__(self, k):          # Forza * numero
        return Forza(self.fx * k, self.fy * k)

    __rmul__ = __mul__             # numero * Forza

    def __abs__(self):
        return math.hypot(self.fx, self.fy)

f = 2 * Forza(3, 4) + Forza(0, -8)
print(f, abs(f), f == Forza(6, 0))
```

## Una sequenza di misure

Con `__len__` e `__getitem__` la tua classe funziona con `len`, gli indici, lo slicing e perfino il `for`:

```python
class Prova:
    def __init__(self, letture):
        self._letture = list(letture)

    def __len__(self):
        return len(self._letture)

    def __getitem__(self, i):
        return self._letture[i]

p = Prova([0.0, 1.2, 2.5, 3.1])
print(len(p), p[-1], p[1:3], max(p))
for v in p:
    print(v, end=" ")
```

## __eq__: quando due oggetti sono uguali

Senza `__eq__`, `==` confronta l'**identità**: due forze con le stesse componenti risultano diverse. Con i float conviene confrontare con una tolleranza, come nell'esempio della forza completa sopra (`math.isclose`).

> [!java] È l'equivalente di `toString()`, `equals()` e dell'overloading degli operatori che in Java non esiste: in Python basta definire il metodo giusto.

> [!trappola] Se definisci `__eq__`, Python rende l'oggetto non *hashable* (non usabile come chiave di dizionario) finché non definisci anche `__hash__`. Le dataclass con `frozen=True` lo fanno per te.

## Riepilogo

- Gli operatori chiamano metodi speciali: `a + b` → `__add__`, `len(x)` → `__len__`, `a == b` → `__eq__`.
- `__repr__` decide come appare l'oggetto stampato.
- `__add__`, `__mul__`… restituiscono un oggetto nuovo, senza modificare gli operandi.
- `__len__` e `__getitem__` fanno comportare un oggetto come una sequenza; `__iter__` lo rende percorribile con `for`.
