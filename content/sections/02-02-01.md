Una **classe** raggruppa dati e funzioni che lavorano su quei dati. Ogni oggetto creato dalla classe è un'**istanza** con i suoi attributi; i **metodi** ricevono l'istanza come primo parametro, `self`.

```python
class SezioneRettangolare:
    def __init__(self, b, h):
        self.b = b      # mm
        self.h = h      # mm

    def area(self):
        return self.b * self.h

    def inerzia(self):
        return self.b * self.h**3 / 12

s = SezioneRettangolare(30, 50)
print(s.area(), s.inerzia())
```

## __init__ e __repr__

`__init__` prepara l'oggetto appena creato. `__repr__` decide come appare quando lo stampi: senza, vedresti solo un indirizzo di memoria.

```python
class Forza:
    def __init__(self, Fx, Fy):
        self.Fx, self.Fy = Fx, Fy

    def modulo(self):
        return (self.Fx**2 + self.Fy**2) ** 0.5

    def __repr__(self):
        return f"Forza({self.Fx}, {self.Fy})"

F = Forza(3, 4)
print(F, F.modulo())
```

## Proprietà calcolate

Con `@property` un metodo si usa come un attributo, senza parentesi: il valore è sempre coerente con i dati.

```python
class Tubo:
    def __init__(self, D, s):
        self.D, self.s = D, s     # diametro esterno e spessore, mm

    @property
    def d(self):
        return self.D - 2 * self.s

tubo = Tubo(60.3, 3.2)
print(tubo.d)
tubo.s = 4
print(tubo.d)    # si aggiorna da solo
```

## Ereditarietà, con parsimonia

Una classe può estenderne un'altra ereditandone i metodi. In Python la si usa meno che in Java: spesso bastano funzioni e dataclass. La vedi per bene in «Ereditarietà e super()», dopo i metodi speciali.

> [!java] Se vieni da Java: niente `private`/`public` né getter e setter. Gli attributi sono pubblici; per convenzione quelli "interni" iniziano con `_`. Se un domani serve logica, trasformi l'attributo in `@property` senza cambiare chi lo usa.

> [!trappola] Dimenticare `self` nella firma dà `TypeError: ... takes 0 positional arguments but 1 was given`.
