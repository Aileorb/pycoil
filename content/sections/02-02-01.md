Una **classe** raggruppa dati e funzioni che lavorano su quei dati. Ogni oggetto creato dalla classe è un'**istanza** con i suoi attributi; i **metodi** ricevono l'istanza come primo parametro, `self`.

```python
class SezioneRettangolare:
    def __init__(self, b, h):
        self.b = b      # mm
        self.h = h      # mm

    def area(self):
        return self.b * self.h

    def inerzia(self):
        return self.b * self.h**3 / 12

s = SezioneRettangolare(30, 50)
print(s.area(), s.inerzia())
```

## Perché le classi

Finora dati e funzioni erano separati: una sezione era `b` e `h` sparsi in due variabili, e le funzioni `area(b, h)`, `inerzia(b, h)` dovevano riceverli ogni volta. Con dieci sezioni diverse è facile passare la `h` di una alla funzione dell'altra. Una **classe** tiene insieme i dati di un oggetto e le operazioni che lo riguardano: ogni sezione «sa» le proprie misure e sa calcolare la propria area.

La classe è lo **stampo** (il disegno tecnico); le **istanze** sono i pezzi prodotti con quello stampo, ognuno con le sue misure.

## Che cosa succede, passo per passo

```python
class SezioneRettangolare:              # 1. definisce lo stampo
    def __init__(self, b, h):           # 2. eseguito quando crei un'istanza
        self.b = b                      #    salva b dentro l'oggetto
        self.h = h

    def area(self):                     # 3. un metodo: una funzione dell'oggetto
        return self.b * self.h

s1 = SezioneRettangolare(30, 50)        # 4. crea un'istanza: chiama __init__(s1, 30, 50)
s2 = SezioneRettangolare(20, 80)
print(s1.area(), s2.area())             # → 1500 1600
print(s1.b, s2.h)                       # → 30 80
```

1. `class Nome:` definisce la classe; per convenzione il nome è in *CamelCase* (iniziali maiuscole).
2. `SezioneRettangolare(30, 50)` crea un oggetto nuovo e chiama subito `__init__`, passandogli l'oggetto appena creato come `self` e poi `30` e `50`.
3. `self.b = b` crea un **attributo**: un valore attaccato all'oggetto. Ogni istanza ha i suoi.
4. `s1.area()` chiama il metodo: Python passa `s1` come `self`, senza che tu lo scriva. Dentro, `self.b` è il `b` **di quell'istanza**.

## self, spiegato

`self` è semplicemente «l'oggetto su cui stai lavorando». `s1.area()` è un modo comodo di scrivere `SezioneRettangolare.area(s1)`:

```python
class Molla:
    def __init__(self, k):
        self.k = k               # N/mm

    def forza(self, x):
        return self.k * x        # usa la k di questa molla

m = Molla(200)
print(m.forza(3), Molla.forza(m, 3))    # → 600 600
```

Ogni metodo ha `self` come **primo** parametro, anche se non lo usa. Il nome `self` è una convenzione universale: non cambiarlo.

## Gli attributi si possono leggere e modificare

```python
class Molla:
    def __init__(self, k):
        self.k = k
    def forza(self, x):
        return self.k * x

m = Molla(200)
m.k = 250                 # modifica l'attributo
print(m.forza(2))         # → 500
m2 = Molla(100)
print(m.k, m2.k)          # → 250 100   (istanze indipendenti)
```

## __init__ e __repr__

`__init__` prepara l'oggetto appena creato. `__repr__` decide come appare quando lo stampi: senza, vedresti solo un indirizzo di memoria.

```python
class Forza:
    def __init__(self, Fx, Fy):
        self.Fx, self.Fy = Fx, Fy

    def modulo(self):
        return (self.Fx**2 + self.Fy**2) ** 0.5

    def __repr__(self):
        return f"Forza({self.Fx}, {self.Fy})"

F = Forza(3, 4)
print(F, F.modulo())
```

## Proprietà calcolate

Con `@property` un metodo si usa come un attributo, senza parentesi: il valore è sempre coerente con i dati.

```python
class Tubo:
    def __init__(self, D, s):
        self.D, self.s = D, s     # diametro esterno e spessore, mm

    @property
    def d(self):
        return self.D - 2 * self.s

tubo = Tubo(60.3, 3.2)
print(tubo.d)
tubo.s = 4
print(tubo.d)    # si aggiorna da solo
```

## Ereditarietà, con parsimonia

Una classe può estenderne un'altra ereditandone i metodi. In Python la si usa meno che in Java: spesso bastano funzioni e dataclass. La vedi per bene in «Ereditarietà e super()», dopo i metodi speciali.

## Esempio: un tirante che si verifica da solo

```python
import math

class Tirante:
    def __init__(self, d, fy, gamma_M=1.05):
        self.d = d                  # mm
        self.fy = fy                # MPa
        self.gamma_M = gamma_M

    def area(self):
        return math.pi * self.d**2 / 4

    def resistenza(self):
        """N: forza massima ammessa."""
        return self.area() * self.fy / self.gamma_M

    def verifica(self, N):
        return N <= self.resistenza()

t = Tirante(16, 355)
print(round(t.resistenza()), "N")          # → 67978 N
print(t.verifica(60_000), t.verifica(80_000))   # → True False
```

I metodi si chiamano tra loro con `self.`: `resistenza` usa `self.area()`.

> [!java] Se vieni da Java: niente `private`/`public` né getter e setter. Gli attributi sono pubblici; per convenzione quelli "interni" iniziano con `_`. Se un domani serve logica, trasformi l'attributo in `@property` senza cambiare chi lo usa.

> [!trappola] Dimenticare `self` nella firma dà `TypeError: ... takes 0 positional arguments but 1 was given`.

## Riepilogo

- La classe è lo stampo, le istanze i pezzi: `oggetto = Classe(argomenti)`.
- `__init__(self, ...)` prepara l'oggetto e salva gli attributi con `self.nome = valore`.
- I metodi hanno `self` come primo parametro; `oggetto.metodo()` lo passa da solo.
- Ogni istanza ha i suoi attributi; si leggono e modificano con `oggetto.attributo`.
- `@property` trasforma un metodo senza parametri in un attributo calcolato.
