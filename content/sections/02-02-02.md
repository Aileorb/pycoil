Quando una classe serve soprattutto a **contenere dati**, il decoratore `@dataclass` scrive per te `__init__`, `__repr__` e `__eq__`. Basta elencare i campi con il loro tipo.

```python
from dataclasses import dataclass

@dataclass
class Materiale:
    nome: str
    fy: float        # MPa
    E: float = 210_000.0
    rho: float = 7850.0   # kg/m³

s355 = Materiale("S355", 355)
print(s355)
print(s355 == Materiale("S355", 355))
```

## Che cosa ti risparmia

Una classe che contiene solo dati richiede di scrivere a mano `__init__` (che copia ogni parametro in `self`), `__repr__` (per stamparla) ed `__eq__` (per confrontarla). Con `@dataclass` basta l'elenco dei campi:

```python
from dataclasses import dataclass

class BulloneAMano:
    def __init__(self, d, classe, passo):
        self.d = d
        self.classe = classe
        self.passo = passo
    def __repr__(self):
        return f"BulloneAMano(d={self.d}, classe={self.classe!r}, passo={self.passo})"

@dataclass
class Bullone:          # stesso risultato, in quattro righe
    d: int              # mm
    classe: str
    passo: float        # mm

print(Bullone(10, "8.8", 1.5))                       # → Bullone(d=10, classe='8.8', passo=1.5)
print(Bullone(10, "8.8", 1.5) == Bullone(10, "8.8", 1.5))   # → True
```

## Come si scrive, riga per riga

- `@dataclass` sopra la classe è un **decoratore**: modifica la classe aggiungendo i metodi (i decoratori li vedrai più avanti in questa Parte).
- Ogni riga `nome: tipo` è un **campo**. Il tipo (`int`, `str`, `float`) è un'**annotazione**: documenta, ma Python non lo controlla.
- `nome: tipo = valore` dà un valore di default. Come per le funzioni, i campi con default vanno **dopo** quelli senza.

```python
from dataclasses import dataclass

@dataclass
class Profilo:
    nome: str
    A: float            # mm²
    Wx: float           # mm³
    acciaio: str = "S275"

p = Profilo("IPE 200", 2848, 194_300)
q = Profilo("HEA 160", 3877, 220_100, acciaio="S355")
print(p.acciaio, q.acciaio)        # → S275 S355
print(p.Wx / p.A)                  # → 68.22331460674157
```

## Metodi e campi calcolati

Una dataclass resta una classe: puoi aggiungere metodi.

```python
from dataclasses import dataclass, field

@dataclass
class Materiale:
    nome: str
    fy: float
    E: float = 210_000.0

    def deformazione_snervamento(self):
        return self.fy / self.E

@dataclass
class Trave:
    materiale: Materiale
    L: float               # mm
    carichi: list[float] = field(default_factory=list)   # kN

t = Trave(Materiale("S275", 275), 4000)
t.carichi.append(12.5)
print(t, f"{t.materiale.deformazione_snervamento():.5f}")
```

`field(default_factory=list)` crea una lista nuova per ogni trave: è il modo corretto di avere un default mutabile.

## Dati che non devono cambiare

Con `frozen=True` l'oggetto diventa immutabile: ideale per una tabella di materiali di riferimento.

```python
from dataclasses import dataclass

@dataclass(frozen=True)
class Acciaio:
    nome: str
    fy: float

S235 = Acciaio("S235", 235)
try:
    S235.fy = 300
except Exception as e:
    print(type(e).__name__, "-> un materiale di riferimento non si modifica")
```

## Esempio: catalogo di materiali e verifica

```python
from dataclasses import dataclass

@dataclass
class Materiale:
    nome: str
    fy: float            # MPa
    gamma_M: float = 1.05

    def resistenza_progetto(self):
        return self.fy / self.gamma_M

catalogo = [Materiale("S235", 235), Materiale("S355", 355), Materiale("EN AW-6082", 260, 1.1)]
sigma = 230      # MPa
for m in catalogo:
    esito = "ok" if sigma <= m.resistenza_progetto() else "NO"
    print(f"{m.nome:<11}{m.resistenza_progetto():7.1f} MPa  {esito}")
```

> [!ing] Nel Progetto 2 costruirai una piccola libreria con `Materiale`, `Sezione` e `Trave` proprio così: dati chiari, verifiche come metodi, test automatici.

> [!trappola] Le annotazioni (`fy: float`) non controllano niente a runtime: `Materiale("S355", "tanto")` funziona. I tipi servono a te e agli strumenti come mypy (Parte II, type hint).

## Riepilogo

- `@dataclass` + campi `nome: tipo` scrivono per te `__init__`, `__repr__`, `__eq__`.
- I campi con default vanno dopo gli altri; le annotazioni non vengono controllate.
- Si possono aggiungere metodi e `@property` come in una classe normale.
- `frozen=True` rende l'oggetto immutabile; `replace()` ne crea una copia modificata.
