Per ordinare oggetti hai due strade: dire a `sorted` **quale chiave** usare con `key=`, oppure rendere gli oggetti **confrontabili** con `order=True` nelle dataclass.

```python
from dataclasses import dataclass

@dataclass
class Componente:
    nome: str
    sigma: float      # MPa

pezzi = [Componente("albero", 180), Componente("perno", 240), Componente("staffa", 95)]
for c in sorted(pezzi, key=lambda c: c.sigma, reverse=True):
    print(f"{c.nome:<8}{c.sigma:>6.0f} MPa")
```

## Due strade, passo per passo

Per ordinare un elenco di oggetti Python deve sapere come confrontarli. Le strade sono due:

1. **Dire a `sorted` su che cosa confrontare**, con `key=`: una funzione che da ogni oggetto estrae un valore (un numero, una stringa). L'oggetto non cambia, decidi tu caso per caso.
2. **Rendere gli oggetti confrontabili**, con `order=True` nella dataclass: da quel momento `<`, `>`, `sorted`, `min`, `max` funzionano direttamente, confrontando i campi **nell'ordine in cui sono scritti**.

La prima è più flessibile (oggi per tensione, domani per nome); la seconda va bene quando esiste un ordine «naturale».

```python
from dataclasses import dataclass

@dataclass
class Componente:
    nome: str
    sigma: float

pezzi = [Componente("albero", 180), Componente("perno", 240)]
print(max(pezzi, key=lambda c: c.sigma).nome)     # → perno
print(sorted(pezzi, key=lambda c: c.nome)[0].nome)   # → albero
```

Senza `key` né `order=True`, `sorted(pezzi)` dà `TypeError: '<' not supported`: Python non sa quale componente venga prima.

## order=True

Con `order=True` la dataclass genera `<`, `<=`, `>`, `>=` confrontando i campi **nell'ordine in cui li scrivi**, come tuple:

```python
from dataclasses import dataclass, field

@dataclass(order=True)
class Verifica:
    utilizzo: float
    elemento: str = field(compare=False)   # escluso dai confronti

v = [Verifica(0.82, "trave A"), Verifica(1.07, "colonna 3"), Verifica(0.45, "controvento")]
print(max(v))
print([x.elemento for x in sorted(v)])
```

## Chiavi multiple

`key` può restituire una tupla: ordina per il primo elemento, a parità per il secondo.

```python
viti = [("M8", 8.8), ("M10", 10.9), ("M8", 10.9), ("M10", 8.8)]
print(sorted(viti, key=lambda v: (int(v[0][1:]), -v[1])))
```

## operator.attrgetter

Per chiavi semplici `operator.attrgetter` e `itemgetter` sono più leggibili delle lambda:

```python
from operator import attrgetter, itemgetter
from dataclasses import dataclass

@dataclass
class Profilo:
    nome: str
    peso: float
    Wy: float

cat = [Profilo("IPE200", 22.4, 194e3), Profilo("HEA160", 30.4, 220e3), Profilo("IPE220", 26.2, 252e3)]
leggeri_ok = sorted((p for p in cat if p.Wy >= 200e3), key=attrgetter("peso"))
print(leggeri_ok[0].nome)
print(sorted([(3, "c"), (1, "a")], key=itemgetter(0)))
```

## Esempio: scegliere il profilo più leggero che basta

```python
from dataclasses import dataclass

@dataclass(order=True)
class Profilo:
    peso: float          # kg/m: primo campo, decide l'ordine
    nome: str
    Wx: float            # cm³

catalogo = [Profilo(22.4, "IPE 200", 194), Profilo(15.8, "IPE 160", 109), Profilo(30.4, "HEA 160", 220), Profilo(18.8, "IPE 180", 146)]
W_richiesto = 140        # cm³
adatti = [p for p in catalogo if p.Wx >= W_richiesto]
print(min(adatti).nome)          # → IPE 180
```

Mettendo `peso` come primo campo, `min` restituisce il più leggero tra quelli che resistono.

> [!trappola] `sorted()` restituisce una lista nuova; `lista.sort()` ordina sul posto e restituisce `None`: `x = lista.sort()` lascia `x` vuoto.

> [!ing] "Il profilo più leggero che verifica" è il problema di ogni dimensionamento: filtro + `min(..., key=peso)`.

## Riepilogo

- `sorted(l, key=funzione)` ordina per il valore che la funzione estrae; `reverse=True` decrescente.
- `@dataclass(order=True)` rende gli oggetti confrontabili campo per campo, nell'ordine di dichiarazione.
- Chiavi multiple: `key=lambda x: (x.a, x.b)` ordina per `a` e, a parità, per `b`.
- `operator.attrgetter("campo")` è un modo compatto di scrivere `lambda x: x.campo`.
