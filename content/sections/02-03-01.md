`match` confronta un valore con una serie di **pattern** e esegue il primo che combacia. Nella forma più semplice sostituisce una catena di `if/elif` su valori fissi.

```python
def coefficiente(combinazione):
    match combinazione:
        case "SLU":
            return 1.5
        case "SLE" | "rara":
            return 1.0
        case _:
            return None   # caso di default

print(coefficiente("SLU"), coefficiente("rara"), coefficiente("boh"))
```

`|` significa "oppure", `_` cattura tutto il resto.

## Come si legge un match

```python
def unita(codice):
    match codice:            # 1. il valore da esaminare
        case "N":            # 2. primo pattern: è esattamente "N"?
            return 1
        case "kN":           # 3. altrimenti: è "kN"?
            return 1000
        case _:              # 4. altrimenti: qualsiasi altra cosa
            return None

print(unita("kN"), unita("MN"))     # → 1000 None
```

Python prova i `case` **dall'alto in basso** ed esegue solo il **primo** che combacia, poi esce dal `match`. `case _:` combacia con tutto: va messo per ultimo, come l'`else` di un `if`. Se nessun caso combacia e manca `case _`, il `match` non fa nulla.

## match o if?

Per confrontare un valore con alcune costanti, `match` e `if/elif` si equivalgono:

```python
def coeff_if(c):
    if c == "SLU":
        return 1.5
    elif c == "SLE" or c == "rara":
        return 1.0
    return None

def coeff_match(c):
    match c:
        case "SLU":
            return 1.5
        case "SLE" | "rara":
            return 1.0
        case _:
            return None

print(coeff_if("rara"), coeff_match("rara"))     # → 1.0 1.0
```

`match` diventa davvero più potente quando il valore ha una **struttura** da smontare (liste, dizionari, oggetti): lo vedi nelle prossime sezioni.

## Catturare: un nome in un pattern

Un nome scritto in un `case` (senza virgolette) non è un confronto: **cattura** il valore in quella posizione, che poi usi nel blocco. Combinato con `split()` permette di interpretare comandi di testo:

```python
def interpreta(riga):
    match riga.split():
        case ["F", valore]:               # due parole, la prima è "F"
            return f"forza di {float(valore)} N"
        case ["M", valore, unita]:        # tre parole, la prima è "M"
            return f"momento di {valore} {unita}"
        case _:
            return "comando sconosciuto"

print(interpreta("F 1200"))        # → forza di 1200.0 N
print(interpreta("M 35 kNm"))      # → momento di 35 kNm
print(interpreta("T 20"))          # → comando sconosciuto
```

## Catturare valori

Un nome nel pattern **cattura** la parte corrispondente del valore:

```python
def descrivi(comando):
    match comando.split():
        case ["sposta", asse, mm]:
            return f"Sposto lungo {asse} di {float(mm)} mm"
        case ["home"]:
            return "Ritorno all'origine"
        case _:
            return "Comando sconosciuto"

print(descrivi("sposta X 12.5"))
print(descrivi("home"))
```

## Dizionari

I pattern funzionano anche sui dizionari, per esempio sui messaggi di un sensore:

```python
lettura = {"tipo": "temperatura", "valore": 82.5, "unita": "C"}
match lettura:
    case {"tipo": "temperatura", "valore": v}:
        print("Temperatura", v)
    case {"tipo": "pressione", "valore": p}:
        print("Pressione", p)
    case {"tipo": t}:
        print("Lettura di tipo", t)
```

> [!c] Se vieni dal C: non è uno `switch`. Non c'è `break` né fall-through e, soprattutto, `match` sa **smontare** liste, dizionari e oggetti.

> [!trappola] `case soglia:` con un nome semplice non confronta con la variabile `soglia`: **cattura** qualsiasi valore. Per confrontare con una costante usa un nome con il punto, come `Limiti.MAX`, o una guardia `if`.

## Riepilogo

- `match valore:` + `case pattern:`: si esegue il primo caso che combacia, dall'alto.
- `|` unisce più alternative; `case _:` cattura tutto il resto e va per ultimo.
- Un nome nel pattern cattura il valore in quella posizione; le costanti tra virgolette si confrontano.
- I pattern di dizionario controllano solo le chiavi scritte.
