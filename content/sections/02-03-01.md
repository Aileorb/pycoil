`match` confronta un valore con una serie di **pattern** e esegue il primo che combacia. Nella forma più semplice sostituisce una catena di `if/elif` su valori fissi.

```python
def coefficiente(combinazione):
    match combinazione:
        case "SLU":
            return 1.5
        case "SLE" | "rara":
            return 1.0
        case _:
            return None   # caso di default

print(coefficiente("SLU"), coefficiente("rara"), coefficiente("boh"))
```

`|` significa "oppure", `_` cattura tutto il resto.

## Catturare valori

Un nome nel pattern **cattura** la parte corrispondente del valore:

```python
def descrivi(comando):
    match comando.split():
        case ["sposta", asse, mm]:
            return f"Sposto lungo {asse} di {float(mm)} mm"
        case ["home"]:
            return "Ritorno all'origine"
        case _:
            return "Comando sconosciuto"

print(descrivi("sposta X 12.5"))
print(descrivi("home"))
```

## Dizionari

I pattern funzionano anche sui dizionari, per esempio sui messaggi di un sensore:

```python
lettura = {"tipo": "temperatura", "valore": 82.5, "unita": "C"}
match lettura:
    case {"tipo": "temperatura", "valore": v}:
        print("Temperatura", v)
    case {"tipo": "pressione", "valore": p}:
        print("Pressione", p)
    case {"tipo": t}:
        print("Lettura di tipo", t)
```

> [!c] Se vieni dal C: non è uno `switch`. Non c'è `break` né fall-through e, soprattutto, `match` sa **smontare** liste, dizionari e oggetti.

> [!trappola] `case soglia:` con un nome semplice non confronta con la variabile `soglia`: **cattura** qualsiasi valore. Per confrontare con una costante usa un nome con il punto, come `Limiti.MAX`, o una guardia `if`.
