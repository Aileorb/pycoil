Una **guardia** `if` dopo il pattern aggiunge una condizione: il caso scatta solo se il pattern combacia **e** la condizione è vera. I **pattern di classe** controllano il tipo e insieme estraggono gli attributi.

```python
from dataclasses import dataclass

@dataclass
class Puntuale:
    F: float   # N
    x: float   # m

@dataclass
class Distribuito:
    q: float   # N/m

def descrivi(carico):
    match carico:
        case Puntuale(F=F, x=x) if F > 50_000:
            return "oltre 50 kN: verifica a fatica"
        case Puntuale(F=F, x=x):
            return f"{F/1000:.1f} kN a {x} m"
        case Distribuito(q=q):
            return f"{q/1000:.1f} kN/m"
        case _:
            raise ValueError(carico)

print(descrivi(Puntuale(12_000, 1.5)))
print(descrivi(Puntuale(60_000, 2.0)))
print(descrivi(Distribuito(4_500)))
```

## Guardie, passo per passo

Un pattern controlla la **forma** del valore; una **guardia** (`if` dopo il pattern) aggiunge una condizione sul **contenuto**. Il caso scatta solo se entrambe sono soddisfatte; se la guardia è falsa, Python prova il caso successivo.

```python
def classifica(sigma):
    match sigma:
        case s if s < 0:
            return "compressione"
        case s if s <= 235:
            return "trazione elastica"
        case _:
            return "oltre lo snervamento"

print(classifica(-40), classifica(120), classifica(300))   # → compressione trazione elastica oltre lo snervamento
```

Qui `s` cattura il numero e la guardia lo esamina. Per semplici soglie numeriche un `if/elif` è altrettanto chiaro: le guardie danno il meglio insieme ai pattern che smontano oggetti.

## Pattern di classe: tipo e attributi in un colpo

`case Puntuale(F=F, x=x):` chiede due cose: l'oggetto è un `Puntuale`? Se sì, prendi i suoi attributi `F` e `x` e mettili in due nomi. È come scrivere `isinstance(carico, Puntuale)` più due assegnazioni, ma in una riga.

```python
from dataclasses import dataclass

@dataclass
class Puntuale:
    F: float       # N
    x: float       # m

@dataclass
class Distribuito:
    q: float       # N/m
    L: float       # m

def risultante(c):
    match c:
        case Puntuale(F=F):
            return F
        case Distribuito(q=q, L=L):
            return q * L

print(risultante(Puntuale(1200, 0.5)), risultante(Distribuito(400, 3)))   # → 1200 1200
```

Non serve elencare tutti gli attributi: solo quelli che ti interessano.

## Forma posizionale

Le dataclass generano `__match_args__`, quindi puoi scrivere i campi per posizione:

```python
from dataclasses import dataclass

@dataclass
class Puntuale:
    F: float
    x: float

def momento_in_A(carico):
    match carico:
        case Puntuale(F, x):
            return F * x
    return 0

print(momento_in_A(Puntuale(10, 2.5)))
```

## Un calcolo su carichi misti

```python
from dataclasses import dataclass

@dataclass
class Puntuale:
    F: float
    x: float

@dataclass
class Distribuito:
    q: float
    a: float
    b: float     # da a a b, in m

def risultante(carichi):
    R = 0
    for c in carichi:
        match c:
            case Puntuale(F, _):
                R += c.F
            case Distribuito(q, a, b):
                R += q * (b - a)
    return R

print(risultante([Puntuale(10, 1), Distribuito(2, 0, 4), Puntuale(5, 3)]), "kN")
```

> [!c] Se vieni dal C: niente `break` né fall-through: vince il primo `case` che combacia e `case _` fa da `default`. In più `match` smonta l'oggetto e ne estrae i campi.

> [!trappola] `Puntuale(F, x)` senza nomi richiede `__match_args__`. Le `dataclass` lo generano da sole; le classi scritte a mano no.

## Riepilogo

- Una guardia `case pattern if condizione:` aggiunge un controllo sul contenuto.
- `case Classe(attr=nome):` controlla il tipo ed estrae gli attributi.
- Con le dataclass si può scrivere per posizione: `case Puntuale(F, x):`.
- L'ordine dei casi conta: i più specifici (con guardia) prima di quelli generali.
