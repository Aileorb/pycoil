Una **guardia** `if` dopo il pattern aggiunge una condizione: il caso scatta solo se il pattern combacia **e** la condizione è vera. I **pattern di classe** controllano il tipo e insieme estraggono gli attributi.

```python
from dataclasses import dataclass

@dataclass
class Puntuale:
    F: float   # N
    x: float   # m

@dataclass
class Distribuito:
    q: float   # N/m

def descrivi(carico):
    match carico:
        case Puntuale(F=F, x=x) if F > 50_000:
            return "oltre 50 kN: verifica a fatica"
        case Puntuale(F=F, x=x):
            return f"{F/1000:.1f} kN a {x} m"
        case Distribuito(q=q):
            return f"{q/1000:.1f} kN/m"
        case _:
            raise ValueError(carico)

print(descrivi(Puntuale(12_000, 1.5)))
print(descrivi(Puntuale(60_000, 2.0)))
print(descrivi(Distribuito(4_500)))
```

## Forma posizionale

Le dataclass generano `__match_args__`, quindi puoi scrivere i campi per posizione:

```python
from dataclasses import dataclass

@dataclass
class Puntuale:
    F: float
    x: float

def momento_in_A(carico):
    match carico:
        case Puntuale(F, x):
            return F * x
    return 0

print(momento_in_A(Puntuale(10, 2.5)))
```

## Un calcolo su carichi misti

```python
from dataclasses import dataclass

@dataclass
class Puntuale:
    F: float
    x: float

@dataclass
class Distribuito:
    q: float
    a: float
    b: float     # da a a b, in m

def risultante(carichi):
    R = 0
    for c in carichi:
        match c:
            case Puntuale(F, _):
                R += c.F
            case Distribuito(q, a, b):
                R += q * (b - a)
    return R

print(risultante([Puntuale(10, 1), Distribuito(2, 0, 4), Puntuale(5, 3)]), "kN")
```

> [!c] Se vieni dal C: niente `break` né fall-through: vince il primo `case` che combacia e `case _` fa da `default`. In più `match` smonta l'oggetto e ne estrae i campi.

> [!trappola] `Puntuale(F, x)` senza nomi richiede `__match_args__`. Le `dataclass` lo generano da sole; le classi scritte a mano no.
