`match` riconosce anche la **forma di una sequenza**: quanti elementi ha e cosa contengono. È perfetto per smontare righe di testo di un log o comandi.

```python
def leggi(riga):
    match riga.split():
        case ["T", valore]:
            return ("temperatura", float(valore))
        case ["F", fx, fy]:
            return ("forza", float(fx), float(fy))
        case []:
            return None
        case _:
            raise ValueError(f"riga non riconosciuta: {riga!r}")

for r in ["T 21.5", "F 120 -40", ""]:
    print(leggi(r))
```

## Il resto con *

`*resto` cattura tutti gli elementi rimanenti, come nell'unpacking:

```python
def serie(riga):
    match riga.split(";"):
        case [nome, *valori] if valori:
            v = [float(x) for x in valori]
            return nome, sum(v) / len(v)
        case [nome]:
            return nome, None

print(serie("estensimetro_1;102;98;101"))
print(serie("estensimetro_2"))
```

## Combinare letterali, tipi e alternative

```python
def evento(e):
    match e:
        case ("start" | "avvio", tempo):
            return f"inizio a t={tempo}"
        case ("stop", tempo) if tempo > 0:
            return f"fine a t={tempo}"
        case (str(tipo), int() | float()):
            return f"evento sconosciuto: {tipo}"

print(evento(("avvio", 0)))
print(evento(("stop", 12.5)))
print(evento(("rottura", 8)))
```

`int() | float()` accetta un numero di uno dei due tipi; `str(tipo)` controlla il tipo **e** cattura.

## Un log di prova

```python
log = """START 0
LOAD 0.5 1200
LOAD 1.0 2350
PAUSE
LOAD 1.5 3410
STOP 2.0"""

carichi = []
for riga in log.splitlines():
    match riga.split():
        case ["LOAD", t, F]:
            carichi.append((float(t), float(F)))
        case ["START" | "STOP", t]:
            print("evento", riga.split()[0], "a", t, "s")
        case ["PAUSE"]:
            pass
print(carichi)
```

> [!trappola] Una stringa **non** combacia con un pattern di sequenza: `case [a, b]` su `"ab"` non scatta, proprio per evitare sorprese. Per questo si fa `match riga.split()`.
