Un **generatore** è una funzione che usa `yield` invece di `return`: produce i valori **uno alla volta**, solo quando servono. Non tiene tutto in memoria, quindi va bene anche per file enormi o sequenze infinite.

```python
def passi_di_carico(F_max, n):
    """Rampa di carico da 0 a F_max in n passi."""
    for i in range(1, n + 1):
        yield F_max * i / n

for F in passi_di_carico(1000, 4):
    print(F)
```

## Come funziona

`for` chiama `iter()` sull'oggetto e poi `next()` finché non arriva `StopIteration`. Un generatore fa tutto da solo e si ferma nel punto del `yield`, riprendendo da lì alla chiamata successiva.

```python
g = passi = (x * x for x in range(3))   # espressione generatrice
print(next(g), next(g), next(g))
try:
    next(g)
except StopIteration:
    print("finito")
```

## Pipeline di dati

I generatori si concatenano: ogni stadio prende il precedente. Niente liste intermedie.

```python
testo = """# prova 7
0;0
0,5;120

1;ERR
1,5;365"""

def righe_utili(righe):
    for r in righe:
        r = r.strip()
        if r and not r.startswith("#"):
            yield r

def coppie(righe):
    for r in righe:
        t, F = r.replace(",", ".").split(";")
        try:
            yield float(t), float(F)
        except ValueError:
            continue

dati = coppie(righe_utili(testo.splitlines()))
print(max(dati, key=lambda c: c[1]))
```

Con un file vero basterebbe passare `open("prova.csv")`: il file viene letto una riga alla volta.

## itertools

```python
from itertools import accumulate, pairwise, islice, count

spostamenti = [0.0, 0.4, 0.9, 1.1]
print(list(pairwise(spostamenti)))                        # tratti consecutivi
print([round(b - a, 2) for a, b in pairwise(spostamenti)])
print(list(accumulate([3, 5, 2])))                        # somme cumulate
print(list(islice(count(0, 0.25), 5)))                    # i primi 5 di una sequenza infinita
```

> [!trappola] Un generatore si consuma una volta sola: dopo averlo scorso, un secondo `for` non produce nulla. Se ti servono i dati due volte, salvali in una lista.

> [!ing] I log delle macchine di prova arrivano a milioni di righe: leggerli con un generatore evita di riempire la memoria.
