Un **decoratore** è una funzione che riceve una funzione e ne restituisce una versione arricchita. La sintassi `@decoratore` sopra `def` è una scorciatoia per `f = decoratore(f)`. Lo usi già: `@dataclass`, `@property`.

```python
import time
from functools import wraps

def cronometra(f):
    @wraps(f)
    def interna(*args, **kwargs):
        t0 = time.perf_counter()
        risultato = f(*args, **kwargs)
        print(f"{f.__name__}: {(time.perf_counter() - t0) * 1000:.2f} ms")
        return risultato
    return interna

@cronometra
def somma_quadrati(n):
    return sum(i * i for i in range(n))

print(somma_quadrati(200_000))
```

## lru_cache: ricordare i risultati

`functools.lru_cache` memorizza i risultati già calcolati: utile per funzioni costose chiamate con gli stessi argomenti.

```python
from functools import lru_cache

@lru_cache(maxsize=None)
def coeff_binomiale(n, k):
    if k in (0, n):
        return 1
    return coeff_binomiale(n - 1, k - 1) + coeff_binomiale(n - 1, k)

print(coeff_binomiale(40, 20))
print(coeff_binomiale.cache_info())
```

## Decoratori con parametri

Un livello in più: una funzione che **crea** il decoratore.

```python
from functools import wraps

def intervallo(minimo, massimo):
    def decoratore(f):
        @wraps(f)
        def interna(x):
            if not minimo <= x <= massimo:
                raise ValueError(f"{f.__name__}: {x} fuori da [{minimo}, {massimo}]")
            return f(x)
        return interna
    return decoratore

@intervallo(0, 1)
def efficienza_carnot_inversa(eta):
    return 1 / eta

print(efficienza_carnot_inversa(0.4))
try:
    efficienza_carnot_inversa(1.3)
except ValueError as e:
    print(e)
```

## Altri strumenti di functools

```python
from functools import partial, reduce

def tensione(N, A, gamma=1.0):
    return N / A * gamma

tensione_progetto = partial(tensione, gamma=1.5)   # fissa un argomento
print(tensione_progetto(30_000, 200))
print(reduce(lambda a, b: a * b, [1.1, 1.2, 1.05]))  # prodotto dei coefficienti
```

> [!trappola] Senza `@wraps(f)` la funzione decorata perde nome e docstring (`__name__` diventa `"interna"`), e messaggi d'errore e documentazione diventano confusi.

> [!nota] `lru_cache` funziona solo con argomenti *hashable*: numeri, stringhe, tuple sì; liste e array NumPy no.
