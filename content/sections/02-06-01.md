I **type hint** sono annotazioni facoltative che dicono quale tipo ti aspetti per argomenti e risultato. Python non li controlla durante l'esecuzione, ma editor e strumenti come **mypy** sì: trovano errori prima di eseguire il codice e rendono il completamento automatico molto più utile.

```python
def tensione(N: float, A: float) -> float:
    """Tensione normale in MPa (N in newton, A in mm²)."""
    return N / A

print(tensione(12_000, 80))
print(tensione.__annotations__)
```

## Collezioni e valori opzionali

```python
def media(valori: list[float]) -> float:
    return sum(valori) / len(valori)

def cerca(catalogo: dict[str, float], nome: str) -> float | None:
    return catalogo.get(nome)

moduli: dict[str, float] = {"acciaio": 210e3, "alluminio": 70e3}
print(media([1.0, 2.0, 4.0]), cerca(moduli, "titanio"))
```

`float | None` significa "un float oppure `None`": chi chiama sa che deve gestire il caso mancante.

## Dataclass e alias di tipo

```python
from dataclasses import dataclass

type Punto = tuple[float, float]       # alias (Python 3.12+)

@dataclass
class Asta:
    i: Punto
    j: Punto
    A: float

    def lunghezza(self) -> float:
        (x1, y1), (x2, y2) = self.i, self.j
        return ((x2 - x1) ** 2 + (y2 - y1) ** 2) ** 0.5

print(Asta((0, 0), (3, 4), 100).lunghezza())
```

## Funzioni come argomenti

```python
from collections.abc import Callable

def bisezione(f: Callable[[float], float], a: float, b: float, tol: float = 1e-9) -> float:
    while b - a > tol:
        m = (a + b) / 2
        a, b = (m, b) if f(a) * f(m) > 0 else (a, m)
    return (a + b) / 2

print(round(bisezione(lambda x: x**3 - 2, 0, 2), 6))
```

## Controllare con mypy

Sul computer:

```bash
pip install mypy
mypy calcoli.py
```

```python norun
def area(b: float, h: float) -> float:
    return b * h

area("10", 5)   # mypy: Argument 1 has incompatible type "str"; expected "float"
```

> [!c] Somigliano alle dichiarazioni di tipo del C, ma sono **solo informative**: `tensione("a", 1)` viene comunque eseguita (e fallisce dentro la funzione).

> [!ing] Nei progetti che durano mesi, o che passano a un collega, i type hint sono documentazione che non invecchia: l'editor ti avvisa se la usi male.
