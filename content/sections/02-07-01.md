Tre strumenti trasformano un insieme di script in un lavoro serio: un **ambiente virtuale** per le librerie del progetto, **Jupyter** per esplorare e documentare, **pytest** per essere sicuri che i calcoli restino giusti.

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install numpy matplotlib pytest jupyterlab
pip freeze > requirements.txt
```

## Ambiente virtuale

Ogni progetto ha la sua cartella `.venv` con le versioni delle librerie che usa. `requirements.txt` permette a chiunque (anche a te tra un anno) di ricreare lo stesso ambiente con `pip install -r requirements.txt`.

Struttura consigliata:

```text
trave/
├── .venv/              (non va su Git)
├── trave.py            il tuo modulo
├── test_trave.py       i test
├── esplorazione.ipynb  il notebook
└── requirements.txt
```

## pytest

Un test è una funzione che inizia con `test_` e contiene `assert`. pytest li trova da solo.

```python
# test_trave.py — puoi provarlo anche qui: le funzioni sono normali funzioni Python
import math
from pytest import approx

def freccia_mezzeria(q, L, EI):
    return 5 * q * L**4 / (384 * EI)

def test_freccia_nota():
    assert freccia_mezzeria(1, 1, 5 / 384) == approx(1)

def test_proporzionale_al_carico():
    assert freccia_mezzeria(2, 3, 1) == approx(2 * freccia_mezzeria(1, 3, 1))

test_freccia_nota(); test_proporzionale_al_carico()
print("test superati")
```

Sul computer:

```bash
pytest -q          # tutti i test
pytest -q -k freccia   # solo quelli che contengono "freccia"
```

`approx` confronta i float con una tolleranza: mai `==` tra numeri calcolati.

## Jupyter

```bash
jupyter lab
```

Un notebook alterna celle di codice e di testo (Markdown con formule `$\sigma = N/A$`). Ottimo per esercitazioni e relazioni; quando una funzione diventa stabile, spostala in un modulo `.py` e importala nel notebook.

## Git in due minuti

```bash
git init
echo ".venv/" > .gitignore
git add .
git commit -m "Prima versione del calcolo della trave"
```

> [!desktop] Questa sezione si fa al computer: i comandi vanno nel terminale. I progetti di PyCoil usano esattamente questo flusso.

> [!trappola] Se `pip install` "funziona" ma poi `import numpy` fallisce, quasi sempre l'ambiente virtuale non è attivo, o l'editor usa un altro interprete: in VS Code scegli l'interprete `.venv` in basso a destra.
