**Vettorizzare** vuol dire scrivere il calcolo sull'intero array, come in una formula. Il **broadcasting** permette di combinare array di forme diverse: uno scalare, un vettore riga, un vettore colonna.

```python
import numpy as np
# freccia di una trave appoggiata con carico distribuito, in 9 punti
q, L, E, I = 5.0, 4000.0, 210_000.0, 1.94e7   # N/mm, mm, MPa, mm^4
x = np.linspace(0, L, 9)
v = q * x * (L**3 - 2 * L * x**2 + x**3) / (24 * E * I)
print(v.round(2))
print("freccia massima:", v.max().round(2), "mm")
```

## Vettorizzare: pensare per array

«Vettorizzare» significa scrivere l'operazione su tutto l'array invece che in un ciclo. Il codice è più corto e, soprattutto, **molto più veloce**: il ciclo vero gira dentro NumPy, in C.

```python
import numpy as np
x = np.linspace(0, 4, 5)        # m, 5 punti lungo una trave
L, q = 4.0, 10.0                # m, kN/m
M = q * x * (L - x) / 2         # momento in ogni punto, una formula sola
print(x)                         # → [0. 1. 2. 3. 4.]
print(M)                         # → [ 0. 15. 20. 15.  0.]
```

La formula è identica a quella del quaderno: `x` è un array, quindi anche `M` lo è.

## Broadcasting, passo per passo

Quando le forme degli array sono diverse, NumPy prova ad «allargare» quello più piccolo. La regola: si confrontano le dimensioni partendo da destra; sono compatibili se sono **uguali** o se una delle due vale **1**.

```python
import numpy as np
diametri = np.array([10, 12, 16])            # forma (3,)
forze = np.array([[1000], [5000]])           # forma (2, 1): una colonna
sigma = forze / (np.pi * diametri**2 / 4)    # forma (2, 3): ogni forza con ogni diametro
print(sigma.shape)                            # → (2, 3)
print(sigma.round(1))
```

La colonna di 2 forze e la riga di 3 diametri diventano una tabella 2×3: riga = forza, colonna = diametro. Senza broadcasting servirebbero due cicli annidati.

## Riduzioni con axis

Le «riduzioni» (`sum`, `mean`, `max`…) collassano l'array in meno numeri. Su una tabella, `axis` dice **lungo quale direzione**:

```python
import numpy as np
T = np.array([[1, 2, 3],
              [4, 5, 6]])
print(T.sum())           # → 21   (tutto)
print(T.sum(axis=0))     # → [5 7 9]   (lungo le righe: una somma per colonna)
print(T.sum(axis=1))     # → [ 6 15]   (lungo le colonne: una per riga)
```

## Broadcasting in una tabella

Un vettore colonna contro un vettore riga produce una tabella di tutte le combinazioni:

```python
import numpy as np
diametri = np.array([16, 20, 24])[:, None]      # colonna (3, 1), mm
forze = np.array([10, 20, 30, 40]) * 1000       # riga (4,), N
tau = forze / (np.pi * diametri**2 / 4)          # tabella (3, 4), MPa
print(tau.round(1))
```

Ogni riga è un diametro, ogni colonna una forza: zero cicli.

## Funzioni universali

`np.sqrt`, `np.sin`, `np.exp`, `np.abs`, `np.maximum`... lavorano elemento per elemento.

```python
import numpy as np
sx, sy, txy = np.array([120, 80]), np.array([-40, 30]), np.array([50, 10])   # MPa
s_vm = np.sqrt(sx**2 - sx * sy + sy**2 + 3 * txy**2)   # von Mises
print(s_vm.round(1))
```

## Riduzioni

`sum`, `mean`, `max`, `argmax` con `axis=` lavorano per righe o per colonne:

```python
import numpy as np
T = np.array([[20.1, 21.4, 23.0],
              [19.8, 21.0, 22.7]])   # 2 sensori × 3 istanti
print(T.mean(axis=0))   # media dei sensori per ogni istante
print(T.max(axis=1))    # massimo per ogni sensore
```

> [!trappola] Il broadcasting allinea le dimensioni **da destra**: `(3,)` con `(3, 1)` dà `(3, 3)`, che forse non volevi. Controlla sempre `.shape`.

## Riepilogo

- Vettorizzare: una formula sugli array al posto del ciclo; più corto e molto più veloce.
- Broadcasting: dimensioni confrontate da destra, compatibili se uguali o 1; colonna × riga = tabella.
- Funzioni universali (`np.sin`, `np.exp`, `np.sqrt`) lavorano elemento per elemento.
- Riduzioni: `sum`, `mean`, `max`, `argmax`; `axis=0` per colonna, `axis=1` per riga.
