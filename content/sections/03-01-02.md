**Vettorizzare** vuol dire scrivere il calcolo sull'intero array, come in una formula. Il **broadcasting** permette di combinare array di forme diverse: uno scalare, un vettore riga, un vettore colonna.

```python
import numpy as np
# freccia di una trave appoggiata con carico distribuito, in 9 punti
q, L, E, I = 5.0, 4000.0, 210_000.0, 1.94e7   # N/mm, mm, MPa, mm^4
x = np.linspace(0, L, 9)
v = q * x * (L**3 - 2 * L * x**2 + x**3) / (24 * E * I)
print(v.round(2))
print("freccia massima:", v.max().round(2), "mm")
```

## Broadcasting in una tabella

Un vettore colonna contro un vettore riga produce una tabella di tutte le combinazioni:

```python
import numpy as np
diametri = np.array([16, 20, 24])[:, None]      # colonna (3, 1), mm
forze = np.array([10, 20, 30, 40]) * 1000       # riga (4,), N
tau = forze / (np.pi * diametri**2 / 4)          # tabella (3, 4), MPa
print(tau.round(1))
```

Ogni riga è un diametro, ogni colonna una forza: zero cicli.

## Funzioni universali

`np.sqrt`, `np.sin`, `np.exp`, `np.abs`, `np.maximum`... lavorano elemento per elemento.

```python
import numpy as np
sx, sy, txy = np.array([120, 80]), np.array([-40, 30]), np.array([50, 10])   # MPa
s_vm = np.sqrt(sx**2 - sx * sy + sy**2 + 3 * txy**2)   # von Mises
print(s_vm.round(1))
```

## Riduzioni

`sum`, `mean`, `max`, `argmax` con `axis=` lavorano per righe o per colonne:

```python
import numpy as np
T = np.array([[20.1, 21.4, 23.0],
              [19.8, 21.0, 22.7]])   # 2 sensori × 3 istanti
print(T.mean(axis=0))   # media dei sensori per ogni istante
print(T.max(axis=1))    # massimo per ogni sensore
```

> [!trappola] Il broadcasting allinea le dimensioni **da destra**: `(3,)` con `(3, 1)` dà `(3, 3)`, che forse non volevi. Controlla sempre `.shape`.
