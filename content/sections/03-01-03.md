Oltre allo slicing delle liste, NumPy permette di selezionare elementi con una **maschera booleana**: un array di `True`/`False` della stessa forma.

```python
import numpy as np
tensioni = np.array([120, 185, 90, 240, 160, 210])   # MPa
fy = 235 / 1.05
critiche = tensioni > 0.8 * fy        # maschera
print(critiche)
print(tensioni[critiche])             # solo quelle critiche
print(np.count_nonzero(critiche), "elementi oltre l'80%")
```

## Matrici

```python
import numpy as np
K = np.arange(16).reshape(4, 4)
print(K[1, 2])        # riga 1, colonna 2
print(K[:, 0])        # prima colonna
print(K[1:3, 1:3])    # blocco centrale
print(K[[0, 3]][:, [0, 3]])   # righe e colonne 0 e 3
```

Estrarre un blocco di una matrice di rigidezza (i gradi di libertà liberi) è esattamente questo.

## Modificare con una maschera

```python
import numpy as np
letture = np.array([21.3, -999, 22.0, 21.8, -999, 22.4])
letture[letture == -999] = np.nan        # segna i dati mancanti
print(np.nanmean(letture).round(2))      # media ignorando i NaN
```

## np.where

Sceglie elemento per elemento tra due valori:

```python
import numpy as np
utilizzo = np.array([0.42, 0.97, 1.08, 0.66])
esito = np.where(utilizzo <= 1, "ok", "NO")
print(esito)
```

> [!trappola] Con le maschere si usano `&`, `|` e `~` con le parentesi: `(a > 0) & (a < 10)`. Scrivere `a > 0 and a < 10` dà errore.

> [!ing] Filtrare i dati di una prova (solo il tratto elastico, solo le letture valide) diventa una riga.
