Oltre allo slicing delle liste, NumPy permette di selezionare elementi con una **maschera booleana**: un array di `True`/`False` della stessa forma.

```python
import numpy as np
tensioni = np.array([120, 185, 90, 240, 160, 210])   # MPa
fy = 235 / 1.05
critiche = tensioni > 0.8 * fy        # maschera
print(critiche)
print(tensioni[critiche])             # solo quelle critiche
print(np.count_nonzero(critiche), "elementi oltre l'80%")
```

## Indici e fette come le liste

Su un array monodimensionale indici e fette funzionano come sulle liste (partono da 0, la fine è esclusa):

```python
import numpy as np
v = np.array([10, 20, 30, 40, 50])
print(v[0], v[-1])        # → 10 50
print(v[1:4])             # → [20 30 40]
print(v[::2])             # → [10 30 50]
```

Una differenza importante: la fetta di un array **non è una copia**, ma una «vista» sugli stessi dati. Modificarla modifica l'originale. Se ti serve indipendente, usa `.copy()`.

## Maschere booleane, passo per passo

Un confronto su un array dà un array di `True`/`False`, uno per elemento: la **maschera**. Usata come indice, tiene solo gli elementi dove vale `True`.

```python
import numpy as np
sigma = np.array([120, 250, 180, 300, 90])   # MPa
fy = 235
maschera = sigma > fy
print(maschera)                 # → [False  True False  True False]
print(sigma[maschera])          # → [250 300]
print(maschera.sum())           # → 2   (True conta come 1)
print(sigma[sigma <= fy].mean())   # → 130.0
```

Le condizioni si combinano con `&` (e) e `|` (o), mettendo ogni confronto **tra parentesi**: `sigma[(sigma > 100) & (sigma < 200)]`. `and` e `or` non funzionano sugli array.

## Matrici

```python
import numpy as np
K = np.arange(16).reshape(4, 4)
print(K[1, 2])        # riga 1, colonna 2
print(K[:, 0])        # prima colonna
print(K[1:3, 1:3])    # blocco centrale
print(K[[0, 3]][:, [0, 3]])   # righe e colonne 0 e 3
```

Estrarre un blocco di una matrice di rigidezza (i gradi di libertà liberi) è esattamente questo.

## Modificare con una maschera

```python
import numpy as np
letture = np.array([21.3, -999, 22.0, 21.8, -999, 22.4])
letture[letture == -999] = np.nan        # segna i dati mancanti
print(np.nanmean(letture).round(2))      # media ignorando i NaN
```

## np.where

Sceglie elemento per elemento tra due valori:

```python
import numpy as np
utilizzo = np.array([0.42, 0.97, 1.08, 0.66])
esito = np.where(utilizzo <= 1, "ok", "NO")
print(esito)
```

> [!trappola] Con le maschere si usano `&`, `|` e `~` con le parentesi: `(a > 0) & (a < 10)`. Scrivere `a > 0 and a < 10` dà errore.

> [!ing] Filtrare i dati di una prova (solo il tratto elastico, solo le letture valide) diventa una riga.

## Riepilogo

- Indici e fette come le liste, ma la fetta è una vista: `.copy()` per un array indipendente.
- Matrici: `M[riga, colonna]`, `M[:, j]` colonna, `M[i, :]` riga.
- Un confronto dà una maschera booleana; `a[maschera]` filtra; `maschera.sum()` conta.
- Condizioni combinate con `&` e `|` tra parentesi; `np.where(cond, a, b)` sceglie elemento per elemento.
