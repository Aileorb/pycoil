Molti problemi dell'ingegneria si riducono a un **sistema lineare** `A x = b`. Con NumPy si risolve con `np.linalg.solve`, senza invertire la matrice.

```python
import numpy as np
# due molle in serie (k1, k2) fissate a un estremo, forza F sul nodo finale
k1, k2, F = 1000.0, 500.0, 200.0           # N/mm, N
K = np.array([[k1 + k2, -k2],
              [-k2,      k2]])
f = np.array([0.0, F])
u = np.linalg.solve(K, f)
print("spostamenti dei nodi:", u.round(3), "mm")
```

## Una travatura reticolare

Due aste concorrono in un nodo caricato: l'equilibrio delle forze nel nodo dà un sistema lineare nelle forze delle aste.

```python
import numpy as np
# nodo C collegato a due appoggi con aste inclinate di 30° e 60° rispetto all'orizzontale
# carico verticale P verso il basso. Incognite: N1, N2 (trazione positiva)
P = 10.0  # kN
a1, a2 = np.radians(150), np.radians(60)   # direzioni delle aste uscenti dal nodo
A = np.array([[np.cos(a1), np.cos(a2)],
              [np.sin(a1), np.sin(a2)]])
b = np.array([0.0, P])
N = np.linalg.solve(A, b)
print("N1 = %.2f kN, N2 = %.2f kN" % tuple(N))
```

## Controllare la soluzione

```python
import numpy as np
A = np.array([[4.0, -2.0, 0.0], [-2.0, 4.0, -2.0], [0.0, -2.0, 2.0]])
b = np.array([0.0, 0.0, 1.0])
x = np.linalg.solve(A, b)
print(x, np.allclose(A @ x, b))   # @ è il prodotto matriciale
print("condizionamento:", np.linalg.cond(A).round(1))
```

Un numero di condizionamento enorme segnala un problema mal posto (per esempio una struttura labile).

> [!trappola] `np.linalg.inv(A) @ b` funziona ma è più lento e meno preciso di `solve`. E `A * x` è il prodotto **elemento per elemento**, non matriciale: usa `@`.

> [!ing] Nel FEM (Parte VII) la matrice di rigidezza globale si assembla e si risolve esattamente così, solo più grande.
