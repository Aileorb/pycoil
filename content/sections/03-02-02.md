Un sistema meccanico a più gradi di libertà vibra secondo i suoi **modi propri**. Le pulsazioni naturali escono da un problema agli **autovalori**: `K φ = ω² M φ`.

```python
import numpy as np
# due masse e due molle in serie (sistema a 2 gdl)
m1, m2 = 2.0, 1.0            # kg
k1, k2 = 2000.0, 1000.0      # N/m
M = np.diag([m1, m2])
K = np.array([[k1 + k2, -k2], [-k2, k2]])
w2, phi = np.linalg.eig(np.linalg.solve(M, K))
f = np.sqrt(w2) / (2 * np.pi)
print("frequenze proprie:", np.sort(f).round(2), "Hz")
```

## Con SciPy, la via corretta

Per matrici simmetriche `scipy.linalg.eigh` risolve direttamente il problema generalizzato ed è più stabile:

```python
import numpy as np
from scipy.linalg import eigh
M = np.diag([2.0, 1.0])
K = np.array([[3000.0, -1000.0], [-1000.0, 1000.0]])
w2, modi = eigh(K, M)
for i in range(2):
    f = np.sqrt(w2[i]) / (2 * np.pi)
    forma = modi[:, i] / np.abs(modi[:, i]).max()
    print(f"modo {i+1}: f = {f:.2f} Hz, forma = {forma.round(2)}")
```

Il primo modo ha le masse **in fase**, il secondo **in controfase**.

## Disegnare i modi

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.linalg import eigh
w2, modi = eigh(np.array([[3000.0, -1000.0], [-1000.0, 1000.0]]), np.diag([2.0, 1.0]))
fig, ax = plt.subplots(figsize=(5, 2.6))
for i in range(2):
    forma = np.r_[0, modi[:, i] / np.abs(modi[:, i]).max()]
    ax.plot([0, 1, 2], forma, "o-", label=f"modo {i+1}: {np.sqrt(w2[i])/(2*np.pi):.1f} Hz")
ax.axhline(0, color="gray", lw=0.8)
ax.set_xticks([0, 1, 2], ["vincolo", "massa 1", "massa 2"])
ax.legend()
```

> [!ing] Evitare che una frequenza di eccitazione (un motore, un albero) coincida con una frequenza propria è la base della progettazione contro le vibrazioni: lo riprenderai nel Progetto 4.

> [!trappola] `np.linalg.eig` non restituisce gli autovalori in ordine: ordina sempre (oppure usa `eigh`, che li dà crescenti).
