Un sistema meccanico a più gradi di libertà vibra secondo i suoi **modi propri**. Le pulsazioni naturali escono da un problema agli **autovalori**: `K φ = ω² M φ`.

```python
import numpy as np
# due masse e due molle in serie (sistema a 2 gdl)
m1, m2 = 2.0, 1.0            # kg
k1, k2 = 2000.0, 1000.0      # N/m
M = np.diag([m1, m2])
K = np.array([[k1 + k2, -k2], [-k2, k2]])
w2, phi = np.linalg.eig(np.linalg.solve(M, K))
f = np.sqrt(w2) / (2 * np.pi)
print("frequenze proprie:", np.sort(f).round(2), "Hz")
```

## Che cosa sono autovalori e modi propri

Un sistema di masse e molle lasciato libero vibra in modi «speciali» in cui **tutte le masse oscillano alla stessa frequenza**, con un rapporto fisso tra le ampiezze: i **modi propri**. Per trovarli si risolve `K φ = ω² M φ`, dove `K` è la matrice di rigidezza, `M` quella delle masse, `ω` la pulsazione e `φ` la forma del modo. È un **problema agli autovalori**: gli `ω²` sono gli autovalori, le forme `φ` gli autovettori.

## Un grado di libertà per cominciare

Con una sola massa e una sola molla tutto si riduce alla formula nota `ω = √(k/m)`:

```python
import numpy as np
k, m = 4000.0, 10.0              # N/m, kg
w = np.sqrt(k / m)               # rad/s
print(round(w, 2), "rad/s")      # → 20.0 rad/s
print(round(w / (2 * np.pi), 3), "Hz")   # → 3.183 Hz
```

Con più masse le matrici `K` e `M` prendono il posto di `k` e `m`, e la «radice» diventa un problema agli autovalori: è quello che fa `eigh`. Ricorda la conversione: `f = ω / 2π` in hertz.

## Con SciPy, la via corretta

Per matrici simmetriche `scipy.linalg.eigh` risolve direttamente il problema generalizzato ed è più stabile:

```python
import numpy as np
from scipy.linalg import eigh
M = np.diag([2.0, 1.0])
K = np.array([[3000.0, -1000.0], [-1000.0, 1000.0]])
w2, modi = eigh(K, M)
for i in range(2):
    f = np.sqrt(w2[i]) / (2 * np.pi)
    forma = modi[:, i] / np.abs(modi[:, i]).max()
    print(f"modo {i+1}: f = {f:.2f} Hz, forma = {forma.round(2)}")
```

Il primo modo ha le masse **in fase**, il secondo **in controfase**.

## Disegnare i modi

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.linalg import eigh
w2, modi = eigh(np.array([[3000.0, -1000.0], [-1000.0, 1000.0]]), np.diag([2.0, 1.0]))
fig, ax = plt.subplots(figsize=(5, 2.6))
for i in range(2):
    forma = np.r_[0, modi[:, i] / np.abs(modi[:, i]).max()]
    ax.plot([0, 1, 2], forma, "o-", label=f"modo {i+1}: {np.sqrt(w2[i])/(2*np.pi):.1f} Hz")
ax.axhline(0, color="gray", lw=0.8)
ax.set_xticks([0, 1, 2], ["vincolo", "massa 1", "massa 2"])
ax.legend()
```

> [!ing] Evitare che una frequenza di eccitazione (un motore, un albero) coincida con una frequenza propria è la base della progettazione contro le vibrazioni: lo riprenderai nel Progetto 4.

> [!trappola] `np.linalg.eig` non restituisce gli autovalori in ordine: ordina sempre (oppure usa `eigh`, che li dà crescenti).

## Riepilogo

- I modi propri sono le forme in cui il sistema vibra a una sola frequenza: `K φ = ω² M φ`.
- `scipy.linalg.eigh(K, M)` dà gli `ω²` (in ordine crescente) e le forme dei modi.
- Frequenza in hertz: `f = √(ω²) / 2π`.
- Normalizza i modi (es. massimo = 1) per confrontarli e disegnarli.
