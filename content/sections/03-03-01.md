**Matplotlib** disegna grafici tecnici di qualità da relazione. Lo schema consigliato crea una **figura** e degli **assi** con `plt.subplots()`, poi disegna sugli assi.

```python
import numpy as np
import matplotlib.pyplot as plt

eps = np.linspace(0, 0.004, 50)
sigma = np.minimum(210_000 * eps, 355)     # legame elastico-perfettamente plastico

fig, ax = plt.subplots(figsize=(5, 3))
ax.plot(eps * 1000, sigma)
ax.set_xlabel("deformazione ε [‰]")
ax.set_ylabel("tensione σ [MPa]")
ax.set_title("Acciaio S355")
ax.grid(True, alpha=0.3)
```

## Le tre righe di ogni grafico

```python
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(0, 2 * np.pi, 100)     # 1. i dati: 100 punti
fig, ax = plt.subplots()                # 2. una figura (fig) con un riquadro di assi (ax)
ax.plot(x, np.sin(x))                   # 3. disegna la curva sugli assi
ax.set(xlabel="angolo [rad]", ylabel="sin")
```

1. Servono due array della **stessa lunghezza**: le x e le y dei punti. `linspace` produce le x, la formula le y.
2. `plt.subplots()` restituisce due oggetti: la **figura** (il foglio) e gli **assi** (il riquadro con le scale). Si lavora quasi sempre su `ax`.
3. `ax.plot(x, y)` unisce i punti con una linea. Con 100 punti la curva sembra liscia; con 5 vedresti i segmenti.

`ax.set(...)` imposta più proprietà insieme: etichette, titolo, limiti (`xlim=(0, 6)`).

## Sempre unità e titoli

Un grafico tecnico senza unità di misura non vale niente. Etichetta sempre gli assi con grandezza e unità tra quadre, e aggiungi una griglia leggera:

```python
import numpy as np
import matplotlib.pyplot as plt
eps = np.array([0, 0.001, 0.002, 0.004, 0.008])
sigma = np.array([0, 210, 300, 330, 345])
fig, ax = plt.subplots(figsize=(5, 3))
ax.plot(eps * 100, sigma, "o-")
ax.set(xlabel="deformazione [%]", ylabel="tensione [MPa]", title="Prova di trazione")
ax.grid(alpha=0.3)
```

`figsize` è la dimensione in pollici (larghezza, altezza); `"o-"` disegna punti uniti da una linea.

## Più curve e legenda

```python
import numpy as np
import matplotlib.pyplot as plt

eps = np.linspace(0, 0.004, 80)
fig, ax = plt.subplots(figsize=(5, 3))
for nome, fy in [("S235", 235), ("S275", 275), ("S355", 355)]:
    ax.plot(eps * 1000, np.minimum(210_000 * eps, fy), label=nome)
ax.set(xlabel="ε [‰]", ylabel="σ [MPa]", ylim=(0, 400))
ax.legend()
ax.grid(alpha=0.3)
```

## Stili di linea e marcatori

`"o-"` punti e linea, `"--"` tratteggio, `":"` puntinato; `color=`, `lw=` (spessore), `ms=` (dimensione dei marcatori).

```python
import matplotlib.pyplot as plt
carico = [0, 1, 2, 3, 4, 5]          # kN
allung = [0, 0.11, 0.21, 0.33, 0.42, 0.55]   # mm
fig, ax = plt.subplots(figsize=(4.5, 3))
ax.plot(allung, carico, "o", label="misure")
ax.plot([0, 0.55], [0, 5], "--", label="retta di riferimento")
ax.set(xlabel="allungamento [mm]", ylabel="carico [kN]")
ax.legend()
```

## Salvare

Sul computer: `fig.savefig("grafico.pdf")` (vettoriale, perfetto per LaTeX e Word) o `.png` con `dpi=200`.

> [!trappola] Scrivi sempre le **unità** negli assi: un grafico senza unità all'esame vale mezzo grafico.

> [!ing] Grafici chiari nelle relazioni di laboratorio e nella tesi fanno la differenza: Matplotlib è lo standard di fatto nelle università e nei centri di ricerca.

## Riepilogo

- `fig, ax = plt.subplots()`, poi `ax.plot(x, y)`: x e y della stessa lunghezza.
- `ax.set(xlabel=…, ylabel=…, title=…)`; sempre grandezza e unità.
- Più curve sugli stessi assi con più `plot`, ognuna con `label`, poi `ax.legend()`.
- Stile con stringhe come `"o-"`, `"--"`; `fig.savefig("nome.png", dpi=200)` per salvare.
