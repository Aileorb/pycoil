**Matplotlib** disegna grafici tecnici di qualità da relazione. Lo schema consigliato crea una **figura** e degli **assi** con `plt.subplots()`, poi disegna sugli assi.

```python
import numpy as np
import matplotlib.pyplot as plt

eps = np.linspace(0, 0.004, 50)
sigma = np.minimum(210_000 * eps, 355)     # legame elastico-perfettamente plastico

fig, ax = plt.subplots(figsize=(5, 3))
ax.plot(eps * 1000, sigma)
ax.set_xlabel("deformazione ε [‰]")
ax.set_ylabel("tensione σ [MPa]")
ax.set_title("Acciaio S355")
ax.grid(True, alpha=0.3)
```

## Più curve e legenda

```python
import numpy as np
import matplotlib.pyplot as plt

eps = np.linspace(0, 0.004, 80)
fig, ax = plt.subplots(figsize=(5, 3))
for nome, fy in [("S235", 235), ("S275", 275), ("S355", 355)]:
    ax.plot(eps * 1000, np.minimum(210_000 * eps, fy), label=nome)
ax.set(xlabel="ε [‰]", ylabel="σ [MPa]", ylim=(0, 400))
ax.legend()
ax.grid(alpha=0.3)
```

## Stili di linea e marcatori

`"o-"` punti e linea, `"--"` tratteggio, `":"` puntinato; `color=`, `lw=` (spessore), `ms=` (dimensione dei marcatori).

```python
import matplotlib.pyplot as plt
carico = [0, 1, 2, 3, 4, 5]          # kN
allung = [0, 0.11, 0.21, 0.33, 0.42, 0.55]   # mm
fig, ax = plt.subplots(figsize=(4.5, 3))
ax.plot(allung, carico, "o", label="misure")
ax.plot([0, 0.55], [0, 5], "--", label="retta di riferimento")
ax.set(xlabel="allungamento [mm]", ylabel="carico [kN]")
ax.legend()
```
