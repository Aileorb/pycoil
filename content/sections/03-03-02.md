Con NumPy e Matplotlib i diagrammi delle sollecitazioni di una trave diventano poche righe. Esempio: trave appoggiata di luce `L` con un carico concentrato `F` a distanza `a` dall'appoggio sinistro.

```python
import numpy as np
import matplotlib.pyplot as plt

L, F, a = 4.0, 10.0, 1.5          # m, kN, m
RB = F * a / L
RA = F - RB
x = np.linspace(0, L, 401)
T = np.where(x < a, RA, RA - F)                   # taglio [kN]
M = np.where(x < a, RA * x, RA * x - F * (x - a))  # momento [kNm]

fig, (a1, a2) = plt.subplots(2, 1, figsize=(5, 4), sharex=True)
a1.fill_between(x, T, step="mid", alpha=0.4); a1.set_ylabel("T [kN]")
a2.fill_between(x, M, alpha=0.4, color="tab:orange"); a2.set_ylabel("M [kNm]")
a2.invert_yaxis(); a2.set_xlabel("x [m]")
print(f"RA = {RA:.2f} kN, RB = {RB:.2f} kN, Mmax = {M.max():.2f} kNm")
```

## Carico distribuito

Per un carico uniforme `q` il taglio è lineare e il momento parabolico:

```python
import numpy as np
import matplotlib.pyplot as plt

L, q = 5.0, 8.0                # m, kN/m
x = np.linspace(0, L, 201)
T = q * L / 2 - q * x
M = q * x * (L - x) / 2

fig, (a1, a2) = plt.subplots(2, 1, figsize=(5, 4), sharex=True)
a1.plot(x, T); a1.axhline(0, color="k", lw=0.6); a1.set_ylabel("T [kN]")
a2.plot(x, M, color="tab:orange"); a2.invert_yaxis(); a2.set_ylabel("M [kNm]")
a2.set_xlabel("x [m]")
i = M.argmax()
a2.annotate(f"Mmax = {M[i]:.1f} kNm", (x[i], M[i]), textcoords="offset points", xytext=(10, -15))
```

## Sovrapposizione degli effetti

Per un sistema lineare gli effetti si sommano: calcola ogni carico separatamente e somma gli array.

```python
import numpy as np
L = 4.0
x = np.linspace(0, L, 401)

def M_conc(F, a):
    RA = F * (L - a) / L
    return np.where(x < a, RA * x, RA * x - F * (x - a))

def M_distr(q):
    return q * x * (L - x) / 2

M = M_conc(10, 1.5) + M_conc(6, 3.0) + M_distr(2)
print(f"Mmax = {M.max():.2f} kNm a x = {x[M.argmax()]:.2f} m")
```

> [!ing] Il convenzionale "momento disegnato dal lato delle fibre tese" si ottiene con `invert_yaxis()`. Il Progetto 3 trasforma questo codice in uno strumento per le esercitazioni.

> [!trappola] Con pochi punti il salto del taglio sotto il carico concentrato viene "smussato": usa molti punti (`linspace` con qualche centinaio) o `step=`.
