Una figura può contenere più **assi** affiancati: `plt.subplots(righe, colonne)`. Le **annotazioni** puntano i valori importanti direttamente sul grafico.

```python
import numpy as np
import matplotlib.pyplot as plt

t = np.linspace(0, 2, 400)
x = np.exp(-1.2 * t) * np.cos(2 * np.pi * 3 * t)   # oscillazione smorzata [mm]
v = np.gradient(x, t)                                # velocità [mm/s]

fig, (a1, a2) = plt.subplots(1, 2, figsize=(7, 2.8))
a1.plot(t, x); a1.set(title="spostamento", xlabel="t [s]", ylabel="x [mm]")
a2.plot(x, v, color="tab:green"); a2.set(title="piano delle fasi", xlabel="x [mm]", ylabel="v [mm/s]")
fig.tight_layout()
```

## Annotare un picco

```python
import numpy as np
import matplotlib.pyplot as plt

f = np.linspace(0.1, 30, 600)          # Hz
fn, z = 12.0, 0.05                     # frequenza propria, smorzamento
r = f / fn
H = 1 / np.sqrt((1 - r**2) ** 2 + (2 * z * r) ** 2)

fig, ax = plt.subplots(figsize=(5, 3))
ax.plot(f, H)
i = H.argmax()
ax.annotate(f"risonanza\n{f[i]:.1f} Hz, ×{H[i]:.1f}", xy=(f[i], H[i]), xytext=(f[i] + 5, H[i] * 0.8),
            arrowprops=dict(arrowstyle="->"))
ax.set(xlabel="frequenza [Hz]", ylabel="amplificazione", yscale="log")
ax.grid(alpha=0.3, which="both")
```

## Due assi y

Quando due grandezze hanno unità diverse:

```python
import numpy as np
import matplotlib.pyplot as plt

giri = np.linspace(1000, 6000, 50)                 # rpm
coppia = 180 - 2.2e-6 * (giri - 3500) ** 2         # Nm
potenza = coppia * giri * 2 * np.pi / 60 / 1000    # kW

fig, ax1 = plt.subplots(figsize=(5, 3))
ax1.plot(giri, coppia, color="tab:blue"); ax1.set_ylabel("coppia [Nm]", color="tab:blue")
ax2 = ax1.twinx()
ax2.plot(giri, potenza, color="tab:red"); ax2.set_ylabel("potenza [kW]", color="tab:red")
ax1.set_xlabel("regime [rpm]")
```

> [!trappola] Se le etichette si sovrappongono, chiama `fig.tight_layout()` (o crea la figura con `layout="constrained"`).

> [!ing] Curve di coppia e potenza, diagrammi di risonanza, piani delle fasi: sono i grafici che incontrerai in Meccanica applicata e in Macchine.
