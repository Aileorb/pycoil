Molte equazioni dell'ingegneria non si risolvono a mano: l'equazione di Colebrook per l'attrito nei tubi, le frequenze di una trave a sbalzo, l'equilibrio di un meccanismo. `scipy.optimize` trova le **radici** `f(x) = 0` in modo robusto.

```python
import numpy as np
from scipy.optimize import brentq

# fattore di attrito di Darcy dall'equazione di Colebrook
Re, eps_D = 1e5, 1e-4
def colebrook(f):
    return 1 / np.sqrt(f) + 2 * np.log10(eps_D / 3.7 + 2.51 / (Re * np.sqrt(f)))

f = brentq(colebrook, 0.005, 0.1)   # cerca nell'intervallo dove cambia segno
print(f"f = {f:.5f}")
```

## Due famiglie di metodi

- **Con intervallo** (`brentq`, bisezione): servono `a` e `b` con `f(a)` e `f(b)` di segno opposto. Convergono sempre: la scelta sicura.
- **Con punto iniziale** (`newton`, `fsolve`): più veloci, ma possono divergere se parti lontano.

```python
from scipy.optimize import newton
import math

# Newton con derivata esplicita: radice cubica di 10
r = newton(lambda x: x**3 - 10, x0=2, fprime=lambda x: 3 * x**2)
print(r, round(r**3, 12))
```

## Più radici: guarda prima il grafico

Le frequenze di una trave a sbalzo vengono dall'equazione `cos(βL)·cosh(βL) + 1 = 0`. Ha infinite radici: si individuano i cambi di segno su una griglia e si raffina ciascuno.

```python
import numpy as np
from scipy.optimize import brentq

g = lambda b: np.cos(b) * np.cosh(b) + 1
x = np.linspace(0.1, 12, 2000)
segni = np.where(np.sign(g(x[:-1])) != np.sign(g(x[1:])))[0]
radici = [brentq(g, x[i], x[i + 1]) for i in segni]
print(np.round(radici, 4))          # βL = 1.8751, 4.6941, 7.8548, 10.9955

# frequenze di una mensola d'acciaio 1 m, sezione 20×20 mm
E, rho, L = 210e9, 7850, 1.0
A, I = 0.02**2, 0.02**4 / 12
f = [(b / L) ** 2 * np.sqrt(E * I / (rho * A)) / (2 * np.pi) for b in radici[:3]]
print("frequenze [Hz]:", np.round(f, 1))
```

## Sistemi di equazioni

`fsolve` risolve sistemi non lineari `F(x) = 0` con `x` vettore:

```python
import numpy as np
from scipy.optimize import fsolve

# intersezione tra una circonferenza di raggio 5 e la parabola y = x²/4
def F(v):
    x, y = v
    return [x**2 + y**2 - 25, y - x**2 / 4]

sol = fsolve(F, x0=[3, 2])
print(sol.round(4), np.allclose(F(sol), 0))
```

> [!trappola] `brentq` vuole un intervallo con cambio di segno: se `f(a)` e `f(b)` hanno lo stesso segno solleva `ValueError`. Disegna sempre la funzione prima di scegliere `a` e `b`.

> [!ing] Colebrook ti servirà in Fluidodinamica e Impianti, le frequenze della mensola in Meccanica applicata: sono due casi classici d'esame risolti in tre righe.
