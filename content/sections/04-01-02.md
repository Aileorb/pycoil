Due situazioni diverse:

- hai una **funzione** → `scipy.integrate.quad` integra con grande precisione;
- hai dei **dati misurati** → `scipy.integrate.trapezoid` o `simpson` integrano i campioni.

```python
import numpy as np
from scipy.integrate import quad, trapezoid

# lavoro di una molla non lineare F = k x + c x³ tra 0 e 20 mm
k, c = 50.0, 0.02                     # N/mm, N/mm³
L, err = quad(lambda x: k * x + c * x**3, 0, 20)
print(f"lavoro = {L:.1f} N·mm (errore stimato {err:.1e})")

# stesso lavoro da una prova: 6 letture di forza
x = np.array([0, 4, 8, 12, 16, 20.0])
F = k * x + c * x**3
print(f"dai dati: {trapezoid(F, x):.1f} N·mm")
```

## Più precisione dai dati: Simpson

```python
import numpy as np
from scipy.integrate import trapezoid, simpson

x = np.linspace(0, np.pi, 11)
y = np.sin(x)
print(trapezoid(y, x), simpson(y, x=x))   # valore esatto: 2
```

## Area, baricentro, inerzia di un profilo qualsiasi

Il profilo di una camma o di un'ala è dato per punti: gli integrali ne danno le proprietà.

```python
import numpy as np
from scipy.integrate import quad

# sezione a parabola: y da 0 a h(x) = 40 (1 - (x/30)²), x in [-30, 30] mm
h = lambda x: 40 * (1 - (x / 30) ** 2)
A, _ = quad(h, -30, 30)
Sx, _ = quad(lambda x: h(x) ** 2 / 2, -30, 30)    # momento statico rispetto all'asse x
yG = Sx / A
print(f"A = {A:.1f} mm², yG = {yG:.2f} mm")        # atteso: yG = 2h/5 = 16 mm
```

## Derivare i dati: np.gradient

Da uno spostamento misurato ricavi velocità e accelerazione. `np.gradient` usa le differenze centrali.

```python
import numpy as np
t = np.linspace(0, 1, 201)                 # s
x = 0.01 * np.sin(2 * np.pi * 5 * t)       # m, 5 Hz
v = np.gradient(x, t)
a = np.gradient(v, t)
print(f"v max = {v.max():.4f} m/s (teorica {0.01 * 2 * np.pi * 5:.4f})")
print(f"a max = {a.max():.2f} m/s² (teorica {0.01 * (2 * np.pi * 5) ** 2:.2f})")
```

## Integrare nel tempo: cumulative_trapezoid

```python
import numpy as np
from scipy.integrate import cumulative_trapezoid
t = np.linspace(0, 2, 5)
a = np.full_like(t, 3.0)                    # accelerazione costante 3 m/s²
v = cumulative_trapezoid(a, t, initial=0)
x = cumulative_trapezoid(v, t, initial=0)
print(v, x)                                 # x = 1.5 t²
```

> [!trappola] Derivare dati **rumorosi** amplifica il rumore: ogni derivata peggiora le cose. Prima filtra (Parte V, serie temporali) o fai un fit, poi deriva.

> [!ing] L'area sotto la curva forza-spostamento è l'energia assorbita: è così che si confrontano gli assorbitori d'urto e si calcola la tenacità nelle prove di trazione.
