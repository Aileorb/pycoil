- **Interpolare**: passare **esattamente** per i punti noti, per leggere valori intermedi (una tabella del vapore, una curva del costruttore).
- **Fare un fit**: trovare i parametri di un **modello** che si avvicina il più possibile a dati rumorosi.

```python
import numpy as np
# tabella: viscosità dell'olio [mPa·s] in funzione della temperatura [°C]
T = np.array([20, 40, 60, 80, 100])
mu = np.array([290, 95, 40, 20, 11.5])
print(np.interp(50, T, mu))            # interpolazione lineare
print(np.interp([30, 70], T, mu))
```

## Interpolare o approssimare?

Sono due cose diverse, e scegliere quella giusta è metà del lavoro:

- **Interpolare**: la curva passa **esattamente** per tutti i punti. Va bene per tabelle affidabili (proprietà dei materiali, tabelle del vapore) quando ti serve un valore intermedio.
- **Approssimare** (*fit*): la curva passa **vicino** ai punti, minimizzando l'errore. Va bene per dati misurati, che hanno rumore: non vuoi una curva che insegue ogni errore di misura.

## np.interp passo per passo

Tra due punti noti traccia un segmento e legge il valore sul segmento:

```python
import numpy as np
T = np.array([20, 40])           # °C
mu = np.array([290, 95])         # mPa·s
print(np.interp(30, T, mu))      # → 192.5   (a metà strada: (290 + 95) / 2)
print(np.interp(25, T, mu))      # → 241.25
print(np.interp(50, T, mu))      # → 95.0    (fuori tabella: tiene l'ultimo valore!)
```

Le `x` della tabella devono essere **crescenti**. Fuori dall'intervallo `np.interp` non estrapola: restituisce il valore all'estremo. Spesso è più sicuro così, ma devi saperlo.

## Fit lineare passo per passo

Il caso più comune: dei punti che dovrebbero stare su una retta (la taratura di un sensore). `np.polyfit(x, y, 1)` trova pendenza e intercetta che minimizzano la somma dei quadrati degli scarti:

```python
import numpy as np
tensione_V = np.array([0.0, 1.0, 2.0, 3.0, 4.0])
forza_N = np.array([0.4, 49.6, 100.3, 149.5, 200.6])   # misure con un po' di rumore
m, q = np.polyfit(tensione_V, forza_N, 1)
print(round(m, 2), round(q, 2))          # → 50.03 0.02
print(round(m * 2.5 + q, 1), "N a 2,5 V")   # → 125.1 N a 2,5 V
```

`polyfit` restituisce i coefficienti dal grado più alto: per una retta `[m, q]`.

## Spline cubiche

L'interpolazione lineare ha "spigoli"; una spline cubica è liscia (derivate continue).

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.interpolate import CubicSpline

T = np.array([20, 40, 60, 80, 100])
mu = np.array([290, 95, 40, 20, 11.5])
cs = CubicSpline(T, np.log(mu))        # interpolo il logaritmo: andamento più regolare
Tf = np.linspace(20, 100, 200)

fig, ax = plt.subplots(figsize=(5, 3))
ax.plot(T, mu, "o", label="tabella")
ax.plot(Tf, np.exp(cs(Tf)), label="spline su log μ")
ax.plot(Tf, np.interp(Tf, T, mu), "--", label="lineare")
ax.set(xlabel="T [°C]", ylabel="μ [mPa·s]", yscale="log")
ax.legend()
print(f"μ(50 °C) ≈ {np.exp(cs(50)):.1f} mPa·s")
```

## Fit polinomiale

```python
import numpy as np
# taratura di una cella di carico: tensione in uscita [mV] vs carico [N]
F = np.array([0, 100, 200, 300, 400, 500])
V = np.array([0.02, 1.01, 2.03, 2.98, 4.02, 5.01])
k, q = np.polyfit(F, V, 1)                 # retta di regressione
print(f"sensibilità = {k * 1000:.3f} mV/kN, offset = {q:.3f} mV")
residui = V - (k * F + q)
print("residuo massimo:", np.abs(residui).max().round(3), "mV")
```

## curve_fit: un modello qualsiasi

Il decadimento di un'oscillazione libera dà lo smorzamento: si fa il fit dei picchi con `A e^{-ζ ω t}`.

```python
import numpy as np
from scipy.optimize import curve_fit

rng = np.random.default_rng(3)
t = np.linspace(0, 2, 15)
picchi = 8.0 * np.exp(-1.6 * t) * (1 + 0.03 * rng.standard_normal(t.size))

def modello(t, A, b):
    return A * np.exp(-b * t)

(A, b), cov = curve_fit(modello, t, picchi, p0=[5, 1])
sb = np.sqrt(np.diag(cov))[1]
wn = 2 * np.pi * 12                     # pulsazione naturale nota (12 Hz)
print(f"A = {A:.2f}, b = {b:.3f} ± {sb:.3f} 1/s, ζ = {b / wn:.4f}")
```

`p0` è la stima iniziale: con modelli non lineari conta molto. `cov` dà l'incertezza dei parametri.

> [!trappola] Mai estrapolare un polinomio di grado alto fuori dall'intervallo dei dati: oscilla in modo assurdo. Per le tabelle tecniche resta nell'intervallo, o usa un modello fisico con `curve_fit`.

> [!ing] Tarare un sensore, leggere le tabelle dei materiali, stimare lo smorzamento da una prova: sono tutti problemi di interpolazione o fit.

## Riepilogo

- Interpolare: la curva passa per i punti (tabelle); approssimare: passa vicino (misure con rumore).
- `np.interp(x, xp, fp)` lineare, `xp` crescente, nessuna estrapolazione; spline con `CubicSpline`.
- `np.polyfit(x, y, grado)` dà i coefficienti dal grado più alto; `np.polyval` li usa.
- `curve_fit(modello, x, y, p0=…)` per qualsiasi formula; valuta sempre i residui.
