- **Interpolare**: passare **esattamente** per i punti noti, per leggere valori intermedi (una tabella del vapore, una curva del costruttore).
- **Fare un fit**: trovare i parametri di un **modello** che si avvicina il più possibile a dati rumorosi.

```python
import numpy as np
# tabella: viscosità dell'olio [mPa·s] in funzione della temperatura [°C]
T = np.array([20, 40, 60, 80, 100])
mu = np.array([290, 95, 40, 20, 11.5])
print(np.interp(50, T, mu))            # interpolazione lineare
print(np.interp([30, 70], T, mu))
```

## Spline cubiche

L'interpolazione lineare ha "spigoli"; una spline cubica è liscia (derivate continue).

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.interpolate import CubicSpline

T = np.array([20, 40, 60, 80, 100])
mu = np.array([290, 95, 40, 20, 11.5])
cs = CubicSpline(T, np.log(mu))        # interpolo il logaritmo: andamento più regolare
Tf = np.linspace(20, 100, 200)

fig, ax = plt.subplots(figsize=(5, 3))
ax.plot(T, mu, "o", label="tabella")
ax.plot(Tf, np.exp(cs(Tf)), label="spline su log μ")
ax.plot(Tf, np.interp(Tf, T, mu), "--", label="lineare")
ax.set(xlabel="T [°C]", ylabel="μ [mPa·s]", yscale="log")
ax.legend()
print(f"μ(50 °C) ≈ {np.exp(cs(50)):.1f} mPa·s")
```

## Fit polinomiale

```python
import numpy as np
# taratura di una cella di carico: tensione in uscita [mV] vs carico [N]
F = np.array([0, 100, 200, 300, 400, 500])
V = np.array([0.02, 1.01, 2.03, 2.98, 4.02, 5.01])
k, q = np.polyfit(F, V, 1)                 # retta di regressione
print(f"sensibilità = {k * 1000:.3f} mV/kN, offset = {q:.3f} mV")
residui = V - (k * F + q)
print("residuo massimo:", np.abs(residui).max().round(3), "mV")
```

## curve_fit: un modello qualsiasi

Il decadimento di un'oscillazione libera dà lo smorzamento: si fa il fit dei picchi con `A e^{-ζ ω t}`.

```python
import numpy as np
from scipy.optimize import curve_fit

rng = np.random.default_rng(3)
t = np.linspace(0, 2, 15)
picchi = 8.0 * np.exp(-1.6 * t) * (1 + 0.03 * rng.standard_normal(t.size))

def modello(t, A, b):
    return A * np.exp(-b * t)

(A, b), cov = curve_fit(modello, t, picchi, p0=[5, 1])
sb = np.sqrt(np.diag(cov))[1]
wn = 2 * np.pi * 12                     # pulsazione naturale nota (12 Hz)
print(f"A = {A:.2f}, b = {b:.3f} ± {sb:.3f} 1/s, ζ = {b / wn:.4f}")
```

`p0` è la stima iniziale: con modelli non lineari conta molto. `cov` dà l'incertezza dei parametri.

> [!trappola] Mai estrapolare un polinomio di grado alto fuori dall'intervallo dei dati: oscilla in modo assurdo. Per le tabelle tecniche resta nell'intervallo, o usa un modello fisico con `curve_fit`.

> [!ing] Tarare un sensore, leggere le tabelle dei materiali, stimare lo smorzamento da una prova: sono tutti problemi di interpolazione o fit.
