Le **equazioni differenziali ordinarie** descrivono quasi tutta la dinamica: masse, molle, smorzatori, circuiti, scambio termico. `solve_ivp` le integra nel tempo. La regola: riscrivere tutto come sistema del **primo ordine** `y' = f(t, y)`.

```python
import numpy as np
from scipy.integrate import solve_ivp

# oscillatore m x'' + c x' + k x = 0  →  stato y = [x, v]
m, c, k = 1.0, 0.8, 400.0
def f(t, y):
    x, v = y
    return [v, -(c * v + k * x) / m]

sol = solve_ivp(f, (0, 2), y0=[0.01, 0.0], max_step=0.005)
print(sol.status, sol.t.size, "passi")
print(f"x(2 s) = {sol.y[0, -1] * 1000:.3f} mm")
```

## Grafico della risposta

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.integrate import solve_ivp

m, c, k = 1.0, 0.8, 400.0
F0, w = 2.0, 18.0                       # forzante armonica
def f(t, y):
    x, v = y
    return [v, (F0 * np.sin(w * t) - c * v - k * x) / m]

t = np.linspace(0, 6, 1500)
sol = solve_ivp(f, (0, 6), [0, 0], t_eval=t, rtol=1e-8, atol=1e-10)
fig, ax = plt.subplots(figsize=(6, 2.8))
ax.plot(sol.t, sol.y[0] * 1000)
ax.set(xlabel="t [s]", ylabel="x [mm]", title="transitorio + regime")
ax.grid(alpha=0.3)
```

`t_eval` sceglie gli istanti in cui vuoi la soluzione; `rtol` e `atol` la precisione.

## Il pendolo non lineare

Per piccole oscillazioni il periodo è `2π√(L/g)`; per grandi ampiezze aumenta. Con `solve_ivp` non serve linearizzare.

```python
import numpy as np
from scipy.integrate import solve_ivp

g, L = 9.81, 1.0
def pendolo(t, y):
    th, om = y
    return [om, -g / L * np.sin(th)]

def passa_per_zero(t, y):        # evento: theta attraversa lo zero
    return y[0]
passa_per_zero.direction = -1     # solo da positivo a negativo

for th0 in [5, 45, 90, 150]:
    s = solve_ivp(pendolo, (0, 20), [np.radians(th0), 0], events=passa_per_zero, rtol=1e-10, atol=1e-12)
    zeri = s.t_events[0]
    T = zeri[1] - zeri[0]
    print(f"θ0 = {th0:3d}°  T = {T:.4f} s  (lineare {2 * np.pi * np.sqrt(L / g):.4f} s)")
```

Gli **eventi** fermano o registrano l'integrazione quando una funzione dello stato si annulla: impatti, fine corsa, cambi di segno.

## Problemi rigidi

Se il sistema ha scale di tempo molto diverse (una molla rigidissima, una reazione chimica veloce) il metodo di default è lento: usa `method="Radau"` o `"BDF"`.

```python
from scipy.integrate import solve_ivp
s = solve_ivp(lambda t, y: [-1000 * (y[0] - 1)], (0, 1), [0], method="BDF")
print(s.y[0, -1].round(6), s.t.size, "passi")
```

> [!trappola] `solve_ivp` sceglie da solo il passo: se ti servono curve lisce passa `t_eval` o `max_step`, altrimenti il grafico può sembrare spezzettato anche se la soluzione è giusta.

> [!ing] Sospensioni, transitori di un motore, carica di un condensatore, raffreddamento di un pezzo: lo schema è sempre lo stesso, cambia solo `f(t, y)`.
