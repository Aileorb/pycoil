Progettare è spesso **ottimizzare**: la sezione più leggera che regge, la forma che minimizza la freccia, i parametri che rendono più efficiente un ciclo. `scipy.optimize.minimize` cerca il minimo di una funzione, anche con **vincoli**.

```python
from scipy.optimize import minimize_scalar

# lunghezza di leva che minimizza la forza richiesta più il peso della leva
def costo(L):
    return 100 / L + 3 * L
r = minimize_scalar(costo, bounds=(0.1, 20), method="bounded")
print(f"L ottima = {r.x:.3f}, costo = {r.fun:.3f}")   # teorica √(100/3) = 5.774
```

## La trave più leggera

Sezione rettangolare `b × h` di una trave appoggiata con carico distribuito. Minimizza l'area (cioè il peso) rispettando tensione ammissibile, freccia massima e un rapporto `h/b` ragionevole.

```python
import numpy as np
from scipy.optimize import minimize

q, L = 10.0, 4000.0                 # N/mm, mm
E, s_amm = 210e3, 160.0             # MPa
v_amm = L / 250                     # mm

M = q * L**2 / 8
def area(x):
    b, h = x
    return b * h

vincoli = [
    {"type": "ineq", "fun": lambda x: s_amm - M / (x[0] * x[1] ** 2 / 6)},             # σ ≤ σ_amm
    {"type": "ineq", "fun": lambda x: v_amm - 5 * q * L**4 / (384 * E * x[0] * x[1] ** 3 / 12)},  # v ≤ v_amm
    {"type": "ineq", "fun": lambda x: 4 * x[0] - x[1]},                              # h ≤ 4 b
]
r = minimize(area, x0=[50, 200], method="SLSQP", constraints=vincoli, bounds=[(10, 300), (20, 600)])
b, h = r.x
print(r.success, f"b = {b:.1f} mm, h = {h:.1f} mm, A = {r.fun:.0f} mm²")
print(f"σ = {M / (b * h**2 / 6):.1f} MPa, v = {5 * q * L**4 / (384 * E * b * h**3 / 12):.2f} mm")
```

Un vincolo `"ineq"` deve essere **≥ 0** quando è rispettato: per questo si scrive `limite − valore`.

## Minimizzare senza derivate

`Nelder-Mead` non usa gradienti: utile per funzioni rumorose o calcolate da una simulazione.

```python
import numpy as np
from scipy.optimize import minimize

# funzione di Rosenbrock, il classico banco di prova
rosen = lambda p: (1 - p[0]) ** 2 + 100 * (p[1] - p[0] ** 2) ** 2
for metodo in ["Nelder-Mead", "BFGS"]:
    r = minimize(rosen, x0=[-1.2, 1.0], method=metodo)
    print(f"{metodo:12s} {r.x.round(4)}  valutazioni: {r.nfev}")
```

## Minimi quadrati non lineari

Quando il problema è "fai combaciare un modello con i dati", `least_squares` è la scelta giusta (è il motore di `curve_fit`).

```python
import numpy as np
from scipy.optimize import least_squares

# legge di Norton per il creep: eps_dot = A σ^n
sigma = np.array([100, 150, 200, 250, 300.0])
eps_dot = np.array([2.1e-9, 1.6e-8, 6.9e-8, 2.1e-7, 5.3e-7])
# parametri ben scalati: ln A (non A, che vale circa 1e-19) ed n
res = least_squares(lambda p: p[0] + p[1] * np.log(sigma) - np.log(eps_dot), x0=[-40.0, 3.0])
lnA, n = res.x
print(f"n = {n:.2f}, A = {np.exp(lnA):.2e}")
```

> [!nota] Conviene sempre dare ai parametri ordini di grandezza simili (qui `ln A` invece di `A`): con valori come 1e-19 l'ottimizzatore si blocca subito.

> [!trappola] Gli ottimizzatori trovano un minimo **locale**: prova più punti di partenza. E controlla sempre `r.success` e `r.message` prima di fidarti del risultato.

> [!ing] Nella pratica il risultato va poi arrotondato a dimensioni commerciali (un profilo del catalogo, una lamiera standard): l'ottimo matematico è il punto di partenza della scelta.
