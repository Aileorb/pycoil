La **trasformata di Fourier** scompone un segnale nel tempo nelle frequenze che lo compongono. Da un accelerometro su un motore ricavi subito la velocità di rotazione, le armoniche, le risonanze. Con dati reali si usa la **FFT** per segnali reali: `rfft`.

```python
import numpy as np
from scipy.fft import rfft, rfftfreq

fs, T = 1000, 2.0                          # Hz di campionamento, durata [s]
t = np.arange(0, T, 1 / fs)
x = 1.0 * np.sin(2 * np.pi * 25 * t) + 0.4 * np.sin(2 * np.pi * 120 * t)

X = np.abs(rfft(x)) * 2 / t.size           # ampiezza di ogni frequenza
f = rfftfreq(t.size, 1 / fs)
picchi = f[np.argsort(X)[-2:]]
print("frequenze principali:", np.sort(picchi), "Hz")
```

## Lo spettro con il rumore

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.fft import rfft, rfftfreq

rng = np.random.default_rng(0)
fs = 2000
t = np.arange(0, 4, 1 / fs)                 # 4 s → risoluzione 0.25 Hz
giri = 1470 / 60                            # Hz: motore a 1470 rpm
x = 0.8 * np.sin(2 * np.pi * giri * t) + 0.3 * np.sin(2 * np.pi * 2 * giri * t) + 0.6 * rng.standard_normal(t.size)

X = np.abs(rfft(x * np.hanning(t.size))) * 4 / t.size   # finestra di Hann
f = rfftfreq(t.size, 1 / fs)
fig, (a1, a2) = plt.subplots(2, 1, figsize=(6, 4.2))
a1.plot(t[:400], x[:400], lw=0.8); a1.set(xlabel="t [s]", ylabel="a [m/s²]")
a2.plot(f, X); a2.set(xlim=(0, 200), xlabel="f [Hz]", ylabel="ampiezza")
a2.axvline(giri, ls=":", color="gray")
fig.tight_layout()
print(f"1× giri = {giri:.1f} Hz, picco trovato a {f[X[1:].argmax() + 1]:.1f} Hz")
```

Nel tempo il segnale sembra solo rumore; nello spettro le due righe (1× e 2× i giri) sono evidenti.

## Tre regole per usarla bene

1. **Nyquist**: con campionamento `fs` vedi solo frequenze fino a `fs/2`. Più in alto il segnale si "ripiega" (aliasing).
2. **Risoluzione**: la distanza tra due righe è `1/T`. Per distinguere 25.0 Hz da 25.5 Hz servono almeno 2 secondi di segnale.
3. **Finestra**: se il segnale non contiene un numero intero di periodi, l'energia si "spalma" (leakage). Moltiplicare per una finestra di Hann la riduce.

```python
import numpy as np
from scipy.fft import rfft, rfftfreq
fs = 100
t = np.arange(0, 1, 1 / fs)
x = np.sin(2 * np.pi * 70 * t)              # 70 Hz campionati a 100 Hz!
f = rfftfreq(t.size, 1 / fs)
print("sembra:", f[np.abs(rfft(x)).argmax()], "Hz")   # aliasing: 30 Hz
```

## Dalla risposta all'impulso alla frequenza propria

```python
import numpy as np
from scipy.fft import rfft, rfftfreq
fs = 1000
t = np.arange(0, 4, 1 / fs)
fn, z = 18.0, 0.02
x = np.exp(-z * 2 * np.pi * fn * t) * np.sin(2 * np.pi * fn * np.sqrt(1 - z**2) * t)   # martellata
f = rfftfreq(t.size, 1 / fs)
print(f"frequenza propria stimata: {f[np.abs(rfft(x)).argmax()]:.2f} Hz")
```

> [!trappola] L'ampiezza "giusta" dipende dalla normalizzazione: `2/N` per una riga sinusoidale senza finestra, `4/N` con la finestra di Hann. Per confronti relativi tra picchi basta `np.abs(rfft(x))`.

> [!ing] La prova di martellata e l'analisi spettrale sono la base della manutenzione predittiva: squilibri (1×), disallineamenti (2×), cuscinetti danneggiati (frequenze caratteristiche) si leggono nello spettro.
