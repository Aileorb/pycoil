Con `solve_ivp` conosci **tutto all'inizio** (posizione e velocità a t = 0). Molti problemi però danno una condizione a **ciascun estremo**: la temperatura alle due facce di una parete, la freccia nulla sui due appoggi di una trave. Sono **problemi ai limiti**.

Il metodo più diretto sono le **differenze finite**: dividi il dominio in punti a passo `h` e sostituisci la derivata seconda con `(T[i−1] − 2T[i] + T[i+1]) / h²`. L'equazione diventa un **sistema lineare**.

```python
import numpy as np

# barra con generazione di calore: −k T'' = q,  T(0) = T(L) = 20 °C
k, q, L, T0 = 15.0, 2.0e6, 0.02, 20.0        # W/(m·K), W/m³, m, °C
n = 19                                        # punti interni
h = L / (n + 1)
A = (np.diag(-2 * np.ones(n)) + np.diag(np.ones(n - 1), 1) + np.diag(np.ones(n - 1), -1)) / h**2
b = np.full(n, -q / k)
b[0] -= T0 / h**2                             # condizioni agli estremi
b[-1] -= T0 / h**2
T = np.linalg.solve(A, b)
print(f"T max = {T.max():.2f} °C   (esatto {T0 + q * L**2 / (8 * k):.2f} °C)")
```

## Le condizioni al contorno finiscono nel termine noto

Nel punto interno vicino a un estremo, la formula usa un valore **noto** (`T0`): lo porti a destra, nel vettore `b`. È tutto il segreto del metodo. La matrice è **tridiagonale**: ogni equazione coinvolge solo il punto e i due vicini.

## Quanto è preciso

Nel primo esempio il risultato è esatto perché la soluzione è una parabola, che le differenze centrate derivano senza errore. In generale l'errore scende come `h²`: dimezzando il passo, l'errore diventa circa un quarto. Verificalo sempre su un caso con soluzione nota.

```python
import numpy as np

def freccia_fd(n, q=10.0, L=4.0, EI=2.0e6):
    """Trave appoggiata con carico uniforme: v'' = −M(x)/EI, v(0) = v(L) = 0."""
    h = L / (n + 1)
    x = np.linspace(h, L - h, n)
    M = q * x * (L - x) / 2                       # N·m (q in N/m, L in m)
    A = (np.diag(-2 * np.ones(n)) + np.diag(np.ones(n - 1), 1) + np.diag(np.ones(n - 1), -1)) / h**2
    v = np.linalg.solve(A, -M / EI)
    return np.abs(v).max()

esatta = 5 * 10.0 * 4.0**4 / (384 * 2.0e6)
for n in [3, 7, 15, 31]:
    f = freccia_fd(n)
    print(f"n = {n:2d}  freccia = {f * 1000:.4f} mm  errore = {abs(f - esatta) / esatta:.1e}")
```

## Problemi non lineari o con derivate al bordo: solve_bvp

Quando la condizione riguarda la **derivata** (estremo isolato, sbalzo libero) o l'equazione non è lineare, `solve_bvp` fa il lavoro per te. Come con `solve_ivp`, riscrivi tutto al primo ordine; in più descrivi le condizioni ai due estremi con una funzione che deve annullarsi.

Esempio: un'**aletta** di raffreddamento con punta isolata, `T'' = m² (T − T∞)`, `T(0) = Tb`, `T'(L) = 0`.

```python
import numpy as np
from scipy.integrate import solve_bvp

Tb, Tinf, m, L = 90.0, 25.0, 20.0, 0.1     # °C, °C, 1/m, m

def f(x, y):
    T, dT = y
    return np.vstack([dT, m**2 * (T - Tinf)])

def bc(ya, yb):
    return np.array([ya[0] - Tb, yb[1]])   # T(0) = Tb,  T'(L) = 0

x = np.linspace(0, L, 11)
y0 = np.vstack([np.full_like(x, Tb), np.zeros_like(x)])
sol = solve_bvp(f, bc, x, y0)
esatta = Tinf + (Tb - Tinf) / np.cosh(m * L)
print(sol.status, f"T(punta) = {sol.sol(L)[0]:.2f} °C  (esatto {esatta:.2f})")
```

`sol.sol(x)` è una funzione: la valuti dove vuoi, non solo nei punti della griglia.

> [!nota] Esiste anche il **metodo di tiro** (*shooting*): indovini la condizione mancante all'inizio, integri con `solve_ivp` e correggi con `brentq` finché all'altro estremo torna quella data. È istruttivo, ma per l'uso quotidiano `solve_bvp` è più robusto.

> [!trappola] Con centinaia di migliaia di punti la matrice densa di `np.diag` occupa troppa memoria: usa `scipy.sparse.diags` e `scipy.sparse.linalg.spsolve`, che salvano solo le tre diagonali. Lo vedrai nella Parte VIII.

> [!ing] Le differenze finite sono il primo passo verso il **FEM** della Parte VII: anche lì il problema continuo diventa un sistema `K u = f`, con le condizioni al contorno che modificano matrice e termine noto. La differenza è che il FEM lavora su elementi e forme qualsiasi, non solo su griglie regolari.
