**pandas** lavora con i **DataFrame**: tabelle con colonne che hanno un nome e un tipo, come un foglio Excel ma programmabile. `read_csv` legge in una riga anche i file "all'italiana" con punto e virgola e virgola decimale.

```python
import io
import pandas as pd

file = io.StringIO("""provino;materiale;d0_mm;Fmax_kN
P1;S235;10,02;34,1
P2;S235;9,98;33,6
P3;S355;10,01;44,9
P4;S355;10,00;45,7
""")
df = pd.read_csv(file, sep=";", decimal=",")
print(df)
print(df.dtypes)
```

`io.StringIO` simula un file: sul computer scriveresti `pd.read_csv("prova.csv", ...)`.

## Prima occhiata ai dati

```python
import io
import pandas as pd
df = pd.read_csv(io.StringIO("t;F\n0;0\n0.5;1.2\n1.0;2.6\n1.5;3.5\n2.0;4.1\n"), sep=";")
print(df.shape)          # (righe, colonne)
print(df.head(3))        # prime righe
print(df.describe())     # statistiche di ogni colonna numerica
```

## Le opzioni che servono davvero

| Problema nel file | Opzione |
|---|---|
| separatore `;` o tab | `sep=";"`, `sep="\t"` |
| virgola decimale | `decimal=","` |
| righe di intestazione della macchina | `skiprows=5` |
| nessuna intestazione | `header=None, names=["t", "F", "x"]` |
| solo alcune colonne | `usecols=["t", "F"]` |
| valori mancanti scritti strani | `na_values=["n.d.", "---"]` |
| codifica di Windows | `encoding="latin-1"` |

```python
import io
import pandas as pd
grezzo = """MACCHINA ZWICK Z100
Operatore: Rossi
Data: 12/11/2026
tempo [s]	forza [N]	corsa [mm]
0,0	0	0,000
0,1	152	0,012
0,2	---	0,025
0,3	455	0,037
"""
df = pd.read_csv(io.StringIO(grezzo), sep="\t", decimal=",", skiprows=3, na_values=["---"])
df.columns = ["t", "F", "x"]          # nomi brevi e senza unità
print(df)
```

## Excel

`read_excel` legge i file `.xlsx` (serve la libreria **openpyxl**); `sheet_name` sceglie il foglio.

```python
import pandas as pd
import openpyxl  # usata da pandas per i file .xlsx

pd.DataFrame({"provino": ["A", "B"], "Rm": [412, 538]}).to_excel("prove.xlsx", index=False, sheet_name="trazione")
df = pd.read_excel("prove.xlsx", sheet_name="trazione")
print(df)
```

> [!trappola] Se una colonna numerica risulta di tipo `object`, c'è del testo nascosto (unità, `"n.d."`, virgole): controlla sempre `df.dtypes` subito dopo la lettura.

> [!ing] I software delle macchine di prova esportano file con righe di intestazione, tab e virgole decimali: `skiprows`, `sep` e `decimal` risolvono il 90% dei casi.
