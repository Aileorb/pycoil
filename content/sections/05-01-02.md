Con un DataFrame scegli colonne per nome, filtri le righe con condizioni (come le maschere NumPy) e crei colonne nuove con formule vettoriali.

```python
import numpy as np
import pandas as pd

df = pd.DataFrame({
    "provino": ["P1", "P2", "P3", "P4", "P5", "P6"],
    "materiale": ["S235", "S235", "S355", "S355", "S275", "S275"],
    "d0": [10.02, 9.98, 10.01, 10.00, 9.99, 10.03],      # mm
    "Fmax": [34.1, 33.6, 44.9, 45.7, 39.0, 38.2],        # kN
})
df["A0"] = np.pi * df["d0"] ** 2 / 4                       # mm²
df["Rm"] = df["Fmax"] * 1000 / df["A0"]                    # MPa
print(df[df["Rm"] > 450][["provino", "materiale", "Rm"]].round(1))
```

## Selezionare, passo per passo

```python
import pandas as pd
df = pd.DataFrame({"mat": ["S235", "S235", "S355", "S355"],
                   "Rm": [412, 398, 521, 509],
                   "A_perc": [28, 30, 22, 21]})
print(df["Rm"].tolist())                 # → [412, 398, 521, 509]   (una colonna)
print(df[["mat", "Rm"]].shape)           # → (4, 2)                 (più colonne: lista di nomi)
print(df[df["Rm"] > 450]["mat"].tolist())   # → ['S355', 'S355']    (righe che rispettano una condizione)
```

Il filtro funziona come le maschere di NumPy: `df["Rm"] > 450` è una colonna di `True/False`, e `df[maschera]` tiene le righe vere. Per più condizioni: `(cond1) & (cond2)`, ciascuna tra parentesi.

## groupby in parole semplici

`groupby` fa tre cose: **divide** la tabella in gruppi secondo una colonna, **calcola** una statistica su ogni gruppo, **riunisce** i risultati in una tabella. È il «subtotale» di Excel.

```python
import pandas as pd
df = pd.DataFrame({"mat": ["S235", "S235", "S355", "S355"], "Rm": [412, 398, 521, 509]})
medie = df.groupby("mat")["Rm"].mean()
print(medie.to_dict())                   # → {'S235': 405.0, 'S355': 515.0}
print(df.groupby("mat")["Rm"].agg(["min", "max", "count"]).loc["S355"].tolist())   # → [509, 521, 2]
```

## loc e iloc

- `df.loc[righe, colonne]` seleziona per **etichetta** (o condizione);
- `df.iloc[i, j]` seleziona per **posizione**.

```python
import pandas as pd
df = pd.DataFrame({"materiale": ["S235", "S355", "S275"], "Rm": [420, 540, 470]}, index=["P1", "P2", "P3"])
print(df.loc["P2", "Rm"])
print(df.loc[df["Rm"] >= 470, "materiale"].tolist())
print(df.iloc[0])          # prima riga
df.loc[df["Rm"] < 450, "esito"] = "basso"
print(df)
```

## groupby: statistiche per gruppo

Il cuore dell'analisi delle prove: raggruppa per materiale (o lotto, o temperatura) e calcola le statistiche.

```python
import numpy as np
import pandas as pd
df = pd.DataFrame({
    "materiale": ["S235"] * 4 + ["S355"] * 4,
    "Rm": [418, 431, 425, 409, 532, 548, 541, 526],
    "A_perc": [27, 29, 28, 26, 22, 21, 23, 22],
})
stat = df.groupby("materiale").agg(
    n=("Rm", "size"),
    Rm_medio=("Rm", "mean"),
    Rm_std=("Rm", "std"),
    A_min=("A_perc", "min"),
)
stat["Rm_k"] = stat["Rm_medio"] - 1.645 * stat["Rm_std"]   # frattile 5% (distribuzione normale)
print(stat.round(1))
```

## Tabelle pivot

```python
import pandas as pd
prove = pd.DataFrame({
    "lotto": ["A", "A", "B", "B", "A", "B"],
    "temperatura": [20, -20, 20, -20, 20, -20],
    "KV_J": [180, 95, 172, 60, 176, 70],          # resilienza Charpy
})
print(prove.pivot_table(index="lotto", columns="temperatura", values="KV_J", aggfunc="mean"))
```

> [!trappola] `df[df.Rm > 450 and df.A > 20]` dà errore: come in NumPy servono `&`, `|` e le parentesi: `df[(df.Rm > 450) & (df.A > 20)]`.

> [!ing] Il valore caratteristico (frattile 5%) è quello che si usa nelle verifiche, non la media: una riga di `groupby` lo calcola per ogni materiale.

## Riepilogo

- `df["col"]` una colonna, `df[["a", "b"]]` più colonne, `df[condizione]` le righe che la rispettano.
- `loc[righe, colonne]` per etichetta, `iloc` per posizione.
- `groupby("col")[...].mean()` (o `.agg([...])`): dividi, calcola, riunisci.
- `pivot_table` per tabelle a doppia entrata.
