Un sensore produce una **serie temporale**: valori con un istante. pandas gestisce date e ore come indice, permette di ricampionare (`resample`) e di calcolare medie mobili (`rolling`); SciPy aggiunge i filtri digitali veri.

```python
import numpy as np
import pandas as pd

ore = pd.date_range("2026-11-12 08:00", periods=8, freq="h")
temp = pd.Series([18.2, 19.0, 21.5, 24.1, 25.3, 25.0, 23.8, 22.1], index=ore, name="T_cuscinetto")
print(temp.resample("2h").mean())
print("massimo alle", temp.idxmax().strftime("%H:%M"))
```

## Media mobile

Con `rolling` ogni punto diventa la media dei vicini: riduce il rumore ma ritarda e smussa i picchi.

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

rng = np.random.default_rng(1)
t = pd.timedelta_range(0, periods=600, freq="100ms")
segnale = 50 + 10 * np.sin(np.arange(600) / 60) + rng.normal(0, 3, 600)
s = pd.Series(segnale, index=t.total_seconds())

fig, ax = plt.subplots(figsize=(6, 2.8))
ax.plot(s, lw=0.6, alpha=0.6, label="grezzo")
ax.plot(s.rolling(25, center=True).mean(), lw=2, label="media mobile 2.5 s")
ax.set(xlabel="t [s]", ylabel="pressione [bar]")
ax.legend()
```

`center=True` centra la finestra ed evita il ritardo.

## Filtro passa-basso di Butterworth

Per separare il segnale utile da un disturbo ad alta frequenza si usa un filtro: `filtfilt` lo applica avanti e indietro, quindi **senza sfasamento**.

```python
import numpy as np
from scipy.signal import butter, filtfilt

fs = 500                                     # Hz
t = np.arange(0, 2, 1 / fs)
utile = np.sin(2 * np.pi * 2 * t)            # 2 Hz
disturbo = 0.3 * np.sin(2 * np.pi * 50 * t)  # 50 Hz di rete
b, a = butter(N=4, Wn=10, btype="low", fs=fs)
filtrato = filtfilt(b, a, utile + disturbo)
print(f"errore massimo dopo il filtro: {np.abs(filtrato - utile)[100:-100].max():.4f}")
```

## Dati a intervalli irregolari

Le acquisizioni reali spesso hanno buchi o tempi irregolari: si ricampionano su una griglia regolare interpolando.

```python
import pandas as pd
t = pd.to_datetime(["2026-11-12 10:00:00", "2026-11-12 10:00:07", "2026-11-12 10:00:21", "2026-11-12 10:00:30"])
v = pd.Series([1.0, 1.7, 3.1, 4.0], index=t)
regolare = v.resample("5s").mean().interpolate("time")
print(regolare)
```

> [!trappola] La media mobile "vede il futuro" solo con `center=True`; per elaborazioni in tempo reale (controllo di una macchina) non si può usare: lì si accetta il ritardo.

> [!ing] Temperature dei cuscinetti, pressioni di un circuito idraulico, correnti di un motore: monitorarle nel tempo è la base della manutenzione predittiva.
