I dati veri sono sporchi: letture mancanti, valori assurdi, righe duplicate. Prima di qualsiasi analisi si **puliscono**, decidendo caso per caso cosa togliere, cosa ricostruire e cosa tenere.

```python
import numpy as np
import pandas as pd

df = pd.DataFrame({"t": [0, 1, 2, 3, 4, 5], "T": [20.1, np.nan, 20.8, 21.2, np.nan, 22.0]})
print(df["T"].isna().sum(), "valori mancanti")
print(df.assign(T_interp=df["T"].interpolate()))
```

## Togliere o riempire

```python
import numpy as np
import pandas as pd
df = pd.DataFrame({"provino": ["A", "B", "C", "D"], "Rm": [420, np.nan, 431, 415], "A_perc": [27, 28, np.nan, 26]})
print(df.dropna())                         # toglie le righe incomplete
print(df.dropna(subset=["Rm"]))            # solo se manca Rm
print(df.fillna({"A_perc": df["A_perc"].median()}))
```

- **misure nel tempo** → `interpolate()` (il valore mancante sta tra i vicini);
- **prove indipendenti** → meglio togliere la riga che inventare un valore;
- **mai** riempire con zero una grandezza fisica: falsa medie e massimi.

## Outlier con l'intervallo interquartile

Un criterio robusto (non influenzato dagli outlier stessi): fuori da `[Q1 − 1.5·IQR, Q3 + 1.5·IQR]`.

```python
import pandas as pd
durezza = pd.Series([212, 208, 215, 210, 211, 290, 209, 213, 150, 212], name="HB")
q1, q3 = durezza.quantile([0.25, 0.75])
iqr = q3 - q1
fuori = (durezza < q1 - 1.5 * iqr) | (durezza > q3 + 1.5 * iqr)
print("sospetti:", durezza[fuori].tolist())
print(f"media con tutto {durezza.mean():.1f}, senza sospetti {durezza[~fuori].mean():.1f}")
```

## Duplicati e tipi sbagliati

```python
import pandas as pd
df = pd.DataFrame({"id": [1, 2, 2, 3], "F": ["120", "135", "135", "1,4e2"]})
df = df.drop_duplicates()
df["F"] = pd.to_numeric(df["F"].str.replace(",", "."), errors="coerce")
print(df, df.dtypes, sep="\n")
```

`errors="coerce"` trasforma in `NaN` ciò che non è un numero, invece di fermarsi: poi decidi tu cosa farne.

> [!trappola] Un outlier non è automaticamente un errore: può essere il dato più interessante (un difetto del materiale, un picco di carico reale). Toglilo solo se sai perché è sbagliato, e scrivilo nella relazione.

> [!ing] Nelle norme di prova (per esempio sulla trazione dei metalli) i provini rotti fuori dal tratto utile si scartano con un criterio dichiarato: è la stessa logica, applicata con il codice.
