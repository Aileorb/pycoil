pandas disegna direttamente con Matplotlib: `df.plot(...)` restituisce gli assi, che poi personalizzi come sempre. Con `groupby` ottieni una curva per gruppo in poche righe.

```python
import numpy as np
import pandas as pd

eps = np.linspace(0, 0.25, 60)
df = pd.DataFrame({
    "eps": np.tile(eps, 2),
    "materiale": ["S235"] * 60 + ["S355"] * 60,
})
fy = df["materiale"].map({"S235": 280, "S355": 400})
fu = df["materiale"].map({"S235": 430, "S355": 540})
df["sigma"] = np.minimum(210e3 * df["eps"], fy + (fu - fy) * (1 - np.exp(-25 * df["eps"])))

ax = df.pivot(index="eps", columns="materiale", values="sigma").plot(figsize=(5, 3))
ax.set(xlabel="ε [-]", ylabel="σ [MPa]", title="Curve di trazione")
ax.grid(alpha=0.3)
```

## Grafici statistici

```python
import pandas as pd
import matplotlib.pyplot as plt
df = pd.DataFrame({
    "materiale": ["S235"] * 5 + ["S275"] * 5 + ["S355"] * 5,
    "Rm": [418, 431, 425, 409, 422, 455, 468, 471, 462, 459, 532, 548, 541, 526, 538],
})
fig, (a1, a2) = plt.subplots(1, 2, figsize=(7, 2.8))
df.boxplot(column="Rm", by="materiale", ax=a1, grid=False)
a1.set(title="", xlabel="", ylabel="Rm [MPa]")
df.groupby("materiale")["Rm"].mean().plot.bar(ax=a2, rot=0, color="tab:blue")
a2.set(ylabel="Rm medio [MPa]", xlabel="")
fig.suptitle("")
fig.tight_layout()
```

## La tabella dei risultati

```python
import pandas as pd
df = pd.DataFrame({
    "materiale": ["S235"] * 3 + ["S355"] * 3,
    "Rm": [418, 431, 425, 532, 548, 541],
    "A_perc": [27, 29, 28, 22, 21, 23],
})
tab = df.groupby("materiale").agg(Rm_medio=("Rm", "mean"), Rm_std=("Rm", "std"), A_medio=("A_perc", "mean")).round(1)
print(tab.to_string())
tab.to_csv("risultati.csv", sep=";", decimal=",")       # per Excel in italiano
print(open("risultati.csv").read())
```

Per una tesi in LaTeX esiste `tab.to_latex()`; per Word conviene esportare in Excel e incollare.

## Salvare figure di qualità

```python
import matplotlib.pyplot as plt
fig, ax = plt.subplots(figsize=(4, 2.5))
ax.plot([0, 1, 2], [0, 1, 4], "o-")
ax.set(xlabel="x [mm]", ylabel="F [kN]")
fig.savefig("figura.pdf", bbox_inches="tight")          # vettoriale: per LaTeX e stampa
fig.savefig("figura.png", dpi=300, bbox_inches="tight") # raster: per Word e slide
import os; print(sorted(f for f in os.listdir() if f.startswith("figura")))
```

> [!trappola] Una figura salvata a 72 dpi sembra perfetta sullo schermo e sgranata in stampa. Usa PDF o almeno 300 dpi, e imposta `figsize` alla dimensione reale in cui comparirà (in pollici).

> [!ing] Una relazione di laboratorio fatta con uno script si rigenera in un secondo quando arrivano nuovi provini: niente più grafici rifatti a mano in Excel.
