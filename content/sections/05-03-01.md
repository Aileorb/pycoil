Dodici provini dello stesso acciaio non danno mai lo stesso snervamento. Media e deviazione standard descrivono il **campione**; l'**intervallo di confidenza** dice dove sta, con buona probabilità, la media **vera** del materiale.

```python
import numpy as np
from scipy import stats

Rp = np.array([372, 365, 381, 359, 376, 368, 384, 362, 370, 378, 366, 374])   # MPa
n, m, s = len(Rp), Rp.mean(), Rp.std(ddof=1)
lo, hi = stats.t.interval(0.95, df=n - 1, loc=m, scale=s / np.sqrt(n))
print(f"media {m:.1f} MPa, s = {s:.1f} MPa")
print(f"media vera tra {lo:.1f} e {hi:.1f} MPa (95%)")
```

Con pochi provini si usa la distribuzione **t di Student** invece della normale: allarga l'intervallo per tenere conto che anche `s` è una stima.

## Distribuzioni: probabilità e quantili

Ogni distribuzione di `scipy.stats` ha gli stessi metodi: `pdf` (densità), `cdf` (probabilità di stare sotto un valore), `ppf` (il valore sotto cui sta una certa probabilità).

```python
from scipy import stats

m, s = 371.25, 7.68                     # MPa, dal lotto della scheda
p = stats.norm.cdf(355, loc=m, scale=s)
f05 = stats.norm.ppf(0.05, loc=m, scale=s)
print(f"P(Rp < 355 MPa) = {p:.1%}")
print(f"frattile 5% = {f05:.1f} MPa")
```

Il **frattile 5%** è l'idea dietro il *valore caratteristico* delle norme: il valore che solo il 5% dei pezzi non raggiunge. Le norme (EN 1990, appendice D) aggiungono un fattore che dipende dal numero di provini, perché anche media e `s` sono incerte.

## Istogramma e curva

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

Rp = np.array([372, 365, 381, 359, 376, 368, 384, 362, 370, 378, 366, 374])
x = np.linspace(340, 400, 200)
fig, ax = plt.subplots(figsize=(5.5, 2.8))
ax.hist(Rp, bins=6, density=True, alpha=0.6, label="provini")
ax.plot(x, stats.norm.pdf(x, Rp.mean(), Rp.std(ddof=1)), label="normale")
ax.set(xlabel="Rp0,2 [MPa]", ylabel="densità")
ax.legend()
```

Con `density=True` l'area dell'istogramma vale 1 e puoi sovrapporgli la densità.

## Weibull: la vita dei componenti

Per vita a fatica e cuscinetti si usa la distribuzione di **Weibull**: la *forma* β dice come cresce il rischio di guasto (β > 1: usura), la *scala* η è la vita caratteristica. La **B10** è la vita raggiunta dal 90% dei pezzi.

```python
import numpy as np
from scipy import stats

vita = np.array([312, 520, 610, 745, 830, 960, 1105, 1240, 1480, 1890])   # ore
beta, _, eta = stats.weibull_min.fit(vita, floc=0)
B10 = stats.weibull_min.ppf(0.10, beta, scale=eta)
print(f"β = {beta:.2f}, η = {eta:.0f} h, B10 = {B10:.0f} h")
```

`floc=0` fissa l'origine a zero: senza, il fit aggiunge un terzo parametro che con pochi dati è instabile.

## Due lotti sono davvero diversi?

Il **test t di Welch** confronta due medie senza supporre varianze uguali. Il *p-value* è la probabilità di vedere una differenza così grande **per caso**, se in realtà i lotti fossero uguali.

```python
import numpy as np
from scipy import stats

lotto_A = np.array([372, 365, 381, 359, 376, 368])
lotto_B = np.array([361, 355, 366, 352, 360, 358])
t, p = stats.ttest_ind(lotto_A, lotto_B, equal_var=False)
print(f"differenza {lotto_A.mean() - lotto_B.mean():.1f} MPa, p = {p:.3f}")
```

Un p piccolo (di solito < 0,05) dice che la differenza difficilmente è casuale; **non** dice che è importante. 10 MPa su 370 possono essere irrilevanti per il progetto.

## Monte Carlo: una catena di tolleranze

Tre pezzi in fila dentro una sede: il gioco finale deve restare sopra 0,1 mm. Invece di sommare i casi peggiori, si simulano centomila assiemi con quote casuali dentro le tolleranze (qui ±3σ):

```python
import numpy as np

rng = np.random.default_rng(1)
N = 100_000
l1 = rng.normal(20.00, 0.10 / 3, N)      # mm, tolleranza ±0,10 = 3σ
l2 = rng.normal(35.00, 0.15 / 3, N)
l3 = rng.normal(15.00, 0.05 / 3, N)
sede = rng.normal(70.30, 0.20 / 3, N)
gioco = sede - (l1 + l2 + l3)
print(f"gioco medio {gioco.mean():.3f} mm, σ = {gioco.std():.3f} mm")
print(f"assiemi con gioco < 0,1 mm: {(gioco < 0.1).mean():.2%}")
```

Il caso peggiore direbbe gioco minimo −0,2 mm, cioè pezzi che non entrano. La simulazione mostra che succede in meno dell'1,5% degli assiemi: è la differenza tra un progetto ipercostoso e uno ragionevole.

> [!trappola] `np.std(x)` divide per `n` (popolazione), `pd.Series(x).std()` e `np.std(x, ddof=1)` per `n − 1` (campione). Con i dati di prova vuoi quasi sempre `ddof=1`.
