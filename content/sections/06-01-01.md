**SymPy** fa calcolo **simbolico**: lavora con le lettere invece che con i numeri, come faresti a mano su un foglio, ma senza errori di segno. Deriva, semplifica, risolve equazioni e alla fine trasforma la formula in una funzione numerica.

```python
import sympy as sp

F, L, E, I, x = sp.symbols("F L E I x", positive=True)
v = F * x**2 * (3 * L - x) / (6 * E * I)     # deformata di una mensola con forza in punta
print(sp.diff(v, x))                          # rotazione
print(sp.simplify(v.subs(x, L)))              # freccia in punta: F L³ / 3EI
```

## Simboli ed espressioni

```python
import sympy as sp
a, b = sp.symbols("a b")
e = (a + b) ** 2
print(sp.expand(e))
print(sp.factor(a**2 - b**2))
print(e.subs({a: 1, b: 2}))
print(sp.Rational(1, 3) + sp.Rational(1, 6))    # frazioni esatte, niente 0.333...
print(sp.sqrt(8), sp.pi.evalf(20))
```

`positive=True` (o `real=True`) dice a SymPy cosa sai delle variabili: le semplificazioni diventano molto migliori.

## Derivate e massimi

```python
import sympy as sp
x, L, q = sp.symbols("x L q", positive=True)
M = q * x * (L - x) / 2                 # momento di una trave appoggiata
dM = sp.diff(M, x)                      # = taglio
x_max = sp.solve(sp.Eq(dM, 0), x)[0]
print("T(x) =", dM, "| massimo in x =", x_max, "| Mmax =", sp.factor(M.subs(x, x_max)))
```

## Risolvere equazioni e sistemi

```python
import sympy as sp
RA, RB, F, a, L = sp.symbols("R_A R_B F a L")
eq = [
    sp.Eq(RA + RB, F),                  # equilibrio verticale
    sp.Eq(RB * L, F * a),               # momenti in A
]
print(sp.solve(eq, [RA, RB]))
```

## Dalla formula ai numeri: lambdify

Ricavi la formula una volta, poi la usi su migliaia di valori con NumPy.

```python
import numpy as np
import sympy as sp
F, L, E, I = sp.symbols("F L E I", positive=True)
freccia = F * L**3 / (3 * E * I)
f = sp.lambdify((F, L, E, I), freccia, "numpy")
L_val = np.array([0.5, 1.0, 1.5])                    # m
print(f(1000, L_val, 210e9, 8.33e-8) * 1000, "mm")
print(sp.latex(freccia))                              # pronta per la relazione in LaTeX
```

> [!trappola] Scrivi `sp.Rational(1, 3)` o `sp.S(1) / 3`, non `1/3`: Python calcolerebbe prima `0.3333` come float e SymPy perderebbe l'esattezza.

> [!ing] Ricavare le formule chiuse con SymPy e poi verificarle numericamente è il modo più sicuro di preparare gli esercizi di Scienza delle costruzioni.
