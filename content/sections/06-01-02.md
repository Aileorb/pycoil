La **linea elastica** `EI v'' = −M(x)` (con `v` positivo verso il basso) si integra due volte e si impongono le condizioni ai vincoli. Con SymPy lo fai esattamente come sul quaderno, ma senza sbagliare un segno.

```python
import sympy as sp
x, L, q, EI, C1, C2 = sp.symbols("x L q EI C1 C2")
M = q * x * (L - x) / 2                       # trave appoggiata, carico uniforme
v = sp.integrate(sp.integrate(-M / EI, x), x) + C1 * x + C2
cost = sp.solve([v.subs(x, 0), v.subs(x, L)], [C1, C2])   # v(0) = v(L) = 0
v = sp.factor(v.subs(cost))
print(v)
print("freccia in mezzeria:", sp.simplify(v.subs(x, L / 2)))   # 5 q L⁴ / 384 EI
```

## Integrali definiti

```python
import sympy as sp
x, b, h = sp.symbols("x b h", positive=True)
# momento d'inerzia di un rettangolo rispetto al baricentro
y = sp.symbols("y")
Ix = sp.integrate(b * y**2, (y, -h / 2, h / 2))
print(Ix)
# energia di deformazione di una mensola a flessione: U = ∫ M² / 2EI dx
F, L, EI = sp.symbols("F L EI", positive=True)
U = sp.integrate((F * (L - x)) ** 2 / (2 * EI), (x, 0, L))
print("U =", U, "→ Castigliano: v = dU/dF =", sp.diff(U, F))
```

Il teorema di Castigliano in due righe: la freccia in punta è la derivata dell'energia rispetto alla forza.

## Equazioni differenziali con dsolve

```python
import sympy as sp
x = sp.symbols("x")
L, q, EI = sp.symbols("L q EI", positive=True)
v = sp.Function("v")
# trave incastro-appoggio: EI v'''' = q con v(0)=v'(0)=0, v(L)=v''(L)=0
eq = sp.Eq(EI * v(x).diff(x, 4), q)
sol = sp.dsolve(eq, v(x), ics={
    v(0): 0, v(x).diff(x).subs(x, 0): 0,
    v(L): 0, v(x).diff(x, 2).subs(x, L): 0,
})
vx = sol.rhs
M_incastro = sp.simplify(-EI * vx.diff(x, 2).subs(x, 0))
print("momento all'incastro:", M_incastro)    # −q L² / 8
```

## Dalla formula al grafico

```python
import numpy as np
import sympy as sp
import matplotlib.pyplot as plt
x, L, q, EI = sp.symbols("x L q EI", positive=True)
v = q * x * (L**3 - 2 * L * x**2 + x**3) / (24 * EI)
f = sp.lambdify(x, v.subs({L: 4, q: 5, EI: 4e3}), "numpy")
xs = np.linspace(0, 4, 100)
fig, ax = plt.subplots(figsize=(5, 2.5))
ax.plot(xs, f(xs) * 1000)
ax.invert_yaxis()
ax.set(xlabel="x [m]", ylabel="v [mm]", title="deformata")
```

> [!trappola] SymPy non sa da solo che `L` è positivo o che `x` sta tra 0 e `L`: dichiaralo nei `symbols` (`positive=True`), altrimenti le radici e i valori assoluti restano complicati.

> [!ing] Le travi iperstatiche (incastro-appoggio, continue) si risolvono con le stesse quattro condizioni al contorno che scrivi all'esame: SymPy fa i conti, tu imposti il problema.
