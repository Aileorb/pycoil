Con il metodo di **Lagrange** le equazioni del moto si ricavano dall'energia: `L = T − V` e, per ogni coordinata `q`, `d/dt(∂L/∂q̇) − ∂L/∂q = Q`. Le derivate sono meccaniche e noiose: perfette per SymPy.

```python
import sympy as sp
t = sp.symbols("t")
m, k = sp.symbols("m k", positive=True)
x = sp.Function("x")(t)

T = m * x.diff(t) ** 2 / 2          # energia cinetica
V = k * x**2 / 2                    # energia potenziale della molla
Lag = T - V
eq = sp.diff(Lag.diff(x.diff(t)), t) - Lag.diff(x)
print(sp.Eq(eq, 0))                 # m x'' + k x = 0
```

## Il pendolo su un carrello

Un carrello di massa `M` su una molla porta un pendolo di massa `m` e lunghezza `l`: due gradi di libertà accoppiati, `x` e `θ`.

```python
import sympy as sp
t = sp.symbols("t")
M, m, l, g, k = sp.symbols("M m l g k", positive=True)
x, th = sp.Function("x")(t), sp.Function("theta")(t)

# posizione e velocità della massa del pendolo
xp, yp = x + l * sp.sin(th), -l * sp.cos(th)
T = M * x.diff(t) ** 2 / 2 + m * (xp.diff(t) ** 2 + yp.diff(t) ** 2) / 2
V = k * x**2 / 2 + m * g * yp
Lag = sp.simplify(T - V)

eqs = [sp.simplify(sp.diff(Lag.diff(q.diff(t)), t) - Lag.diff(q)) for q in (x, th)]
for e in eqs:
    print(sp.Eq(e, 0))
```

## Dalle equazioni simboliche alla simulazione

Si risolve per le accelerazioni, si trasforma in funzione con `lambdify` e si integra con `solve_ivp`.

```python
import numpy as np
import sympy as sp
from scipy.integrate import solve_ivp

t = sp.symbols("t")
M, m, l, g, k = sp.symbols("M m l g k", positive=True)
x, th = sp.Function("x")(t), sp.Function("theta")(t)
xp, yp = x + l * sp.sin(th), -l * sp.cos(th)
Lag = M * x.diff(t) ** 2 / 2 + m * (xp.diff(t) ** 2 + yp.diff(t) ** 2) / 2 - (k * x**2 / 2 + m * g * yp)
eqs = [sp.diff(Lag.diff(q.diff(t)), t) - Lag.diff(q) for q in (x, th)]

a_x, a_th = sp.symbols("a_x a_th")
v_x, v_th, X, TH = sp.symbols("v_x v_th X TH")
sost = {x.diff(t, 2): a_x, th.diff(t, 2): a_th}
sost2 = {x.diff(t): v_x, th.diff(t): v_th, x: X, th: TH}
acc = sp.solve([e.subs(sost).subs(sost2) for e in eqs], [a_x, a_th])
par = {M: 2.0, m: 0.5, l: 0.6, g: 9.81, k: 80.0}
f_acc = sp.lambdify((X, TH, v_x, v_th), [acc[a_x].subs(par), acc[a_th].subs(par)], "numpy")

def f(t, y):
    ax, ath = f_acc(*y)
    return [y[2], y[3], ax, ath]

sol = solve_ivp(f, (0, 10), [0.05, 0.3, 0, 0], max_step=0.01)
print(f"θ massimo = {np.degrees(np.abs(sol.y[1]).max()):.1f}°, x massimo = {np.abs(sol.y[0]).max() * 1000:.1f} mm")
```

> [!nota] SymPy ha anche un modulo dedicato, `sympy.physics.mechanics`, con `LagrangesMethod` e `KanesMethod` per sistemi grandi. Per capire il metodo, però, scriverlo a mano come qui è più istruttivo.

> [!ing] Assorbitori dinamici di vibrazioni, gru a ponte con carico oscillante, sospensioni a più gradi di libertà: è sempre questo schema energia → equazioni → simulazione.
