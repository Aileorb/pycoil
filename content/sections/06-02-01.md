**pint** associa a ogni numero la sua **unità di misura**. Le conversioni diventano automatiche e, soprattutto, sommare grandezze incompatibili dà subito un errore invece di un risultato sbagliato.

```python
import pint
u = pint.UnitRegistry()

F = 12 * u.kN
d = 16 * u.mm
sigma = (4 * F / (3.1416 * d**2)).to(u.MPa)
print(sigma)
print(f"{sigma:.1f~P}")        # formato compatto con simboli
```

Nell'app la libreria si scarica da PyPI al primo uso: la prima esecuzione richiede qualche secondo in più.

## Conversioni

```python
import pint
u = pint.UnitRegistry()
p = 3.5 * u.bar
print(p.to(u.kPa), p.to(u.psi).round(2))
P = 75 * u.kW
n = 1450 / u.minute
C = (P / (2 * 3.14159 * n)).to(u.N * u.m)     # coppia = potenza / velocità angolare
print(f"coppia = {C:.1f}")
print(u.Quantity(20, u.degC).to(u.K))       # le temperature con offset si creano con Quantity
```

## Gli errori che pint ferma

```python
import pint
u = pint.UnitRegistry()
try:
    print(10 * u.mm + 3 * u.N)
except pint.DimensionalityError as e:
    print("Errore:", e)
L = 2 * u.m + 350 * u.mm                      # unità diverse ma compatibili: va bene
print(L, "=", L.to(u.m))
```

## Funzioni con le unità controllate

`u.wraps` dichiara le unità di ingresso e di uscita: chi chiama può usare qualsiasi unità compatibile.

```python
import pint
u = pint.UnitRegistry()

@u.wraps(u.mm, (u.N, u.mm, u.MPa, u.mm**4))
def freccia_mensola(F, L, E, I):
    return F * L**3 / (3 * E * I)

print(freccia_mensola(1 * u.kN, 1.2 * u.m, 210 * u.GPa, 8.5e5 * u.mm**4))
```

## Con NumPy

```python
import numpy as np
import pint
u = pint.UnitRegistry()
v = np.array([10, 20, 30]) * u.km / u.hour
print(v.to(u.m / u.s))
energia = (0.5 * 1200 * u.kg * v**2).to(u.kJ)
print(energia)
```

> [!trappola] Crea **un solo** `UnitRegistry` per programma: grandezze di registri diversi non si possono combinare tra loro.

> [!ing] La sonda Mars Climate Orbiter andò persa nel 1999 per un errore tra libbre-forza e newton. Nei calcoli che passano tra più persone le unità esplicite sono un'assicurazione.
