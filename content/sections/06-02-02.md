Ogni misura ha un'**incertezza**. La libreria `uncertainties` propaga automaticamente le incertezze nei calcoli con la formula del GUM (derivate parziali al primo ordine), tenendo conto anche delle correlazioni.

```python
import math
from uncertainties import ufloat

F = ufloat(12_000, 150)     # N, ± incertezza tipo
d = ufloat(10.00, 0.02)     # mm
sigma = 4 * F / (math.pi * d**2)
print(sigma)                                 # valore ± incertezza
print(f"σ = {sigma:.2uP} MPa")               # 2 cifre significative sull'incertezza
```

## Da dove viene il numero

Per `σ = 4F/(πd²)` la formula del GUM dà
`(uσ/σ)² = (uF/F)² + (2·ud/d)²`: il diametro pesa **doppio** perché compare al quadrato.

```python
import math
from uncertainties import ufloat
F, d = ufloat(12_000, 150, "forza"), ufloat(10.00, 0.02, "diametro")
sigma = 4 * F / (math.pi * d**2)
rel = math.sqrt((150 / 12_000) ** 2 + (2 * 0.02 / 10) ** 2)
print(f"libreria: {sigma.s / sigma.n:.5f}, a mano: {rel:.5f}")
for nome, contributo in sigma.error_components().items():
    print(f"contributo di {nome.tag}: {contributo:.2f} MPa")
```

## Funzioni matematiche e correlazioni

`uncertainties.umath` sostituisce `math`; le variabili che derivano dalla stessa misura restano correlate.

```python
from uncertainties import ufloat, umath
L = ufloat(1000.0, 0.5, "L")        # mm
th = ufloat(30.0, 0.2, "theta")      # gradi
x = L * umath.cos(umath.radians(th))
y = L * umath.sin(umath.radians(th))
print(f"x = {x:.2uP} mm, y = {y:.2uP} mm")
print("x − x =", x - x)                # zero esatto: la libreria sa che è la stessa grandezza
```

## Con gli array: unumpy

```python
import numpy as np
from uncertainties import unumpy as unp
F = unp.uarray([10.2, 20.1, 29.8], [0.1, 0.1, 0.2])   # kN
dL = unp.uarray([0.051, 0.101, 0.150], [0.002, 0.002, 0.002])  # mm
k = F / dL
print(k)
print("valori:", unp.nominal_values(k).round(1), "incertezze:", unp.std_devs(k).round(1))
```

## Verifica con Monte Carlo

Per formule molto non lineari si controlla con una simulazione: si estraggono migliaia di valori e si guarda la dispersione del risultato.

```python
import numpy as np
rng = np.random.default_rng(0)
F = rng.normal(12_000, 150, 100_000)
d = rng.normal(10.00, 0.02, 100_000)
s = 4 * F / (np.pi * d**2)
print(f"Monte Carlo: {s.mean():.1f} ± {s.std():.1f} MPa")
```

> [!trappola] Riporta l'incertezza con 1–2 cifre significative e il valore allo stesso decimale: `152.8 ± 2.0 MPa`, non `152.7887 ± 1.9953`.

> [!ing] In una relazione di laboratorio il risultato senza incertezza non è un risultato: la libreria rende il calcolo automatico e la tabella dei contributi mostra quale strumento migliorare.
