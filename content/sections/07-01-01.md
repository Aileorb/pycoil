**CoolProp** calcola le proprietà di acqua, aria, refrigeranti e molti altri fluidi da equazioni di stato di riferimento. `PropsSI(uscita, nome1, valore1, nome2, valore2, fluido)` sostituisce tabelle del vapore e diagrammi di Mollier. Tutte le unità sono **SI**: K, Pa, J/kg.

```python
from CoolProp.CoolProp import PropsSI

p = 10e5                                      # 10 bar
T_sat = PropsSI("T", "P", p, "Q", 0, "Water") - 273.15
h_l = PropsSI("H", "P", p, "Q", 0, "Water") / 1000
h_v = PropsSI("H", "P", p, "Q", 1, "Water") / 1000
print(f"a 10 bar: T_sat = {T_sat:.2f} °C, calore latente = {h_v - h_l:.1f} kJ/kg")
```

## Le grandezze più usate

| Simbolo | Grandezza | Unità |
|---|---|---|
| `T` | temperatura | K |
| `P` | pressione | Pa |
| `H` | entalpia specifica | J/kg |
| `S` | entropia specifica | J/(kg·K) |
| `D` | densità | kg/m³ |
| `Q` | titolo del vapore | 0…1 |
| `C` | calore specifico cp | J/(kg·K) |

Due proprietà indipendenti fissano lo stato: `("P", p, "T", T)`, `("P", p, "Q", x)`, `("P", p, "S", s)`…

## Il ciclo Rankine semplice

1→2 pompa isentropica, 2→3 caldaia, 3→4 turbina isentropica, 4→1 condensatore.

```python
from CoolProp.CoolProp import PropsSI
f = "Water"
p_cond, p_cald, T3 = 0.1e5, 80e5, 480 + 273.15

h1 = PropsSI("H", "P", p_cond, "Q", 0, f); s1 = PropsSI("S", "P", p_cond, "Q", 0, f)
h2 = PropsSI("H", "P", p_cald, "S", s1, f)
h3 = PropsSI("H", "P", p_cald, "T", T3, f); s3 = PropsSI("S", "P", p_cald, "T", T3, f)
h4 = PropsSI("H", "P", p_cond, "S", s3, f)
x4 = PropsSI("Q", "P", p_cond, "S", s3, f)

L_t, L_p, Q_in = h3 - h4, h2 - h1, h3 - h2
eta = (L_t - L_p) / Q_in
print(f"lavoro turbina {L_t / 1e3:.0f} kJ/kg, pompa {L_p / 1e3:.1f} kJ/kg")
print(f"rendimento = {eta:.3f}, titolo allo scarico = {x4:.3f}")
```

## Il diagramma T-s

```python
import numpy as np
import matplotlib.pyplot as plt
from CoolProp.CoolProp import PropsSI
f = "Water"
T = np.linspace(280, PropsSI("Tcrit", f) - 0.5, 150)
sl = [PropsSI("S", "T", t, "Q", 0, f) / 1e3 for t in T]
sv = [PropsSI("S", "T", t, "Q", 1, f) / 1e3 for t in T]

p_cond, p_cald, T3 = 0.1e5, 80e5, 753.15
s1 = PropsSI("S", "P", p_cond, "Q", 0, f); s3 = PropsSI("S", "P", p_cald, "T", T3, f)
T1 = PropsSI("T", "P", p_cond, "Q", 0, f)
iso = np.linspace(s1, s3, 60)                              # isobara della caldaia
T_iso = [PropsSI("T", "P", p_cald, "S", s, f) for s in iso]

fig, ax = plt.subplots(figsize=(5, 3.4))
ax.plot(sl, T - 273.15, "k", lw=1); ax.plot(sv, T - 273.15, "k", lw=1)
ax.plot(iso / 1e3, np.array(T_iso) - 273.15, "tab:red", label="caldaia")
ax.plot([s3 / 1e3, s3 / 1e3], [T3 - 273.15, T1 - 273.15], "tab:blue", label="turbina")
ax.plot([s1 / 1e3, s3 / 1e3], [T1 - 273.15] * 2, "tab:green", label="condensatore")
ax.set(xlabel="s [kJ/(kg·K)]", ylabel="T [°C]", title="Ciclo Rankine")
ax.legend(fontsize=8)
```

## Aria umida e refrigeranti

```python
from CoolProp.CoolProp import PropsSI, HAPropsSI
# punto di rugiada dell'aria a 25 °C con umidità relativa 60 %
Tdp = HAPropsSI("D", "T", 298.15, "P", 101325, "R", 0.6) - 273.15
print(f"punto di rugiada = {Tdp:.1f} °C")
# pressione di evaporazione del refrigerante R134a a −10 °C
print(f"R134a a −10 °C: {PropsSI('P', 'T', 263.15, 'Q', 1, 'R134a') / 1e5:.2f} bar")
```

> [!trappola] Il titolo `Q` ha senso solo dentro la campana: fuori CoolProp restituisce −1. E ricordati di convertire: °C → K e bar → Pa prima di chiamare `PropsSI`.

> [!ing] Con CoolProp i cicli di Fisica tecnica e Macchine (Rankine con risurriscaldamento, frigoriferi, turbine a gas) si studiano cambiando un parametro alla volta e vedendo subito l'effetto sul rendimento.
