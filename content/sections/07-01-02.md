Il **quadrilatero articolato** (manovella `a`, biella `b`, bilanciere `c`, telaio `d`) è il meccanismo più diffuso. Data la posizione della manovella `θ2`, la chiusura del circuito vettoriale dà la posizione del bilanciere `θ4`. Con NumPy si calcola per tutto il giro in una volta.

```python
import numpy as np

a, b, c, d = 40.0, 120.0, 80.0, 100.0          # mm
s, l = min(a, b, c, d), max(a, b, c, d)
p, q = sorted([a, b, c, d])[1:3]
print("Grashof:", s + l <= p + q, "→ la manovella fa il giro completo" if s + l <= p + q and s == a else "")

th2 = np.radians(np.arange(0, 361, 30))
K1, K2, K3 = d / a, d / c, (a**2 - b**2 + c**2 + d**2) / (2 * a * c)
A = np.cos(th2) - K1 - K2 * np.cos(th2) + K3
B = -2 * np.sin(th2)
C = K1 - (K2 + 1) * np.cos(th2) + K3
th4 = 2 * np.arctan2(-B - np.sqrt(B**2 - 4 * A * C), 2 * A)   # configurazione "aperta"
print((np.degrees(th4) % 360).round(1))     # θ4 in gradi, tra 0 e 360
```

## Controllare con la chiusura del circuito

Il circuito `a·e^{iθ2} + b·e^{iθ3} − c·e^{iθ4} − d = 0` deve chiudersi: è il modo per verificare qualsiasi formula. I numeri complessi rendono tutto compatto.

```python
import numpy as np
a, b, c, d = 40.0, 120.0, 80.0, 100.0
th2 = np.radians(np.linspace(0, 360, 361))
K1, K2, K3 = d / a, d / c, (a**2 - b**2 + c**2 + d**2) / (2 * a * c)
A = np.cos(th2) - K1 - K2 * np.cos(th2) + K3
B, C = -2 * np.sin(th2), K1 - (K2 + 1) * np.cos(th2) + K3
th4 = 2 * np.arctan2(-B - np.sqrt(B**2 - 4 * A * C), 2 * A)

# posizione della biella dal vettore che chiude il circuito
v3 = c * np.exp(1j * th4) + d - a * np.exp(1j * th2)
th3 = np.angle(v3)
errore = np.abs(a * np.exp(1j * th2) + b * np.exp(1j * th3) - c * np.exp(1j * th4) - d)
print(f"|biella| = {np.abs(v3).min():.6f}…{np.abs(v3).max():.6f} (deve essere {b}), errore max {errore.max():.1e}")
print(f"escursione del bilanciere: {np.degrees(th4.max() - th4.min()):.1f}°")
```

## Velocità e angolo di trasmissione

Derivando rispetto al tempo (qui numericamente) ottieni la velocità angolare del bilanciere per `ω2` costante. L'**angolo di trasmissione** tra biella e bilanciere dovrebbe restare sopra 40° circa per una buona trasmissione della forza.

```python
import numpy as np
import matplotlib.pyplot as plt
a, b, c, d = 40.0, 120.0, 80.0, 100.0
w2 = 2 * np.pi * 60 / 60                       # 60 giri/min
th2 = np.radians(np.linspace(0, 360, 721))
K1, K2, K3 = d / a, d / c, (a**2 - b**2 + c**2 + d**2) / (2 * a * c)
A = np.cos(th2) - K1 - K2 * np.cos(th2) + K3
B, C = -2 * np.sin(th2), K1 - (K2 + 1) * np.cos(th2) + K3
th4 = np.unwrap(2 * np.arctan2(-B - np.sqrt(B**2 - 4 * A * C), 2 * A))
th3 = np.angle(c * np.exp(1j * th4) + d - a * np.exp(1j * th2))
w4 = np.gradient(th4, th2) * w2
mu = np.degrees(np.abs(np.angle(np.exp(1j * (th4 - th3)))))
mu = np.minimum(mu, 180 - mu)

fig, (a1, a2) = plt.subplots(2, 1, figsize=(5.5, 4), sharex=True)
a1.plot(np.degrees(th2), w4); a1.set_ylabel("ω4 [rad/s]")
a2.plot(np.degrees(th2), mu, color="tab:orange"); a2.axhline(40, ls=":", color="gray")
a2.set(xlabel="θ2 [°]", ylabel="angolo di trasm. [°]")
print(f"angolo di trasmissione minimo: {mu.min():.1f}°" + ("  → sotto i 40° consigliati: prova un'altra biella" if mu.min() < 40 else ""))
```

## La traiettoria di un punto della biella

```python
import numpy as np
import matplotlib.pyplot as plt
a, b, c, d = 40.0, 120.0, 80.0, 100.0
th2 = np.radians(np.linspace(0, 360, 361))
K1, K2, K3 = d / a, d / c, (a**2 - b**2 + c**2 + d**2) / (2 * a * c)
A = np.cos(th2) - K1 - K2 * np.cos(th2) + K3
B, C = -2 * np.sin(th2), K1 - (K2 + 1) * np.cos(th2) + K3
th4 = 2 * np.arctan2(-B - np.sqrt(B**2 - 4 * A * C), 2 * A)
th3 = np.angle(c * np.exp(1j * th4) + d - a * np.exp(1j * th2))
P = a * np.exp(1j * th2) + 60 * np.exp(1j * (th3 + np.radians(40)))   # punto della biella
fig, ax = plt.subplots(figsize=(4.5, 3.5))
ax.plot(P.real, P.imag); ax.set_aspect("equal")
ax.plot([0, d], [0, 0], "ks-")
ax.set(title="curva di biella", xlabel="x [mm]", ylabel="y [mm]")
```

> [!trappola] Il segno davanti alla radice sceglie la configurazione (aperta o incrociata): se a metà giro il bilanciere "salta", hai cambiato ramo. E se `B² − 4AC < 0` il meccanismo non si può montare in quella posizione.

> [!ing] Tergicristalli, presse, sospensioni, macchine automatiche: progettare un meccanismo vuol dire provare decine di combinazioni di lunghezze e scegliere quella con escursione giusta e buon angolo di trasmissione. Con questo codice è un ciclo `for`.
