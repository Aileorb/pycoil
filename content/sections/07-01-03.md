Un componente sotto carico variabile si rompe per **fatica** anche molto sotto la tensione di rottura. Il carico si descrive con tensione media `σm` e alternata `σa`; il **diagramma di Haigh** confronta il punto di lavoro con la curva limite (Goodman, Gerber, Soderberg).

```python
Su, Sy = 600.0, 420.0          # MPa
Se = 220.0                     # limite di fatica corretto
sm, sa = 150.0, 90.0           # punto di lavoro
n_goodman = 1 / (sa / Se + sm / Su)
n_snerv = Sy / (sa + sm)
print(f"Goodman: n = {n_goodman:.2f}  |  snervamento: n = {n_snerv:.2f}")
```

## Il limite di fatica corretto (fattori di Marin)

Il limite del provino lucidato `Se' ≈ 0.5·Su` va ridotto per finitura superficiale, dimensioni, tipo di carico, temperatura, affidabilità: `Se = ka·kb·kc·kd·ke·Se'`.

```python
import math

def limite_fatica(Su, d, finitura="lavorato", carico="flessione", affidabilita=0.99):
    Se1 = 0.5 * Su if Su <= 1400 else 700.0
    a, b = {"rettificato": (1.58, -0.085), "lavorato": (4.51, -0.265), "laminato a caldo": (57.7, -0.718)}[finitura]
    ka = a * Su**b
    kb = 1.24 * d**-0.107 if 2.79 <= d <= 51 else 1.51 * d**-0.157   # d in mm
    kc = {"flessione": 1.0, "assiale": 0.85, "torsione": 0.59}[carico]
    ke = {0.5: 1.0, 0.9: 0.897, 0.99: 0.814, 0.999: 0.753}[affidabilita]
    return ka * kb * kc * ke * Se1

Se = limite_fatica(600, d=30)
print(f"Se = {Se:.1f} MPa (Se' = 300 MPa)")
```

## Il diagramma di Haigh

```python
import numpy as np
import matplotlib.pyplot as plt
Su, Sy, Se = 600.0, 420.0, 200.0
sm = np.linspace(0, Su, 200)
fig, ax = plt.subplots(figsize=(5.2, 3.4))
ax.plot(sm, Se * (1 - sm / Su), label="Goodman")
ax.plot(sm, Se * (1 - (sm / Su) ** 2), label="Gerber")
ax.plot(sm, np.clip(Se * (1 - sm / Sy), 0, None), label="Soderberg")
ax.plot(sm, np.clip(Sy - sm, 0, None), "k--", lw=1, label="snervamento (Langer)")
ax.plot(150, 90, "ro"); ax.annotate("punto di lavoro", (150, 90), xytext=(170, 130), arrowprops=dict(arrowstyle="->"))
ax.plot([0, 150 * 2], [0, 90 * 2], ":", color="gray")   # retta di carico a σa/σm costante
ax.set(xlabel="σm [MPa]", ylabel="σa [MPa]", xlim=(0, Su), ylim=(0, Sy))
ax.legend(fontsize=8)
```

## Dal carico alle tensioni

Un albero di diametro `d` con momento flettente che oscilla tra `Mmin` e `Mmax`, con un intaglio di fattore `Kf`:

```python
import math
d, Kf = 30.0, 1.6                    # mm
Mmax, Mmin = 400e3, -150e3           # N·mm
W = math.pi * d**3 / 32
s_max, s_min = Kf * Mmax / W, Kf * Mmin / W
sm, sa = (s_max + s_min) / 2, (s_max - s_min) / 2
Su, Se = 600.0, 200.0
n = 1 / (sa / Se + sm / Su)
print(f"σm = {sm:.1f} MPa, σa = {sa:.1f} MPa, coefficiente di sicurezza a fatica n = {n:.2f}")
```

## Vita a termine: la curva di Wöhler

Sotto il ginocchio la curva S-N si approssima con `σa = a·N^b` tra 10³ e 10⁶ cicli.

```python
import math
Su, Se, f = 600.0, 200.0, 0.85            # f: frazione di Su a 1000 cicli
a = (f * Su) ** 2 / Se
b = -math.log10(f * Su / Se) / 3
for sa in [400, 300, 250]:
    N = (sa / a) ** (1 / b)
    print(f"σa = {sa} MPa → N ≈ {N:,.0f} cicli")
```

> [!trappola] Il fattore d'intaglio `Kf` va applicato alle tensioni (o, in alcuni testi, solo all'alternata): usa sempre la convenzione del tuo corso e dichiarala. E controlla sempre anche lo snervamento al primo ciclo.

> [!ing] Alberi di trasmissione, molle, bulloni sotto carico variabile: la verifica a fatica è il cuore di Costruzione di macchine, e con una funzione ben fatta la ripeti su ogni sezione critica.
