Il **metodo degli elementi finiti** divide la struttura in elementi semplici, scrive per ciascuno la matrice di rigidezza, le **assembla** in un sistema globale `K u = F`, impone i vincoli e risolve. Il caso più semplice: una barra in trazione.

```python
import numpy as np

E, A, L, n = 210e3, 100.0, 1000.0, 4        # MPa, mm², mm, elementi
le = L / n
k = E * A / le * np.array([[1, -1], [-1, 1]])  # rigidezza di un elemento
K = np.zeros((n + 1, n + 1))
for e in range(n):
    K[e:e + 2, e:e + 2] += k                    # assemblaggio
F = np.zeros(n + 1); F[-1] = 10_000.0          # 10 kN in fondo
u = np.zeros(n + 1)
u[1:] = np.linalg.solve(K[1:, 1:], F[1:])      # nodo 0 incastrato
print(u.round(4), "mm  (atteso FL/EA =", 10_000 * L / (E * A), "mm)")
```

## Carico distribuito e confronto con la soluzione esatta

Una barra appesa sotto il peso proprio (carico distribuito `p` per unità di lunghezza): il vettore dei carichi nodali equivalenti si ottiene integrando le funzioni di forma, cioè `p·le/2` a ciascun nodo dell'elemento.

```python
import numpy as np
import matplotlib.pyplot as plt

E, A, L, p = 210e3, 100.0, 1000.0, 5.0         # p in N/mm
x_ex = np.linspace(0, L, 200)
u_ex = p / (E * A) * (L * x_ex - x_ex**2 / 2)

fig, ax = plt.subplots(figsize=(5, 3))
ax.plot(x_ex, u_ex * 1000, "k", label="esatta")
for n in [1, 2, 4]:
    le = L / n
    K = np.zeros((n + 1, n + 1)); F = np.zeros(n + 1)
    for e in range(n):
        K[e:e + 2, e:e + 2] += E * A / le * np.array([[1, -1], [-1, 1]])
        F[e:e + 2] += p * le / 2
    u = np.zeros(n + 1); u[1:] = np.linalg.solve(K[1:, 1:], F[1:])
    ax.plot(np.linspace(0, L, n + 1), u * 1000, "o-", label=f"{n} elementi")
ax.set(xlabel="x [mm]", ylabel="u [µm]"); ax.legend()
```

Gli spostamenti ai nodi coincidono con quelli esatti; tra i nodi l'elemento lineare approssima la parabola con una spezzata.

## Tensioni negli elementi

La deformazione in ogni elemento è `(u_j − u_i)/le`, costante: la tensione esce "a gradini".

```python
import numpy as np
E, A, L, p, n = 210e3, 100.0, 1000.0, 5.0, 5
le = L / n
K = np.zeros((n + 1, n + 1)); F = np.zeros(n + 1)
for e in range(n):
    K[e:e + 2, e:e + 2] += E * A / le * np.array([[1, -1], [-1, 1]])
    F[e:e + 2] += p * le / 2
u = np.zeros(n + 1); u[1:] = np.linalg.solve(K[1:, 1:], F[1:])
sigma = E * np.diff(u) / le
x_medio = (np.arange(n) + 0.5) * le
print("σ FEM   :", sigma.round(2))
print("σ esatta:", (p * (L - x_medio) / A).round(2))      # nel punto medio coincidono
```

## Reazioni vincolari

Una volta noti tutti gli spostamenti, la riga del nodo vincolato dà la reazione: `R = K[0, :] @ u − F[0]`.

```python
import numpy as np
E, A, L, n = 210e3, 100.0, 1000.0, 3
le = L / n
K = np.zeros((n + 1, n + 1))
for e in range(n):
    K[e:e + 2, e:e + 2] += E * A / le * np.array([[1, -1], [-1, 1]])
F = np.array([0, 2000.0, 0, 5000.0])
u = np.zeros(n + 1); u[1:] = np.linalg.solve(K[1:, 1:], F[1:])
print("reazione all'incastro:", (K[0] @ u - F[0]).round(6), "N")     # −7000 N
```

> [!nota] Tutti i codici FEM, anche quelli commerciali, fanno esattamente questi passi: rigidezza dell'elemento, assemblaggio, vincoli, soluzione, post-processing. Cambiano solo il tipo di elemento e la dimensione del problema.

> [!trappola] Senza vincoli la matrice `K` è singolare (la barra può traslare liberamente): `np.linalg.solve` darebbe errore. Per questo si eliminano righe e colonne dei gradi di libertà bloccati.
