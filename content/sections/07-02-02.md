In una **travatura reticolare** ogni asta lavora solo a sforzo normale. L'elemento è la barra della sezione precedente, ma **ruotata** nel piano: ogni nodo ha due gradi di libertà (`ux`, `uy`) e la matrice dell'elemento dipende da coseno e seno dell'inclinazione.

```python
import numpy as np

def k_asta(xi, yi, xj, yj, EA):
    L = np.hypot(xj - xi, yj - yi)
    c, s = (xj - xi) / L, (yj - yi) / L
    v = np.array([-c, -s, c, s])
    return EA / L * np.outer(v, v), L, v

k, L, _ = k_asta(0, 0, 3, 4, 1.0)
print("L =", L)
print((k * L).round(3))
```

## Una capriata completa

Nodi, aste, vincoli e carichi in tabelle; l'assemblaggio mette ogni matrice 4×4 al posto giusto nella matrice globale.

```python
import numpy as np

nodi = np.array([[0, 0], [2, 0], [4, 0], [1, 1.5], [3, 1.5]], dtype=float)   # m
aste = [(0, 1), (1, 2), (0, 3), (3, 1), (1, 4), (4, 2), (3, 4)]
EA = 210e9 * 6e-4                                                             # N
ndof = 2 * len(nodi)
K = np.zeros((ndof, ndof))
for i, j in aste:
    L = np.linalg.norm(nodi[j] - nodi[i])
    c, s = (nodi[j] - nodi[i]) / L
    v = np.array([-c, -s, c, s])
    dofs = [2 * i, 2 * i + 1, 2 * j, 2 * j + 1]
    K[np.ix_(dofs, dofs)] += EA / L * np.outer(v, v)

F = np.zeros(ndof)
F[2 * 3 + 1] = -10e3; F[2 * 4 + 1] = -10e3        # 10 kN sui nodi superiori
vincolati = [0, 1, 2 * 2 + 1]                       # cerniera in 0, carrello in 2
liberi = np.setdiff1d(np.arange(ndof), vincolati)
u = np.zeros(ndof)
u[liberi] = np.linalg.solve(K[np.ix_(liberi, liberi)], F[liberi])

for i, j in aste:
    L = np.linalg.norm(nodi[j] - nodi[i])
    c, s = (nodi[j] - nodi[i]) / L
    N = EA / L * np.array([-c, -s, c, s]) @ u[[2 * i, 2 * i + 1, 2 * j, 2 * j + 1]]
    N = 0.0 if abs(N) < 1e-6 else N              # zero numerico
    stato = "scarica" if N == 0 else "trazione" if N > 0 else "compressione"
    print(f"asta {i}-{j}: N = {N / 1e3:7.2f} kN  {stato}")
R = K @ u - F
print("reazioni verticali:", (R[[1, 5]] / 1e3).round(2), "kN")
```

`np.ix_` seleziona il blocco righe×colonne: è il modo NumPy di fare l'assemblaggio e di estrarre la parte libera.

## Disegnare la deformata

```python
import numpy as np
import matplotlib.pyplot as plt

nodi = np.array([[0, 0], [2, 0], [4, 0], [1, 1.5], [3, 1.5]], dtype=float)
aste = [(0, 1), (1, 2), (0, 3), (3, 1), (1, 4), (4, 2), (3, 4)]
EA = 210e9 * 6e-4
ndof = 2 * len(nodi)
K = np.zeros((ndof, ndof))
for i, j in aste:
    d = nodi[j] - nodi[i]; L = np.linalg.norm(d); c, s = d / L
    v = np.array([-c, -s, c, s]); dofs = [2 * i, 2 * i + 1, 2 * j, 2 * j + 1]
    K[np.ix_(dofs, dofs)] += EA / L * np.outer(v, v)
F = np.zeros(ndof); F[[7, 9]] = -10e3
lib = np.setdiff1d(np.arange(ndof), [0, 1, 5])
u = np.zeros(ndof); u[lib] = np.linalg.solve(K[np.ix_(lib, lib)], F[lib])

scala = 300
def_nodi = nodi + scala * u.reshape(-1, 2)
fig, ax = plt.subplots(figsize=(5.5, 2.6))
for i, j in aste:
    ax.plot(*nodi[[i, j]].T, color="lightgray", lw=3)
    ax.plot(*def_nodi[[i, j]].T, color="tab:blue")
ax.set_aspect("equal"); ax.set_title(f"deformata (×{scala})")
print(f"spostamento verticale massimo: {u[1::2].min() * 1000:.3f} mm")
```

> [!trappola] Una travatura labile (aste mancanti, vincoli insufficienti) dà una matrice singolare: `LinAlgError`. Controlla sempre la condizione `aste + vincoli ≥ 2 × nodi`.

> [!ing] Gru, tralicci, capriate, telai di macchine: con poche decine di righe hai un piccolo solutore che puoi verificare con il metodo dei nodi visto a lezione.
