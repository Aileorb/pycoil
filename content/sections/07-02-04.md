Con **CadQuery** un pezzo meccanico si descrive con il codice: schizzi, estrusioni, fori, raccordi. Il vantaggio rispetto al CAD con il mouse è la **parametricità vera**: una famiglia di pezzi nasce da una tabella di dimensioni, e il calcolo può guidare direttamente la geometria.

```python norun
import cadquery as cq

flangia = (
    cq.Workplane("XY")
    .circle(60).extrude(12)                      # disco Ø120 × 12
    .faces(">Z").workplane().hole(30)            # foro centrale Ø30
    .faces(">Z").workplane()
    .polarArray(45, 0, 360, 6).hole(9)           # 6 fori Ø9 su Ø90
    .edges("%CIRCLE and >Z").fillet(1.0)
)
cq.exporters.export(flangia, "flangia.step")
```

CadQuery si installa solo sul computer (`pip install cadquery`); il visualizzatore **CQ-editor** mostra il modello mentre scrivi.

## La tabella prima della geometria

La parte di calcolo si può (e si deve) separare dalla geometria: qui la famiglia di flange nasce dai diametri dei tubi, con interassi e numero di bulloni scelti con regole semplici. Questa parte gira anche nell'app.

```python
import math

def flangia_per_tubo(d_tubo):
    """Dimensioni indicative di una flangia piana per un tubo di diametro esterno d_tubo (mm)."""
    D = round(2.2 * d_tubo + 40, -1)               # diametro esterno
    interasse = round((D + d_tubo) / 2, -1)        # diametro dei fori
    n_bulloni = max(4, 4 * math.ceil(interasse * math.pi / 120 / 4))
    foro = 14 if d_tubo < 60 else 18
    spessore = max(10, round(0.12 * d_tubo + 8))
    return dict(d_tubo=d_tubo, D=D, interasse=interasse, n=n_bulloni, foro=foro, s=spessore)

print(f"{'tubo':>6}{'D':>6}{'Øfori':>7}{'n':>4}{'foro':>6}{'s':>5}")
for d in [33.7, 48.3, 60.3, 88.9, 114.3]:
    f = flangia_per_tubo(d)
    print(f"{f['d_tubo']:>6}{f['D']:>6.0f}{f['interasse']:>7.0f}{f['n']:>4}{f['foro']:>6}{f['s']:>5}")
```

## Dalla tabella ai file STEP

```python norun
import cadquery as cq

def modello(f):
    return (
        cq.Workplane("XY").circle(f["D"] / 2).extrude(f["s"])
        .faces(">Z").workplane().hole(f["d_tubo"] + 1)
        .faces(">Z").workplane().polarArray(f["interasse"] / 2, 0, 360, f["n"]).hole(f["foro"])
    )

for d in [33.7, 48.3, 60.3, 88.9, 114.3]:
    f = flangia_per_tubo(d)
    cq.exporters.export(modello(f), f"flangia_DN{round(d)}.step")
```

Cinque file STEP pronti per l'assieme o per la produzione, generati in un secondo e sempre coerenti con la tabella.

## Selettori: scegliere facce e spigoli

| Selettore | Significato |
|---|---|
| `">Z"` | la faccia più in alto lungo Z |
| `"<X"` | la più a sinistra lungo X |
| `"\|Z"` | spigoli paralleli a Z |
| `"%CIRCLE"` | spigoli circolari |
| `">Z and %CIRCLE"` | combinazioni |
