Uno strumento vero si lancia dal terminale con dei parametri: `python verifica.py prova.csv --fy 355`. Il modulo **argparse** legge gli argomenti, genera l'aiuto (`--help`) e controlla i tipi.

```python
import argparse

parser = argparse.ArgumentParser(description="Verifica a trazione di una barra")
parser.add_argument("forza", type=float, help="forza di trazione [kN]")
parser.add_argument("--diametro", "-d", type=float, default=20, help="diametro [mm]")
parser.add_argument("--fy", type=float, default=355, help="tensione di snervamento [MPa]")

args = parser.parse_args(["85", "-d", "18"])     # sul computer: parser.parse_args()
sigma = args.forza * 1000 / (3.14159 * args.diametro**2 / 4)
print(f"σ = {sigma:.1f} MPa, utilizzo {sigma / (args.fy / 1.05):.0%}")
```

Nell'app passiamo gli argomenti come lista; da terminale `parse_args()` li legge da soli.

## La struttura di uno script

```python
import argparse
import sys

def calcola(forza_kN, d_mm, fy):
    A = 3.14159 * d_mm**2 / 4
    sigma = forza_kN * 1000 / A
    return sigma, sigma / (fy / 1.05)

def main(argv=None):
    p = argparse.ArgumentParser(prog="verifica")
    p.add_argument("forze", type=float, nargs="+", help="una o più forze [kN]")
    p.add_argument("-d", "--diametro", type=float, default=20)
    p.add_argument("--fy", type=float, choices=[235, 275, 355], default=355)
    a = p.parse_args(argv)
    peggiore = 0
    for F in a.forze:
        s, u = calcola(F, a.diametro, a.fy)
        print(f"F = {F:6.1f} kN   σ = {s:6.1f} MPa   {'OK' if u <= 1 else 'NON VERIFICATA'}")
        peggiore = max(peggiore, u)
    return 0 if peggiore <= 1 else 1             # codice di uscita: utile negli automatismi

codice = main(["50", "80", "120", "--fy", "275"])
print("codice di uscita:", codice)
# in fondo al file vero: if __name__ == "__main__": sys.exit(main())
```

## Un report automatico in HTML

Un report HTML si apre in qualsiasi browser, contiene tabelle e grafici, e si stampa in PDF.

```python
import base64, io
from datetime import date
import matplotlib.pyplot as plt

forze = [50, 80, 120, 95]
utilizzi = [f * 1000 / (3.14159 * 20**2 / 4) / (275 / 1.05) for f in forze]

fig, ax = plt.subplots(figsize=(4, 2.4))
ax.bar(range(1, len(forze) + 1), utilizzi, color=["tab:green" if u <= 1 else "tab:red" for u in utilizzi])
ax.axhline(1, color="k", lw=0.8); ax.set(xlabel="caso di carico", ylabel="utilizzo")
buf = io.BytesIO(); fig.savefig(buf, format="png", dpi=150, bbox_inches="tight")
img = base64.b64encode(buf.getvalue()).decode()

righe = "".join(f"<tr><td>{i}</td><td>{f}</td><td>{u:.2f}</td></tr>" for i, (f, u) in enumerate(zip(forze, utilizzi), 1))
html = f"""<!doctype html><meta charset="utf-8"><title>Verifica</title>
<h1>Verifica a trazione</h1><p>Data: {date.today():%d/%m/%Y}</p>
<table border=1 cellpadding=4><tr><th>Caso</th><th>F [kN]</th><th>Utilizzo</th></tr>{righe}</table>
<img src="data:image/png;base64,{img}">"""
open("report.html", "w", encoding="utf-8").write(html)
print(f"report.html scritto: {len(html) // 1024} kB, {sum(u > 1 for u in utilizzi)} casi non verificati")
```

## logging invece di print

```python
import logging
logging.basicConfig(level=logging.INFO, format="%(levelname)s %(message)s", force=True)
log = logging.getLogger("verifica")
log.info("letti %d casi di carico", 4)
log.warning("caso %d oltre il limite (utilizzo %.2f)", 3, 1.25)
log.debug("questo non compare: livello troppo basso")
```

Con `logging` decidi da fuori quanto dettaglio vedere, e puoi scrivere su file senza cambiare il codice.

> [!trappola] Non mettere percorsi assoluti nel codice (`C:\Users\Mario\...`): passali come argomenti o usa percorsi relativi con `pathlib`. Lo script funzionerà anche sul computer di un collega.

> [!ing] Uno script con argomenti e un report automatico trasforma un calcolo fatto una volta in uno strumento che tutto l'ufficio tecnico può usare.
