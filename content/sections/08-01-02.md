In azienda molti dati vivono in Excel. **openpyxl** legge e scrive file `.xlsx` mantenendo formule, formati e più fogli: puoi compilare in automatico un modulo, raccogliere dati da cento file o produrre un foglio di calcolo per chi non usa Python.

```python
from openpyxl import Workbook

wb = Workbook()
ws = wb.active
ws.title = "Verifiche"
ws.append(["Elemento", "N [kN]", "A [mm²]", "σ [MPa]"])
for nome, N, A in [("tirante 1", 85, 314), ("tirante 2", 120, 452), ("puntone", 60, 380)]:
    r = ws.max_row + 1
    ws.append([nome, N, A, f"=B{r}*1000/C{r}"])   # formula Excel: si aggiorna in Excel
wb.save("verifiche.xlsx")
print("righe scritte:", ws.max_row)
```

Nell'app openpyxl si scarica da PyPI al primo uso.

## Formati e larghezze

```python
from openpyxl import Workbook
from openpyxl.styles import Font, PatternFill, Alignment
from openpyxl.formatting.rule import CellIsRule

wb = Workbook(); ws = wb.active
ws.append(["Elemento", "Utilizzo"])
for riga in [("trave A", 0.82), ("colonna 3", 1.07), ("controvento", 0.45)]:
    ws.append(riga)
for c in ws[1]:
    c.font = Font(bold=True, color="FFFFFF")
    c.fill = PatternFill("solid", fgColor="1F4E78")
    c.alignment = Alignment(horizontal="center")
for c in ws["B"][1:]:
    c.number_format = "0%"
ws.column_dimensions["A"].width = 16
rosso = PatternFill("solid", fgColor="F4B6B6")
ws.conditional_formatting.add("B2:B100", CellIsRule(operator="greaterThan", formula=["1"], fill=rosso))
ws.freeze_panes = "A2"
wb.save("utilizzi.xlsx")
print("salvato con formattazione condizionale")
```

## Leggere un file esistente

```python
from openpyxl import Workbook, load_workbook

wb = Workbook(); ws = wb.active                 # creo un file d'esempio
ws.append(["provino", "Rm"]); ws.append(["P1", 418]); ws.append(["P2", 431]); ws.append(["P3", None])
wb.save("prove.xlsx")

wb = load_workbook("prove.xlsx", data_only=True)   # data_only: valori invece delle formule
ws = wb["Sheet"]
valori = [r[1] for r in ws.iter_rows(min_row=2, values_only=True) if r[1] is not None]
print(f"{len(valori)} provini, Rm medio {sum(valori) / len(valori):.1f} MPa")
```

`data_only=True` legge l'**ultimo valore calcolato da Excel**: un file scritto da openpyxl e mai aperto in Excel non ha ancora valori per le formule.

## Raccogliere molti file

```python
from pathlib import Path
from openpyxl import Workbook, load_workbook

cartella = Path("lotti"); cartella.mkdir(exist_ok=True)
for i, rm in enumerate([[412, 420], [433, 429, 441], [418]], 1):   # tre file d'esempio
    wb = Workbook(); ws = wb.active; ws.append(["Rm"]); [ws.append([v]) for v in rm]
    wb.save(cartella / f"lotto_{i}.xlsx")

riepilogo = Workbook(); out = riepilogo.active; out.append(["file", "n", "Rm medio"])
for f in sorted(cartella.glob("*.xlsx")):
    v = [r[0] for r in load_workbook(f).active.iter_rows(min_row=2, values_only=True)]
    out.append([f.name, len(v), round(sum(v) / len(v), 1)])
riepilogo.save("riepilogo.xlsx")
for r in out.iter_rows(values_only=True):
    print(r)
```

> [!trappola] openpyxl non calcola le formule: le scrive, e le calcola Excel all'apertura. Se ti servono i risultati in Python, calcolali in Python e scrivi i valori (o entrambi).

> [!ing] Compilare in automatico il foglio di collaudo o il modulo di non conformità, partendo dai dati della macchina, è uno dei primi lavori che un ingegnere che sa Python si vede affidare.
