Un **Arduino** (o un ESP32) con un sensore manda misure sulla porta seriale; Python le legge con **pySerial**, le salva e le disegna. È il modo più economico di fare un banco prova in laboratorio o per la tesi.

Sul microcontrollore basta stampare una riga per misura:

```text
// sketch Arduino: una riga "tempo_ms;valore" ogni 10 ms
void setup() { Serial.begin(115200); }
void loop() {
  Serial.print(millis()); Serial.print(';'); Serial.println(analogRead(A0));
  delay(10);
}
```

## Leggere la seriale (sul computer)

```python norun
import serial                     # pip install pyserial

with serial.Serial("COM3", 115200, timeout=1) as porta:    # Linux/macOS: "/dev/ttyACM0"
    porta.reset_input_buffer()
    for _ in range(500):
        riga = porta.readline().decode(errors="ignore").strip()
        if riga:
            t_ms, valore = riga.split(";")
            print(int(t_ms), int(valore))
```

Per trovare la porta: `python -m serial.tools.list_ports`.

## Il parsing, provato qui

La parte delicata è interpretare righe incomplete o corrotte (all'avvio, o se il cavo si muove). La proviamo con una "seriale finta".

```python
import random

def seriale_finta(n, seed=1):
    """Simula le righe che arriverebbero da Arduino, con qualche errore."""
    rnd = random.Random(seed)
    yield "Avvio sensore..."
    for i in range(n):
        v = int(512 + 300 * __import__("math").sin(i / 15) + rnd.gauss(0, 8))
        riga = f"{i * 10};{v}"
        yield riga if rnd.random() > 0.03 else riga[: rnd.randint(1, len(riga) - 1)]

def leggi_misure(righe, vref=5.0, bit=10):
    dati, scarti = [], 0
    for r in righe:
        parti = r.strip().split(";")
        if len(parti) != 2 or not all(p.isdigit() for p in parti):
            scarti += 1
            continue
        t, adc = int(parti[0]) / 1000, int(parti[1])
        dati.append((t, adc * vref / (2**bit - 1)))       # conversione ADC → volt
    return dati, scarti

dati, scarti = leggi_misure(seriale_finta(300))
print(f"{len(dati)} misure valide, {scarti} righe scartate")
print("prime:", [(t, round(v, 3)) for t, v in dati[:3]])
```

## Dalla tensione alla grandezza fisica

```python
import numpy as np
# taratura di un sensore di forza: due punti noti
v_tar = np.array([0.52, 3.87])          # volt letti
F_tar = np.array([0.0, 200.0])          # newton applicati (pesi campione)
k, q = np.polyfit(v_tar, F_tar, 1)
letture = np.array([0.55, 1.20, 2.75, 3.90])
print("forze [N]:", (k * letture + q).round(1))
```

## Salvare mentre acquisisci

```python
import csv, time
from pathlib import Path

file = Path("acquisizione.csv")
with file.open("w", newline="") as f:
    w = csv.writer(f, delimiter=";")
    w.writerow(["t_s", "V"])
    for i in range(5):                        # al posto del ciclo sulla seriale
        w.writerow([round(i * 0.01, 3), round(2.5 + 0.1 * i, 3)])
        f.flush()                             # i dati sono al sicuro anche se il programma si interrompe
print(file.read_text())
```

> [!desktop] La lettura della porta seriale si fa al computer con la scheda collegata via USB; il parsing e l'elaborazione si possono provare qui.

> [!trappola] Arduino si riavvia quando apri la porta seriale: le prime righe possono essere spazzatura. Scartale (come fa `leggi_misure`) e aspetta un attimo prima di iniziare la prova.
