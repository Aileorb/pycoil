Prima regola: **misura, non indovinare**. Il collo di bottiglia raramente è dove pensi. `timeit` cronometra piccoli frammenti, `cProfile` dice quali funzioni consumano il tempo in un programma intero.

```python
import timeit
import numpy as np

x = np.random.default_rng(0).random(100_000)
t_ciclo = timeit.timeit(lambda: sum(v * v for v in x), number=5) / 5
t_numpy = timeit.timeit(lambda: np.dot(x, x), number=5) / 5
print(f"ciclo: {t_ciclo * 1000:.1f} ms   numpy: {t_numpy * 1000:.3f} ms   → {t_ciclo / t_numpy:.0f}× più veloce")
```

## Profilare un programma

```python
import cProfile, pstats, io
import numpy as np

def assembla(n):
    K = np.zeros((n, n))
    for e in range(n - 1):
        for i in range(2):
            for j in range(2):
                K[e + i, e + j] += (1 if i == j else -1)
    return K

def risolvi(n):
    K = assembla(n); K[0, 0] += 1
    return np.linalg.solve(K, np.ones(n))

pr = cProfile.Profile(); pr.enable()
risolvi(600)
pr.disable()
s = io.StringIO(); pstats.Stats(pr, stream=s).sort_stats("cumulative").print_stats(4)
print("\n".join(s.getvalue().splitlines()[:14]))
```

## Le ricette che contano

1. **Vettorizza**: operazioni su interi array invece di cicli.
2. **Non ricalcolare**: sposta fuori dai cicli ciò che non cambia, usa `lru_cache`.
3. **Strutture giuste**: `set` e `dict` cercano in tempo costante, le liste no.
4. **Matrici sparse** per il FEM: con migliaia di nodi una matrice piena non sta nemmeno in memoria.

```python
import timeit
codici = list(range(50_000))
insieme = set(codici)
print("lista:", round(timeit.timeit(lambda: 49_999 in codici, number=200) * 1000, 2), "ms")
print("set:  ", round(timeit.timeit(lambda: 49_999 in insieme, number=200) * 1000, 3), "ms")
```

## Matrici sparse

```python
import numpy as np
import scipy.sparse as sps
from scipy.sparse.linalg import spsolve

n = 20_000
diag = np.full(n, 2.0); diag[-1] = 1.0
K = sps.diags([-np.ones(n - 1), diag, -np.ones(n - 1)], [-1, 0, 1], format="csc")
u = spsolve(K, np.full(n, 1e-3))
print(f"{n} incognite, elementi non nulli: {K.nnz} su {n * n:,}")
print(f"memoria sparsa ≈ {K.data.nbytes / 1e6:.2f} MB, piena sarebbe {n * n * 8 / 1e9:.1f} GB")
```

> [!nota] Esistono strumenti per compilare il Python numerico (Numba, Cython): utili, ma solo dopo aver vettorizzato e profilato. Nella maggior parte dei casi NumPy e SciPy bastano.

> [!trappola] Ottimizzare codice che non è il collo di bottiglia è tempo perso e codice più difficile da leggere. Profila, sistema la funzione che pesa di più, misura di nuovo.
