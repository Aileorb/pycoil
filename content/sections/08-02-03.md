Con **scikit-learn** costruisci modelli che imparano dai dati: prevedere l'usura di un utensile dai parametri di taglio, la vita a fatica da tensione e finitura, un guasto dalle vibrazioni. Lo schema è sempre `modello.fit(X, y)` e poi `modello.predict(X_nuovi)`.

```python
import numpy as np
from sklearn.linear_model import LinearRegression

# rugosità Ra misurata in funzione di avanzamento e velocità di taglio
X = np.array([[0.10, 150], [0.15, 150], [0.20, 150], [0.10, 250], [0.15, 250], [0.20, 250]])
y = np.array([0.82, 1.65, 2.90, 0.70, 1.48, 2.60])        # µm
m = LinearRegression().fit(X, y)
print("coefficienti:", m.coef_.round(4), "intercetta:", round(m.intercept_, 3))
print("Ra prevista con f = 0.12, v = 200:", m.predict([[0.12, 200]]).round(2), "µm")
```

## Dividere i dati: allenamento e prova

Un modello va valutato su dati che **non ha visto**, altrimenti sembra perfetto e poi sbaglia.

```python
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestRegressor
from sklearn.metrics import mean_absolute_error, r2_score

rng = np.random.default_rng(0)
n = 400
v = rng.uniform(100, 300, n)          # velocità di taglio [m/min]
f = rng.uniform(0.05, 0.3, n)         # avanzamento [mm/giro]
ap = rng.uniform(0.5, 3, n)           # profondità [mm]
vita = 6e5 * v**-1.6 * f**-0.6 * ap**-0.2 * rng.lognormal(0, 0.08, n)   # minuti (tipo Taylor)
X = np.column_stack([v, f, ap])

X_tr, X_te, y_tr, y_te = train_test_split(X, vita, test_size=0.25, random_state=1)
rf = RandomForestRegressor(n_estimators=200, random_state=1).fit(X_tr, y_tr)
pred = rf.predict(X_te)
print(f"errore medio {mean_absolute_error(y_te, pred):.1f} min, R² = {r2_score(y_te, pred):.3f}")
print("importanza:", {k: round(float(v), 2) for k, v in zip(["v", "f", "ap"], rf.feature_importances_)})
```

## Quando la fisica aiuta: trasformare le variabili

La legge di Taylor è una potenza: in scala logaritmica diventa **lineare**. Un modello lineare sui logaritmi è semplice, interpretabile e spesso migliore.

```python
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import cross_val_score

rng = np.random.default_rng(0)
n = 400
v, f, ap = rng.uniform(100, 300, n), rng.uniform(0.05, 0.3, n), rng.uniform(0.5, 3, n)
vita = 6e5 * v**-1.6 * f**-0.6 * ap**-0.2 * rng.lognormal(0, 0.08, n)
Xlog = np.log(np.column_stack([v, f, ap]))
m = LinearRegression()
punteggi = cross_val_score(m, Xlog, np.log(vita), cv=5, scoring="r2")
m.fit(Xlog, np.log(vita))
print("esponenti stimati:", m.coef_.round(2), "(veri: −1.6, −0.6, −0.2)")
print(f"R² in validazione incrociata: {punteggi.mean():.3f} ± {punteggi.std():.3f}")
```

## Classificare: guasto sì o no

```python
import numpy as np
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import confusion_matrix

rng = np.random.default_rng(2)
rms = np.concatenate([rng.normal(1.0, 0.25, 150), rng.normal(2.0, 0.4, 50)])     # vibrazione [mm/s]
temp = np.concatenate([rng.normal(55, 5, 150), rng.normal(70, 6, 50)])           # °C
guasto = np.r_[np.zeros(150), np.ones(50)]
X = np.column_stack([rms, temp])
clf = LogisticRegression().fit(X, guasto)
print(confusion_matrix(guasto, clf.predict(X)))
print("probabilità di guasto (rms 1.6, 64 °C):", clf.predict_proba([[1.6, 64]])[0, 1].round(2))
```

> [!trappola] Un modello non sa estrapolare: se l'hai allenato con velocità tra 100 e 300 m/min, a 500 m/min la previsione è un'invenzione. Conosci sempre l'intervallo dei dati di allenamento.

> [!ing] Nella manutenzione predittiva e nell'ottimizzazione dei processi questi modelli sono già pratica comune. Il valore aggiunto dell'ingegnere è sapere quali grandezze misurare e riconoscere quando un modello dice sciocchezze.
