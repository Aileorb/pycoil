Una campagna di prove produce centinaia di file: uno per provino, con nomi scritti a mano da persone diverse. Python li trova, li ordina, li rinomina e li archivia in pochi secondi, e lo fa **sempre allo stesso modo**.

```python
from pathlib import Path

cartella = Path("prove")
cartella.mkdir(exist_ok=True)
for nome in ["trazione_S355_01.csv", "trazione_S355_02.csv", "durezza_S235_01.csv", "note.txt"]:
    (cartella / nome).write_text("forza;allungamento\n")

csv = sorted(cartella.glob("*.csv"))
print(len(csv), "file CSV")                                    # → 3 file CSV
print([f.name for f in sorted(cartella.glob("trazione_*.csv"))])   # → ['trazione_S355_01.csv', 'trazione_S355_02.csv']
```

`glob` cerca i file che corrispondono a uno **schema**: `*` vuol dire «qualunque testo». `sorted` mette i risultati in ordine alfabetico, perché il sistema operativo li restituisce in un ordine qualsiasi.

## Un percorso è un oggetto, non una stringa

Nella Parte I hai usato `Path` per aprire un file. Un `Path` sa scomporsi da solo nei suoi pezzi, e l'operatore `/` unisce cartelle e nomi con il separatore giusto per il sistema (`/` su macOS e Linux, `\` su Windows).

```python
from pathlib import Path

f = Path("prove") / "lotto_A" / "trazione_S355_01.csv"
print(f.as_posix())        # → prove/lotto_A/trazione_S355_01.csv
print(f.name)              # → trazione_S355_01.csv
print(f.stem)              # → trazione_S355_01
print(f.suffix)            # → .csv
print(f.parent.name)       # → lotto_A
print(f.with_suffix(".xlsx").name)          # → trazione_S355_01.xlsx
print(f.stem.split("_"))                    # → ['trazione', 'S355', '01']
```

- `name` è il nome completo, `stem` il nome senza estensione, `suffix` l'estensione;
- `parent` è la cartella che lo contiene;
- `with_suffix` e `with_name` creano un **nuovo** percorso con un pezzo cambiato (il file sul disco non cambia).

> [!trappola] Non costruire i percorsi sommando stringhe (`"prove" + "\\" + nome`): funziona su un sistema e si rompe sull'altro. Con `Path` e `/` il codice va bene ovunque.

## Cercare: glob e rglob

Gli schemi di `glob` usano pochi caratteri speciali:

| Schema | Significato | Esempio che corrisponde |
|---|---|---|
| `*` | qualunque testo (anche vuoto) | `*.csv` → `prova.csv` |
| `?` | un solo carattere | `P?.csv` → `P1.csv`, non `P12.csv` |
| `[0-9]` | un carattere tra quelli indicati | `P[0-9][0-9].csv` → `P07.csv` |
| `**` | qualunque numero di sottocartelle | `**/*.csv` → anche `lotto_A/x.csv` |

`glob` guarda solo nella cartella indicata; `rglob` («recursive glob») scende anche in tutte le sottocartelle.

```python
from pathlib import Path

base = Path("campagna")
for rel in ["lotto_A/P01.csv", "lotto_A/P02.csv", "lotto_B/P01.csv", "lotto_B/foto/P01.jpg", "leggimi.txt"]:
    f = base / rel
    f.parent.mkdir(parents=True, exist_ok=True)     # crea anche le cartelle intermedie
    f.write_text("x")

print([f.name for f in base.glob("*.csv")])          # → []
tutti = sorted(f.relative_to(base).as_posix() for f in base.rglob("*.csv"))
print(tutti)                                         # → ['lotto_A/P01.csv', 'lotto_A/P02.csv', 'lotto_B/P01.csv']
print(sorted(d.name for d in base.iterdir() if d.is_dir()))   # → ['lotto_A', 'lotto_B']
```

- `mkdir(parents=True, exist_ok=True)` crea tutta la catena di cartelle e non protesta se esistono già: è la forma da usare quasi sempre;
- `relative_to(base)` toglie la parte iniziale del percorso, comodo da stampare;
- `iterdir()` elenca il contenuto di una cartella, file e sottocartelle; `is_dir()` e `is_file()` li distinguono.

## Dimensione e data di modifica

`stat()` restituisce le informazioni del file system: `st_size` è la dimensione in byte, `st_mtime` l'istante dell'ultima modifica (in secondi dal 1970, da convertire con `datetime`).

```python
from pathlib import Path

Path("vuoto.csv").write_text("")
Path("piccolo.csv").write_text("t;F\n0;0\n")
Path("grande.csv").write_text("t;F\n" + "0.01;12.5\n" * 1000)

for f in sorted(Path(".").glob("*.csv")):
    print(f.name, f.stat().st_size, "byte")
vuoti = [f.name for f in Path(".").glob("*.csv") if f.stat().st_size == 0]
print(vuoti)                       # → ['vuoto.csv']
```

Un file vuoto o troppo piccolo è spesso una prova interrotta: trovarli subito evita di scoprirlo a metà dell'analisi. Per i file più recenti:

```python
from datetime import datetime
from pathlib import Path

Path("oggi.csv").write_text("t;F\n")
ultimo = max(Path(".").glob("*.csv"), key=lambda f: f.stat().st_mtime)
quando = datetime.fromtimestamp(ultimo.stat().st_mtime)
print(ultimo.name, quando.strftime("%d/%m/%Y %H:%M"))
```

`max(..., key=...)` lo conosci dalla Parte I: qui sceglie il file con la data di modifica più grande, cioè il più recente.

## Copiare, spostare, rinominare, cancellare

| Operazione | Codice | Nota |
|---|---|---|
| copiare un file | `shutil.copy2(src, dst)` | conserva anche la data di modifica |
| copiare una cartella | `shutil.copytree(src, dst)` | `dst` non deve esistere |
| spostare o rinominare | `shutil.move(src, dst)` o `src.rename(dst)` | `move` funziona anche tra dischi diversi |
| cancellare un file | `f.unlink()` | **definitivo**, niente cestino |
| cancellare una cartella | `shutil.rmtree(d)` | **definitivo**, con tutto il contenuto |

```python
import shutil
from pathlib import Path

Path("in").mkdir()
Path("in/P01.csv").write_text("t;F\n0;0\n")
Path("backup").mkdir()

shutil.copy2("in/P01.csv", "backup/P01.csv")           # copia
shutil.move("in/P01.csv", "in/S355_P01.csv")           # rinomina
print(sorted(f.name for f in Path("in").iterdir()))    # → ['S355_P01.csv']
print(Path("backup/P01.csv").exists())                 # → True
```

> [!trappola] `unlink` e `rmtree` non chiedono conferma e non passano dal cestino. Negli script automatici sposta i file da scartare in una cartella `_scarti` invece di cancellarli: se lo script sbaglia, recuperi tutto.

## Prima a vuoto, poi davvero

Uno script che rinomina centinaia di file deve poter **mostrare cosa farebbe** senza farlo (*dry run*). Si separa il calcolo del piano dall'esecuzione: una funzione restituisce la lista delle operazioni, un'altra le applica.

```python
import shutil
from pathlib import Path

def piano(cartella):
    """Per ogni CSV «tipo_materiale_n.csv» decide la destinazione «materiale/tipo_n.csv»."""
    mosse = []
    for f in sorted(Path(cartella).glob("*.csv")):
        pezzi = f.stem.split("_")
        if len(pezzi) != 3:
            continue                                   # nome fuori schema: lo lasciamo dov'è
        tipo, materiale, n = pezzi
        dst = Path(cartella) / materiale / f"{tipo}_{int(n):03d}.csv"
        mosse.append((f, dst))
    return mosse

def applica(mosse):
    for src, dst in mosse:
        dst.parent.mkdir(parents=True, exist_ok=True)
        if dst.exists():
            raise FileExistsError(dst)                 # mai sovrascrivere in silenzio
        shutil.move(src, dst)

d = Path("prove")
d.mkdir()
for nome in ["trazione_S355_1.csv", "trazione_S355_2.csv", "durezza_S235_1.csv", "appunti.csv"]:
    (d / nome).write_text("x")

mosse = piano(d)
for src, dst in mosse:
    print(src.name, "→", dst.relative_to(d).as_posix())
applica(mosse)
print(sorted(f.relative_to(d).as_posix() for f in d.rglob("*.csv")))
```

Uscita:

```text
durezza_S235_1.csv → S235/durezza_001.csv
trazione_S355_1.csv → S355/trazione_001.csv
trazione_S355_2.csv → S355/trazione_002.csv
['S235/durezza_001.csv', 'S355/trazione_001.csv', 'S355/trazione_002.csv', 'appunti.csv']
```

Tre scelte da copiare nei tuoi script:

- i file con un nome fuori schema vengono **saltati**, non rinominati male;
- `f"{int(n):03d}"` porta i numeri a tre cifre (`001`, `002`, … `010`): così l'ordine alfabetico coincide con quello numerico;
- se la destinazione esiste già, lo script si ferma invece di sovrascrivere.

## Archiviare: zip

A fine campagna i dati si archiviano in un unico file compresso. `shutil.make_archive` crea lo zip di un'intera cartella; `zipfile` lo rilegge.

```python
import shutil
import zipfile
from pathlib import Path

d = Path("campagna_2026_03")
d.mkdir()
for i in range(1, 4):
    (d / f"P{i:02d}.csv").write_text("t;F\n" * 100)

nome_zip = shutil.make_archive("archivio_2026_03", "zip", root_dir=d)
with zipfile.ZipFile(nome_zip) as z:
    print(sorted(z.namelist()))          # → ['P01.csv', 'P02.csv', 'P03.csv']
print(Path(nome_zip).name)               # → archivio_2026_03.zip
```

## Leggere tutti i file e unirli

Il passo che segue quasi sempre: leggere ogni file e metterli insieme in un'unica tabella, ricordando da quale file arriva ogni riga.

```python
from pathlib import Path
import pandas as pd

d = Path("prove")
d.mkdir()
(d / "P01.csv").write_text("deformazione;tensione\n0.001;210\n0.002;355\n")
(d / "P02.csv").write_text("deformazione;tensione\n0.001;208\n0.002;349\n")

parti = []
for f in sorted(d.glob("*.csv")):
    df = pd.read_csv(f, sep=";")
    df["provino"] = f.stem
    parti.append(df)
tutto = pd.concat(parti, ignore_index=True)
print(tutto.groupby("provino")["tensione"].max().to_dict())   # → {'P01': 355, 'P02': 349}
```

È la stessa struttura del Progetto 9: un ciclo sui file, una tabella per file, `concat` alla fine.

> [!nota] Nell'app i file vivono in un disco virtuale che si svuota a ogni esecuzione: per questo ogni esempio crea da sé i file che usa. Sul computer `Path("C:/Prove/2026")` o `Path.home() / "Documenti"` puntano alle tue cartelle vere.

> [!ing] Uno schema di nomi deciso all'inizio della campagna (`AAAA-MM-GG_prova_materiale_n.csv`) vale più di qualunque script di pulizia: mettilo per iscritto e fallo rispettare a chi esegue le prove.

## Riepilogo

- `Path` scompone i percorsi (`name`, `stem`, `suffix`, `parent`) e li unisce con `/`, su ogni sistema.
- `glob` cerca nella cartella, `rglob` anche nelle sottocartelle; ordina sempre con `sorted`.
- `stat().st_size` e `st_mtime` per dimensione e data; `mkdir(parents=True, exist_ok=True)` per creare cartelle.
- `shutil.copy2`, `shutil.move`, `make_archive`; `unlink` e `rmtree` sono definitivi.
- Prima calcola il piano e mostralo, poi applicalo; non sovrascrivere mai in silenzio.
