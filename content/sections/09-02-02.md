Un certificato di collaudo o una scheda di prova si consegnano in **PDF**: si apre uguale su ogni computer e nessuno lo modifica per sbaglio. **fpdf2** disegna il PDF direttamente da Python, pagina per pagina.

```python
from fpdf import FPDF

pdf = FPDF()                      # A4 verticale, misure in millimetri
pdf.add_page()
pdf.set_font("Helvetica", style="B", size=16)
pdf.cell(0, 10, "Certificato di collaudo", new_x="LMARGIN", new_y="NEXT")
pdf.set_font("Helvetica", size=11)
pdf.multi_cell(0, 6, "Lotto 2026-118: 48 pezzi controllati, 47 conformi.")
pdf.output("certificato.pdf")
print(pdf.page_no())              # → 1
```

Il PDF si costruisce come con una penna: scegli il carattere, scrivi una **cella** (una riga di testo in un riquadro), il cursore va a capo, scrivi la successiva.

## Come ragiona fpdf2

La pagina è un foglio A4 di 210 × 297 mm con dei margini (10 mm di default). C'è un **cursore**, il punto in cui verrà scritto il prossimo elemento, con coordinate `x` e `y` in millimetri dall'angolo in alto a sinistra.

- `cell(w, h, testo)` scrive **una riga** in un riquadro largo `w` e alto `h`; `w=0` vuol dire «fino al margine destro». Con `new_x="LMARGIN", new_y="NEXT"` il cursore va a capo, altrimenti resta a destra della cella (utile per mettere più celle sulla stessa riga);
- `multi_cell(w, h, testo)` va a capo da sola quando il testo è lungo; `h` è l'altezza di **ogni riga**;
- `ln(h)` scende di `h` millimetri;
- `set_font(famiglia, style, size)`: `style` è `""`, `"B"` (grassetto), `"I"` (corsivo) o `"BI"`;
- `set_text_color`, `set_fill_color`, `set_draw_color` vogliono i colori come rosso, verde, blu da 0 a 255.

Nell'app fpdf2 si installa da solo al primo uso; sul computer: `pip install fpdf2` (l'`import` è `fpdf`).

```python
from fpdf import FPDF

pdf = FPDF()
pdf.add_page()
pdf.set_font("Helvetica", size=11)
print(round(pdf.epw), round(pdf.x), round(pdf.y))   # → 190 10 10

pdf.cell(40, 8, "Provino", border=1)         # tre celle affiancate
pdf.cell(40, 8, "Rm [MPa]", border=1)
pdf.cell(40, 8, "Esito", border=1, new_x="LMARGIN", new_y="NEXT")
pdf.set_fill_color(255, 199, 206)
pdf.cell(40, 8, "P03", border=1, fill=True)
pdf.cell(40, 8, "498", border=1, fill=True, align="R")
pdf.cell(40, 8, "scarto", border=1, fill=True, new_x="LMARGIN", new_y="NEXT")
print(round(pdf.y, 1))                       # → 26.0
pdf.output("celle.pdf")
```

`epw` (*effective page width*) è la larghezza utile tra i margini: 210 − 2 × 10 = 190 mm. Arrotondiamo perché fpdf2 lavora internamente in punti tipografici e la conversione in millimetri lascia qualche decimale in coda, come i float della Parte 0. Dopo due righe alte 8 mm il cursore è sceso da 10 a 26 mm.

## Le lettere fuori dall'alfabeto latino

I caratteri di base dei PDF (Helvetica, Times, Courier) conoscono solo l'alfabeto latino: `σ`, `≤`, `€`, `γ` mandano in errore fpdf2. Per scrivere i simboli tecnici serve un font **Unicode** in formato TTF. Un font adatto è già sul tuo computer se hai Matplotlib: è il DejaVu Sans, quello dei grafici.

```python
from pathlib import Path
import matplotlib
from fpdf import FPDF

FONT = Path(matplotlib.get_data_path()) / "fonts" / "ttf"
pdf = FPDF()
pdf.add_font("DejaVu", style="", fname=FONT / "DejaVuSans.ttf")
pdf.add_font("DejaVu", style="B", fname=FONT / "DejaVuSans-Bold.ttf")
pdf.add_page()
pdf.set_font("DejaVu", size=12)
pdf.multi_cell(0, 7, "σ = 312,4 MPa ≤ fyd = 338,1 MPa   (γM0 = 1,05)   ✓")
pdf.output("unicode.pdf")
print(Path("unicode.pdf").read_bytes()[:5])     # → b'%PDF-'
```

Ogni file PDF inizia con i byte `%PDF-`: è un controllo rapido che il file sia stato scritto davvero. Con un font registrato puoi usare anche un font aziendale: basta il suo file `.ttf`.

## Intestazione e piè di pagina

Per avere su **ogni** pagina il nome del documento e il numero di pagina, si crea una classe figlia di `FPDF` (l'ereditarietà della Parte II) e si ridefiniscono i metodi `header` e `footer`: fpdf2 li chiama da solo a ogni nuova pagina.

```python
from fpdf import FPDF

class Certificato(FPDF):
    def __init__(self, titolo):
        super().__init__()
        self.titolo = titolo

    def header(self):
        self.set_font("Helvetica", style="B", size=10)
        self.cell(0, 8, self.titolo, border="B", new_x="LMARGIN", new_y="NEXT")
        self.ln(4)

    def footer(self):
        self.set_y(-15)                                  # 15 mm dal fondo
        self.set_font("Helvetica", style="I", size=8)
        self.cell(0, 10, f"Pagina {self.page_no()} di {{nb}}", align="C")

pdf = Certificato("Certificato di collaudo - Lotto 2026-118")
pdf.set_font("Helvetica", size=11)
pdf.add_page()
for i in range(1, 81):
    pdf.cell(0, 7, f"Pezzo {i:03d}: conforme", new_x="LMARGIN", new_y="NEXT")
pdf.output("lungo.pdf")
print(pdf.page_no())                                     # → 3
```

- `{nb}` è un segnaposto che fpdf2 sostituisce alla fine con il numero **totale** di pagine (nella f-string si scrive `{{nb}}` perché le graffe doppie diventano graffe semplici);
- quando una cella non sta più nella pagina, fpdf2 aggiunge da solo una pagina nuova, con intestazione e piè di pagina.

## Tabelle

`pdf.table()` crea una tabella che si adatta alla larghezza della pagina, con l'intestazione ripetuta se la tabella continua sulla pagina seguente.

```python
from fpdf import FPDF

dati = [
    ("Provino", "Fmax [kN]", "A [mm2]", "Rm [MPa]"),
    ("P01", "48.2", "78.5", "614"),
    ("P02", "47.9", "78.6", "609"),
    ("P04", "49.0", "78.4", "625"),
]
pdf = FPDF()
pdf.add_page()
pdf.set_font("Helvetica", size=10)
with pdf.table(col_widths=(30, 25, 25, 25), text_align=("LEFT", "RIGHT", "RIGHT", "RIGHT")) as tabella:
    for riga in dati:
        r = tabella.row()
        for valore in riga:
            r.cell(valore)
pdf.output("tabella.pdf")
print(len(dati) - 1, "righe di dati")            # → 3 righe di dati
```

- la prima riga è l'intestazione (in grassetto e ripetuta sulle pagine successive);
- `col_widths` dà le proporzioni delle colonne, `text_align` l'allineamento di ognuna: i numeri a destra, così le cifre si incolonnano;
- le celle vogliono **testo**: i numeri si formattano prima, con le f-string.

## Grafici

Come in Word, un grafico Matplotlib passa da un `BytesIO`; `image` lo posiziona con la larghezza in millimetri (l'altezza segue le proporzioni).

```python
import io
import matplotlib.pyplot as plt
import numpy as np
from fpdf import FPDF

t = np.linspace(0, 2, 400)
x = np.exp(-0.8 * t) * np.cos(2 * np.pi * 3 * t)
fig, ax = plt.subplots(figsize=(6, 2.5))
ax.plot(t, x)
ax.set(xlabel="t [s]", ylabel="x [mm]")
buf = io.BytesIO()
fig.savefig(buf, format="png", dpi=200, bbox_inches="tight")
plt.close(fig)

pdf = FPDF()
pdf.add_page()
pdf.set_font("Helvetica", style="B", size=12)
pdf.cell(0, 8, "Risposta libera smorzata", new_x="LMARGIN", new_y="NEXT")
pdf.image(buf, w=pdf.epw)
print(round(pdf.y) > 60)                          # → True
pdf.output("grafico.pdf")
```

Dopo `image` il cursore scende sotto la figura: il testo successivo non la copre.

## Un certificato completo

Tutti i pezzi insieme, in una funzione che riceve i dati e scrive il file. È la forma da usare negli script: la stessa funzione, chiamata con lotti diversi, produce certificati identici nella forma.

```python
from fpdf import FPDF

def certificato(file, lotto, data, pezzi):
    """`pezzi` è una lista di (codice, diametro misurato, conforme)."""
    pdf = FPDF()
    pdf.set_title(f"Certificato lotto {lotto}")
    pdf.add_page()
    pdf.set_font("Helvetica", style="B", size=16)
    pdf.cell(0, 10, "Certificato di collaudo dimensionale", new_x="LMARGIN", new_y="NEXT")
    pdf.set_font("Helvetica", size=11)
    conformi = sum(1 for p in pezzi if p[2])
    pdf.multi_cell(0, 6, f"Lotto: {lotto}\nData: {data}\nPezzi controllati: {len(pezzi)}, conformi: {conformi}")
    pdf.ln(4)
    with pdf.table(col_widths=(30, 30, 30), text_align=("LEFT", "RIGHT", "CENTER")) as tab:
        for riga in [("Pezzo", "D1 [mm]", "Esito")] + [(c, f"{d:.3f}", "OK" if ok else "SCARTO") for c, d, ok in pezzi]:
            r = tab.row()
            for valore in riga:
                r.cell(valore)
    pdf.ln(8)
    pdf.cell(0, 6, "Il responsabile qualità: ____________________")
    pdf.output(file)
    return conformi

n = certificato("lotto_118.pdf", "2026-118", "14/03/2026", [("A001", 20.012, True), ("A002", 19.948, True), ("A003", 20.061, False)])
print(n)                                         # → 2
```

`\n` dentro il testo di `multi_cell` va a capo, come nelle stringhe normali.

## Word o PDF?

| | Word (python-docx) | PDF (fpdf2) |
|---|---|---|
| chi lo modifica dopo | chiunque, con Word | nessuno (è il documento finale) |
| impaginazione | la fa Word (a capo, pagine) | la decidi tu, al millimetro |
| modelli aziendali | si parte dal `.docx` dell'azienda | si ridisegnano nel codice |
| adatto a | relazioni da rivedere e firmare | certificati, schede, etichette, archivi |

Una soluzione frequente: il report si genera in Word, si rivede, e il PDF si ottiene alla fine convertendo il `.docx` con LibreOffice (sezione 9.3.1).

> [!nota] Per raccogliere solo **grafici** in un PDF di più pagine basta Matplotlib: `from matplotlib.backends.backend_pdf import PdfPages`, poi `with PdfPages("grafici.pdf") as pdf: pdf.savefig(fig)` per ogni figura.

## Riepilogo

- `FPDF()`, `add_page`, `set_font`, poi `cell` (una riga) e `multi_cell` (testo lungo); misure in mm.
- `new_x="LMARGIN", new_y="NEXT"` per andare a capo; `epw` è la larghezza utile.
- I font di base non hanno `σ`, `≤`, `€`: registra un TTF Unicode con `add_font` (DejaVu arriva con Matplotlib).
- Classe figlia con `header` e `footer` per intestazione e numeri di pagina (`{nb}` per il totale).
- `with pdf.table() as t:` per le tabelle; grafici con `BytesIO` e `pdf.image(buf, w=...)`.
- Word per i documenti da rivedere, PDF per quelli finali.
